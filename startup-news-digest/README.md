# 아침한장

> 아침에 들어온 물류 기사를 골라 3줄로 요약하고, **요약 속 숫자가 원문과 같은지 대조한 뒤** 무료판·유료판 뉴스레터로 내보내는 도구

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘업계한장’)** 의 예시 프로젝트입니다. 기사·매체·회사·숫자는 모두 가상이며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 물류 뉴스를 매일 30개씩 읽고 정리하는 데 아침 2시간 | 기사를 고르고 ‘요약하기’ → 오늘 호가 바로 나옴 · **2시간 → 30분** (목표치) |
| 같은 소식을 다룬 기사를 두 번 읽었다 | 원문 숫자·문장이 겹치는 기사를 **같은 소식**으로 묶어 알려 줌 |
| **요약이 기사 원문과 다른 숫자를 씀** | 숫자는 원문에서 그대로 인용하게 고정. 요약 속 숫자를 하나하나 원문과 대조하고, 다르면 그 문장은 버리거나 발송을 막음 |
| 무료·유료 구독자에게 보낼 내용을 따로 만들었다 | 무료판(앞 3건)·유료판(전부 + 해설)을 버튼 하나로 전환, 메일 HTML·텍스트로 내보내기 |

결과 (1기 목표치): **구독자 1,240명, 유료 96명(월 5,900원) · 정리 2시간 → 30분**

## 주요 기능

- **숫자 원문 대조** — 요약 속 숫자마다 초록(원문과 같음) / 빨강(원문에 없음) 표시. `1,240명`과 `1240명`은 같은 숫자로, `18%`와 `20%`, `42만 건`과 `42만 명`은 다른 숫자로 봅니다.
- **기다리지 않는 요약** — 원문 문장을 그대로 고른 규칙 요약이 즉시 나오고, Claude 요약이 오면 검사를 통과한 문장만 덮어씁니다.
- **뺀 문장 보기** — Claude가 원문과 다른 숫자를 쓴 문장은 버리고, 무엇을 왜 뺐는지 목록으로 보여 줍니다.
- **사람이 고쳐도 같은 검사** — 문장을 고치다 원문에 없는 숫자를 넣으면 발송 버튼이 잠깁니다. 되돌리기 가능.
- **같은 소식 묶기 · 순서 바꾸기 · 기사 직접 붙여 넣기**
- **무료판 / 유료판 · 메일 HTML 복사 · 텍스트 내려받기 · 읽는 시간**

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `newsdigest.summarize` → 형식 검사 → 문장마다 숫자 원문 대조 → 통과한 문장만 사용 | `Claude로 요약 · 2.1초` |
| 숫자가 다른 문장 | 그 문장만 버리고 ‘뺀 문장’에 기록. 기사 하나의 문장이 다 버려지면 그 기사는 원문 문장 요약 | `원문 문장` 배지 |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 원문 문장을 골라 쓰는 규칙 요약 (숫자가 틀릴 수 없음) | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 요약 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
