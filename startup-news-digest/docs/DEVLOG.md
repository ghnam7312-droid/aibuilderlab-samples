# 아침한장 개발 일지 (창업 트랙 1~3주차)

> **1기 목표 모델**: 가상의 수강생 ‘업계한장’(물류 업계 7년 차 · 뉴스레터 운영)이 이렇게 진행하는 것을 목표로 쓴 일지입니다. 실제 수강생의 기록이 아닙니다.
> 숫자는 COVI 학습 기록 기준이며, 포트폴리오에 적은 합계와 같습니다.

| 시기 | 만든 것 | 프롬프트 | 디버깅 | 시간 |
|---|---|---|---|---|
| 1주차 | 아침 2시간 쪼개기, 기사 목록 · 고르기 · 같은 소식 묶기 | 12 | 1 | 2.0h |
| 2주차 | Claude 요약 + 무료판·유료판 뉴스레터 | 16 | 3 | 3.0h |
| 3주차 | 숫자 원문 대조, 발송 잠금, 내보내기, 테스트 | 15 | 2 | 3.0h |
| **합계** | | **43** | **6** | **8h** |

---

## 1주차 — 2시간이 어디서 새는지부터

**한 일**
- 아침 2시간을 재 보니: 기사 30개 훑기 50분, 같은 소식 걸러내기 20분, 요약 쓰기 40분, 메일 편집 10분.
- 기사 목록에서 넣을 것을 고르고 순서를 정하는 화면을 만들었다.
- 매체만 다르고 같은 소식인 기사를 묶었다. 제목은 매체마다 달라서, 본문에 같은 숫자(단위 포함)가 2개 이상이고 글이 많이 겹치면 같은 소식으로 본다.

**막힌 것 → 해결**
- 제목만 비교했더니 ‘택배 단가 다시 오른다’와 ‘누리택배, 상자당 120원 인상’을 못 묶음 → 본문 숫자 겹침을 기준에 더함.

---

## 2주차 — Claude가 요약하게

**한 일**
- `newsdigest.summarize`: 고른 기사를 한 번에 보내고 기사마다 제목·핵심 2~3문장·실무 의미를 받는다.
- 무료판(앞 3건, 해설 없음)과 유료판(전부 + 해설)을 버튼 하나로 바꾼다. 유료는 월 5,900원.
- AI가 안 될 때를 위해, 원문에서 숫자가 든 문장을 골라 쓰는 규칙 요약을 만들었다.

**막힌 것 → 해결**
- **요약이 기사 원문과 다른 숫자를 씀** — ‘18% 증가’를 ‘20% 가까이’로, ‘42만 건’을 ‘약 40만 건’으로, 두 숫자를 더해 원문에 없는 합계를 만들었다. 독자 한 분이 원문과 다르다고 답장을 줬다.
  → 지시문에 “숫자는 원문 표기 그대로 옮기고, 단위를 바꾸거나 계산하거나 반올림하지 않는다”를 넣었다. 그래도 가끔 틀려서 3주차에 화면 검사를 붙였다.
- Claude가 기사 하나를 빠뜨리고 돌려줌 → 빠뜨린 기사는 규칙 요약으로 채우게 함.
- 응답이 가끔 JSON이 아님 → 형식 검사(`normalizeDigest`)에서 버리고 규칙 요약 유지.

## 3주차 — 숫자는 원문 그대로

**한 일**
- 숫자와 단위를 뽑아 원문과 대조하는 `checkNumbers`. 원문에 없는 숫자가 든 Claude 문장은 버리고, 뺀 문장을 화면에 목록으로 남긴다.
- 사람이 고친 문장도 같은 검사. 원문과 다른 숫자가 하나라도 있으면 발송 버튼이 잠긴다.
- 숫자마다 초록/빨강 표시, 상단에 ‘원문과 같은 숫자 37/37’.
- 메일 HTML 복사, 텍스트 내려받기, 로직 분리 + 테스트 14개.

**막힌 것 → 해결**
- `1,240명`과 `1240명`을 다른 숫자로 봄 → 쉼표를 빼고 비교.
- `42만 명`(틀림)이 `42만 건`(원문)과 같다고 통과 → 만·억·천 뒤의 세는 말까지 단위로 묶음.

**결과 (1기 목표치)**
- 구독자 1,240명, 유료 96명(월 5,900원) · 정리 2시간 → 30분

> 리드 빌더 코멘트 — “숫자를 원문 그대로 쓰게 한 규칙 하나가 유료 구독의 이유가 됐습니다.” — 린스타터
