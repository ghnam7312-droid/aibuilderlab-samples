# 한자리

> 상담 예약 폼 → 결제 → 안내 메일을 한자리에서 자동으로. 메일은 **보내는 순간 결제 상태를 다시 확인**해서, 취소한 예약에는 가지 않습니다.

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘이직나침반’)** 의 예시 프로젝트입니다. 예약 고객은 모두 가상 인물이고, 결제는 **실제 결제가 아닌 모의 상태 전환**입니다. 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 예약 문의를 DM으로 받고, 빈 시간을 일일이 답했다 | 고객이 빈 시간만 고르는 예약 폼. 같은 시간은 한 명만 → **응대 하루 30분 → 5분** |
| 계좌 입금을 눈으로 확인했다 | 결제 링크 → 결제 완료로 자동 전환. 12시간 안에 결제 안 하면 자리가 풀림 |
| 상담을 잊고 안 오는 고객 (노쇼 22%) | 확정 · 하루 전 · 2시간 전 안내 자동 발송 → **노쇼 22% → 6%** |
| 취소한 예약에도 안내 메일이 갔다 | 보낼 시각에 **예약 상태를 다시 확인**하고, 맞지 않으면 ‘보류 · 취소된 예약’으로 남김 |

## 주요 기능

- **예약 폼** — 상품(1회 상담 · 4주 패키지), 7일 × 3개 시간. 이미 잡힌 시간과 2시간 이내는 고를 수 없습니다.
- **모의 결제** — ‘결제 링크 열기’ → 결제 승인 / 승인 실패 시험. 실제로 돈이 오가지 않습니다.
- **시뮬레이션 시계** — `+6시간`, `+1일`로 시간을 돌리면 그 사이 보낼 메일이 처리되고, 결제 기한이 지난 자리는 풀립니다.
- **자동 안내 메일** — 결제 요청 · 결제 리마인드 · 예약 확정 · 하루 전 · 2시간 전. 보냄 / 보류(이유)를 메일함에 남기고, 눌러서 본문을 봅니다.
- **취소 · 환불** — 24시간 전까지 전액, 그 뒤 50%(코치가 정한 규정). 되돌리기 가능.
- **완료 · 노쇼 기록** — 상담 시각이 지난 뒤에만 기록하고, 기록 기준 노쇼율을 보여 줍니다.
- 메일함과 예약 목록의 이메일은 `ha***@example.com`처럼 가려서 보여 줍니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | 확정 메일을 규칙 문장으로 먼저 넣고 `coachbooking.mail` 결과가 검사를 통과하면 교체 | `Claude로 작성 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 규칙 문장 그대로 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 (일시가 다르거나 금액이 다름) | 버리고 규칙 문장 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

**보낼지 말지는 AI가 정하지 않습니다.** 발송 여부는 항상 `shouldSend()` 규칙이 예약 상태로 결정합니다.

작업 정의는 [docs/ai-task.json](docs/ai-task.json), 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문은 [docs/PROMPTS.md](docs/PROMPTS.md).

## 기술 스택

| 구분 | 데모 | 실제 버전 |
|---|---|---|
| 예약 폼 | HTML · CSS · JavaScript (빌드 없음) | 예약 폼 |
| 결제 | 모의 상태 전환 (`pay()`) | 결제 링크 + 결제 완료 알림 |
| 메일 | 화면 안 메일함 (`runScheduler()`) | 메일 자동 발송 |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai` | Claude API |
| 테스트 | Node 내장 `node:test` | |
