# 사실먼저

> 의뢰인이 쓴 상황 설명에서 근무 기간·임금·근무 시간·계약서 유무 같은 **사실관계만** 정리하고, 판단은 **노무사 상담에서 확인**으로 넘기는 노무 상담 사전 접수 도구

**데모** · https://aibuilderlab.kr/demo/startup-labor-intake/index.html

> **알림** AI 빌더랩 스타트업 트랙 **1기 목표 모델(가상의 수강생 ‘노무한눈’)** 의 예시 프로젝트입니다. 의뢰인·사업장은 모두 가상이고, 결과 숫자는 1기 목표치입니다. 이 도구는 법률 자문을 하지 않습니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 전화 상담 초반 40분을 근무 기간·임금·계약서 유무를 묻는 데 썼다 | 상담 전에 받은 설명을 7개 사실 항목으로 정리 → **접수 정리 40분 → 8분** |
| 빠진 사실을 상담 중에야 알았다 | 설명에 없는 항목은 **상담 전에 확인할 질문**으로 바뀌고, 들은 답을 바로 적는다 |
| AI가 “받을 수 있습니다”처럼 법적 판단을 답처럼 말했다 | 판단 문장은 결과에서 빼고 **‘노무사 상담에서 확인’** 으로 옮긴다. 의뢰인 질문에도 답하지 않는다 |
| 정리된 값이 어디서 나왔는지 몰랐다 | 사실마다 **근거 문장 번호**. 원문에 근거가 없는 AI 값은 버린다 |
| 상담 가능 건수가 적었다 | **월 상담 18건 → 34건** (목표치) |

## 주요 기능

- **접수 목록** — 샘플 의뢰인 3명(근로자·사업주). 목록마다 정리된 사실 수와 확인할 것 개수.
- **문장 보기** — 의뢰인 설명을 문장으로 나누고, 근거로 쓴 문장과 의뢰인 질문을 색으로 표시. 결과의 `3번 문장`을 누르면 그 문장으로 갑니다.
- **사실 정리 표** — 입사일, 퇴사일·재직 여부, 임금, 근무 시간(주 N시간 계산), 근로계약서, 사업장 인원, 상담 주제 + 근무 기간 계산.
- **상담 전에 확인할 것** — 빠진 항목마다 물어볼 질문과 답 적는 칸.
- **노무사 상담에서 확인** — 의뢰인 질문과 AI가 쓴 판단 문장(줄 그어 표시)을 모아, 답하지 않고 넘깁니다.
- **판단 문장 검사** — 아무 문장이나 넣어 사실/판단/질문 중 무엇으로 읽히는지 바로 확인.
- **상담 준비 메모 복사 · 인쇄** — 이름은 가리고(정\*윤), 설명 속 전화번호·이메일도 가립니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `laborintake.facts` → `normalizeAi` 검사(정해진 항목만, 근거 문장 확인, 판단 문장 차단) → 규칙 결과 위에 덮어씀 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 날짜·금액·낱말 규칙으로 정리 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 결과 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

이름·연락처는 AI에 보내지 않고, 설명 안의 전화번호·이메일도 가려서 보냅니다. 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

|---|---|
