# 집으로

> 부모 교육 강사가 강의 원고를 넣으면 부모가 집에서 해 볼 **가정 실천 카드**(말 한마디 · 행동 1개 · 돌아보기 질문)를 만들고, 카드의 모든 문장에 **근거가 된 원고 문장 번호**를 붙여 근거 없는 의학·발달 조언은 버리는 주간 구독 서비스

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘한걸음부모’)** 의 예시 프로젝트입니다. 강의 원고 3개와 카드 문장은 이 예시를 위해 새로 쓴 가상의 내용이고, 결과 숫자는 1기 목표치입니다. 이 서비스는 의료·발달 판단을 하지 않습니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 강의가 끝나면 부모님들이 “집에서 뭘 해 보면 되냐”고 묻는데, 강의 내용을 집에서 이어 갈 자료가 없었다 | 강의 원고를 문장 단위로 번호를 붙이고, 그 문장으로 **가정 실천 카드**와 **주간 구독 메일**(무료판/유료판)을 만든다 |
| AI가 강의에 없는 의학·발달 조언(예: 잠자리 강의 카드에 ‘멜라토닌’)을 덧붙였다 | 카드의 모든 문장은 원고 문장 번호가 있어야 하고, 원고와 60% 이상 일치해야 한다. 원고에 없는 의학·발달·약·진단 낱말이나 숫자 기준이 있으면 **버리고 이유를 남긴다** |
| 부모가 보낸 질문에 건강·발달 고민이 섞여 온다 | 건강·발달·안전 낱말이 있으면 카드를 만들지 않고 **전문가 상담 안내**, 응급 낱말이면 **119 안내**. 이 질문은 AI에 보내지 않는다 |
| 카드 제작에 매주 3시간이 걸렸다 | 원고를 넣으면 규칙 카드가 바로 나오고, 발송함에 담아 월요일에 보낸다 (목표: 주 30분) |

## 주요 기능

- **가정 실천 카드** — 오늘 해 볼 말 한마디 · 해 볼 행동 1개 · 돌아보기 질문 · 강사 한 줄. 문장마다 `원고 3` 같은 근거 칩, 누르면 왼쪽 원고 문장이 강조된다.
- **근거 검사** — 규칙 카드든 Claude 카드든 같은 `ground()`를 거친다. 버린 문장은 이유와 함께 ‘버린 문장’에 남는다.
- **문장 근거 검사기** — 카드에 넣고 싶은 문장과 근거 번호를 적으면 지금 원고로 검사한다.
- **부모 질문 → 사람에게 넘기기** — 건강·발달은 상담 안내, 응급은 119. 질문의 이름·전화·메일·나이는 가리고(`scrub`) 보낸다.
- **주간 구독 메일 미리보기** — 무료판(말·행동)과 유료판(질문·강사 한 줄·근거 원문까지), 받는 사람 이름 없이 ‘보호자님’. 복사 버튼.
- **이번 주 발송함** — 같은 주 같은 강의 카드는 한 장만(새로 담으면 바꿔 끼움), 빼기·되돌리기.
- **다른 문장으로 · 원고 고치기 · 샘플로 되돌리기**.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `parentcards.make` → 형식 검사(`normalizeCard`) → **문장마다 근거 검사(`ground`)** → 말·행동·질문이 모두 남으면 덮어씀 | `Claude로 정리 · 2.1초`, 버린 문장 개수 |
| AI 키 없음 · 한도 초과 · 작업 없음 · 네트워크 오류 | 원고 문장에서 규칙 카드 (같은 근거 검사) | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 카드 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |
| 근거 있는 문장이 모자람 | 버리고 규칙 카드 유지, 버린 이유는 표시 | `규칙 기반 · 근거 있는 문장이 모자람` |
| 부모 질문에 건강·발달·안전 낱말 | 카드를 만들지 않고 AI도 부르지 않음 | 전문가 상담 안내 / 119 안내 |

Claude에게는 강의 제목, 번호 붙은 원고 문장, 개인정보를 가린 질문만 보냅니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버에 넣을 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 이 데모 | 실제 버전 (포트폴리오) |
|---|---|---|
| 화면 | HTML · CSS · JavaScript (빌드 없음) | Next.js |
| 저장 | localStorage (`startup-parent-cards-v1`, 부모 질문은 저장 안 함) | Supabase (원고·카드·구독자·발송 기록) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai` | Claude API |
| 테스트 | Node 내장 `node:test` 13개 | 같음 |
