# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버에 넣을 원문([ai-task.json](ai-task.json))입니다.

## 1. 만들 때 쓴 프롬프트 (대표 4개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 7주 | 문장 나누기 | 원고를 마침표·물음표 뒤에서 잘라 1부터 번호를 붙여 줘. 따옴표 “ ” 안의 물음표에서는 자르지 마. |
| 8주 | 응답 검사 | Claude 응답에서 lines가 배열이 아니면 null. slot이 say/do/ask/tip이 아니거나 text가 없으면 그 줄은 버려. |
| 8주 | 근거 검사 | 카드 문장마다 refs 번호의 원고 문장과 비교해. 번호가 없거나, 일치가 60% 미만이거나, 원고에 없는 의학·발달·약 낱말이나 ‘1시간’ 같은 숫자가 있으면 버리고 이유를 문장으로 남겨. ‘약속’은 ‘약’이 아니야. |
| 9주 | 사람에게 넘기기 | 부모 질문에 ‘삼켰’, ‘경련’이 있으면 119 안내, ‘말이 늦’, ‘발달’, ‘약’이면 상담 안내만 하고 카드는 만들지 마. 그 질문은 AI에 보내지 마. |

## 2. 서비스가 쓰는 지시문 (`parentcards.make`)

```
부모 교육 강사의 강의 원고로 부모가 집에서 해 볼 '가정 실천 카드'를 만든다. input.sentences는 번호(no)가
붙은 강의 원고 문장이다. lines에 slot이 say(오늘 해 볼 말 한마디: 부모가 아이에게 그대로 할 말),
do(해 볼 행동 1개), ask(부모가 스스로 하는 돌아보기 질문), tip(강사 한 줄)인 문장을 하나씩 쓴다.
모든 문장은 input.sentences의 문장만 근거로 쓰고, 근거가 된 문장 번호를 refs에 넣는다. 원고 문장의
낱말을 되도록 그대로 쓰고, 원고에 없는 내용을 덧붙이지 않는다. input에 없는 사실을 지어내지 않는다.
특히 의학·발달·약·진단·치료에 관한 조언, 월령·나이·시간 같은 숫자 기준은 원고에 없으면 절대 쓰지 않는다.
input.question은 부모가 보낸 질문이다. 질문과 가까운 원고 문장을 먼저 고르되, 질문에 답하려고 원고 밖의
조언을 만들지 않는다. 아이의 상태를 판단하지 않는다. 모든 문장은 한국어로, 짧고 구체적으로 쓴다.
반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"lines":[{"slot":"say","text":"","refs":[1]}]}
```
- 입력: `{ lecture, sentences:[{no, text}], question(개인정보 가림), seed }` · 최대 700토큰
- 화면 검사: `normalizeCard()` → 문장마다 `ground()` → 말·행동·질문이 모두 남을 때만 사용

### 왜 이렇게 썼나

- **번호를 받는다.** “원고만 보고 써”라고만 하면 지켰는지 확인할 길이 없다. 근거 번호가 있어야 화면이 그 문장과 맞춰 볼 수 있다.
- **원고 낱말을 그대로 쓰게 한다.** 일치율로 검사하므로, 말을 많이 바꾸면 버려진다. 강사 말투가 남는 것도 장점이다.
- **질문은 고르는 데만.** 부모 질문에 ‘답’하려 하면 원고 밖 조언이 생긴다. 건강·발달 질문은 애초에 화면이 걸러 보내지 않는다.
- **그래도 지시문을 믿지 않는다.** ‘절대’를 넣은 v3에서도 드물게 원고에 없는 숫자가 섞여 왔다. 최종 판단은 `ground()`다.

## 3. 실패했던 이전 버전

### v1 (버림)
```
다음 강의 내용을 바탕으로 부모가 집에서 실천할 카드를 만들어 줘. 따뜻한 말투로.
```
- 잠자리 루틴 강의에 ‘잠들기 전 멜라토닌을 조금 먹이면 도움이 됩니다’, 스마트폰 강의에 ‘하루 1시간’이 붙었다. 강의에 없던 말이다.
- 어느 문장이 강의 어디에서 왔는지 알 수 없어 강사가 하나하나 원고와 대조해야 했다 (주 3시간의 대부분).

| 버전 | 바꾼 것 | 결과 |
|---|---|---|
| v1 | 자유 작성 | 강의에 없는 의학·숫자 조언 · 출처 없음 |
| v2 | JSON 형식, 문장마다 refs | 대조는 쉬워짐, 번호만 붙이고 내용은 지어내는 경우 남음 |
| v3 | 원고 낱말 유지 + 화면에서 `ground()`로 일치율·의학 낱말·숫자 검사 | 근거 없는 문장이 화면에 나오지 않음, 버린 이유 표시 |
