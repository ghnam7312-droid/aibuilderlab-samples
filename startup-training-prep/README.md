# 맞춤사례

> 사전 설문으로 고객사의 고민을 진단하고, **공개 정보와 설문 요약만** 써서 업종에 맞는 강의 사례 초안을 만드는 도구. 회사 내부 자료는 AI에 넣기 전에 걸러 냅니다.

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘교육효과측정소’)** 의 예시 프로젝트입니다. 고객사 3곳·설문·자료는 모두 가상이고, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 회사마다 업종이 다른데 같은 사례로 강의해 반응이 엇갈렸다 | 사전 설문으로 고민 순위를 내고, 상위 3개 고민을 **그 업종의 말**(물류센터·교대조, 개발 조직·스쿼드, 생산 라인)로 사례에 옮긴다 |
| 사례 하나 고치는 데 자료 읽고 다시 쓰는 데 3시간 | 고객사를 고르면 진단·사례 3개·오프닝 질문이 바로 나오고, Claude가 다듬는다 (**3시간 → 40분**) |
| 회사 내부 자료를 AI에 그대로 넣으려 했다 | 자료마다 **기준 검사**: 공개 정보·설문 요약은 사용, 대외비·인사 정보·직원 실명·연락처는 제외, 금액·비율 수치는 사람이 공개 출처를 확인해야 사용. AI에 실제로 보내는 내용을 화면에서 그대로 보여 준다 |
| AI가 내부 수치를 기억해 사례에 섞을 수 있다 | 제외한 자료의 수치·실명·따옴표 이름을 뽑아 두고, Claude 사례에 섞여 오면 그 사례를 버린다 |

## 주요 기능

- **사전 설문 진단** — 고른 항목 + 자유 응답 낱말로 고민 순위(%)를 내고, 자유 응답 인용은 이름을 가려 보여 준다.
- **자료 기준 검사** — `사용 / 확인 필요 / 제외` 판정과 이유. 확인 필요 자료는 “공개 출처를 확인했어요”를 눌러야 들어가고, 제외 자료는 눌러도 들어가지 않는다. 새 자료는 넣기 전에 미리 판정이 보인다.
- **AI에 실제로 보내는 내용 보기** — 보내는 JSON을 그대로 펼쳐 볼 수 있다.
- **맞춤 사례 초안** — 오프닝 질문 1개 + 고민별 사례 3개(상황 + 토론 질문), 근거 자료 개수 배지.
- **강의 노트 복사(마크다운) · 인쇄**, 자료 지우기(되돌리기), 샘플로 되돌리기.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `trainingprep.cases` → 형식 검사 → 제외 자료 낱말이 섞인 사례 버림 | `Claude로 작성 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 업종별 낱말 × 고민별 사례 틀로 규칙 사례 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 / 사례가 모두 버려짐 | 규칙 사례 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 자료 검사 | 브라우저 안에서 `logic.js` (내부 자료는 서버로 보내지 않음) |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
startup-training-prep/
├── index.html
├── style.css
├── logic.js          진단 · 자료 기준 검사 · 새어 나감 낱말 · 업종 사례 틀 · 응답 검사 · 강의 노트 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            고객사 · 진단 · 자료 · 사례 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```

```bash
npm test                      # = node --test, 11개
```
