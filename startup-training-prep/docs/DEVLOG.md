## 7주차 — 같은 사례, 엇갈린 반응

**한 일**
- 지난 분기 강의 평가를 보니 같은 ‘피드백 리더십’ 과정인데 물류 고객사는 3.8, IT 고객사는 4.4. 의견에 “우리 현장과 안 맞는 사례”가 반복됐다.
- 강의 2주 전에 보내는 사전 설문(고민 6가지 중 고르기 + 자유 응답)으로 고민 순위를 내는 진단을 만들었다.
- 고민별 사례 틀에 업종 낱말(물류센터·교대조·출고 마감 / 개발 조직·스쿼드·배포 일정 / 생산 라인·품질 점검)을 끼워 넣는 규칙 사례, 그리고 Claude가 다듬는 `trainingprep.cases`.

**막힌 것 → 해결**
- 업종 낱말을 끼우니 “라인가”, “스쿼드이” 같은 조사가 어색함 → 받침에 맞춰 조사를 고르는 함수를 만들고 테스트.
- 자유 응답 낱말과 고른 항목이 같은 사람에게서 두 번 세짐 → 고르지 않은 항목만 자유 응답으로 더함.

## 8주차 — 회사 내부 자료를 AI에 넣으려 했다

**한 일**
- 담당자에게 받은 ‘센터별 실적(대외비)’과 팀장 면담 메모를 그대로 AI에 붙이려다 멈췄다. 고객사 정보를 어디까지 넣을지 기준이 없었다.
- 기준을 정했다: **공개 정보와 설문 요약만**. 자료마다 사용 / 확인 필요 / 제외로 판정하고 이유를 보여 준다. 금액·비율이 있는 공개 자료는 사람이 출처를 확인해야 들어간다.
- AI에 실제로 보내는 내용을 화면에서 펼쳐 볼 수 있게 했다. 담당자에게 “이것만 보냅니다”를 보여 줄 수 있다.
- 제외한 자료의 수치·실명이 Claude 사례에 섞여 오면 그 사례를 버리는 검사.

**막힌 것 → 해결**
- ‘신임 팀장 12명’이 직원 실명으로 걸림 → 성씨로 시작하는지 + 일반 낱말 예외 목록으로 이름만 찾게 고침(테스트 추가).

**결과 (1기 목표치)**
- 맞춤 사례 준비 3시간 → 40분, 교육 만족도 4.1 → 4.6
