# 고객말

> 쇼핑몰 리뷰를 감정 · 주제 · 개선 요청으로 나누고, **AI가 애매해하는 리뷰는 ‘사람 확인’으로 따로 모아** 상품팀에 보낼 개선 요청 상위 5개를 만드는 도구

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘보고서는자동’ · 마케팅팀 주임)** 의 예시 프로젝트입니다. 가상의 생활용품 쇼핑몰 ‘하루살림’의 리뷰 24건(월 800건 중 일부라고 가정)으로 동작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 쇼핑몰 리뷰 월 800건을 읽을 사람이 없어 불만이 쌓이는 걸 몰랐다 | 분류는 자동, 사람은 애매한 것만 → **분류 월 2일 → 1시간 (목표치)** |
| “배송 진짜 빠르네요^^ 열흘 만에 왔어요” 같은 반어적 칭찬을 긍정으로 분류 | 반어 신호 · 별점과 글 어긋남 · 낮은 확신도는 **‘사람 확인’으로 따로 모음**. AI가 확신해도 이 칸은 사람만 비울 수 있음 |
| 불만은 많은데 무엇부터 고칠지 몰랐다 | 상품 · 주제별로 묶은 **개선 요청 상위 5개** → 상품팀 전달 글 (목표: 상위 5개 상품팀 전달) |
| 다침 · 발열 같은 리뷰가 다른 불만 사이에 묻혔다 | 안전 관련은 분류하지 않고 맨 위로, **품질안전 담당에게 넘기기** |
| 리뷰에 고객 연락처가 적혀 있기도 했다 | 이름 가운데 가리기, 전화번호 · 이메일 · 주문번호는 화면 · AI 입력 · 전달 글에서 모두 가림 |

## 주요 기능

- **분류** — 리뷰마다 감정 · 주제 · 개선 요청 · 확신도와 누가(Claude/규칙) 분류했는지 표시.
- **사람 확인** — 노란 카드에서 긍정 · 중립 · 부정을 고르면 집계에 들어갑니다. 정한 것은 되돌릴 수 있습니다.
- **안전 관련** — 빨간 카드, AI 제안만 보여 주고 판단하지 않습니다. ‘품질안전 담당에게 넘기기’로 넘깁니다.
- **상품팀 전달** — 개선 요청 상위 5와 대표 문장, 사람 확인 대기 건수 안내, 전달 글 복사.
- **거르기** — 위 숫자 칸이나 보기 버튼(전체 · 사람 확인 · 개선 요청 · 부정 · 긍정), 상품별.
- **리뷰 붙여넣기** — `별점 | 상품 | 내용` 한 줄에 한 건. 틀린 줄은 이유를 알려 주고, 맞는 줄은 바로 분류합니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `reviewsort.classify` → 형식 검사 → 규칙 신호와 합치기(`mergeAi`) | `Claude로 분류 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 칭찬 · 불만 말과 별점으로 규칙 분류 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림(절반 넘게) | 버리고 규칙 분류 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |
| Claude 확신도 60% 미만, 또는 규칙이 반어 · 어긋남 · 안전을 잡음 | 자동으로 끝내지 않음 | 카드에 `사람 확인` |

AI에는 작성자 이름을 보내지 않고, 본문의 연락처는 가린 뒤 보냅니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 실제 버전 | 쇼핑몰 관리자 리뷰 내려받기 → 분류 → 대시보드 |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
ax-review-sort/
├── index.html
├── style.css
├── logic.js          규칙 분류 · 반어/안전 신호 · 개인정보 가리기 · 응답 검사 · 집계 · 전달 글 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            숫자 · 리뷰 목록 · 사람 확인 · 상품팀 전달 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```
