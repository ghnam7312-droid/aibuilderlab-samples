> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘문의정리반’)** 의 예시 프로젝트입니다. 가상의 쇼핑몰 ‘솔담리빙’의 정책과 상담 응답으로 동작하며, 상담원·고객은 모두 지어낸 것입니다. 회사 정책은 예시로 정한 사내 기준이고 법령 기준이 아닙니다. 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 신입 상담원이 익숙해지기까지 **두 달** | 체크리스트 10항목으로 답변마다 바로 점검, 연습 기록으로 실전 투입 시점 판단 → 목표 **3주** |
| 선배마다 “좋은 답변” 기준이 달랐다 | 팀장이 4.5점 이상 준 우수 응답을 분석해 **10항목**으로 정리 |
| **AI가 만든 모범 답안이 회사 정책과 다름** (반품 14일, 배송비 무료 등) | 예시는 **실제 우수 응답만** 사용. AI 답안 · 낮은 점수 · 정책과 다른 응답은 이유와 함께 제외 |
| 정책 숫자를 틀리게 안내 | 답변 속 반품 기한·환불 기간·배송비를 회사 정책과 자동 대조 |

## 주요 기능

- **답변 점검** — 연습 문의 3개(반품·배송비, 배송 지연, 파손)에 답을 쓰고 ‘점검하기’. 10항목마다 통과/고칠 점/해당 없음, 근거 문장, 고칠 방향.
- **우리 팀 실제 예시** — 고칠 항목마다 그 항목을 잘 지킨 선배의 실제 문장(작성자 연차 · 팀장 평가 점수).
- **정책 대조** — 반품·교환 신청 7일, 환불 영업일 3~5일, 단순 변심 왕복 배송비 6,000원, 불량·파손 배송비 없음.
- **약속·사내 말 검사** — ‘무료로 처리해 드릴게요’, ‘반드시 … 드리겠습니다’ 같은 약속과 회수·익일·귀책 같은 사내 말.
- **연습 기록** — 점수 막대, 처음 → 최근 점수, 최근 3번 모두 80점 이상이면 실전 응대 시작 안내. 지우기 + 되돌리기.
- **교육 자료** — 항목별 설명 + 실제 예시 2개, 예시로 쓰지 않는 응답과 이유, 인쇄 · PDF, 텍스트 복사.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `cschecklist.review` → 형식 검사 → 문맥 항목(인사·공감·다음 단계 등)만 덮어쓰기 | `Claude로 점검 · 2.4초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 | 항목별 규칙(표현 찾기 · 정책 대조 · 금지 표현) | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 (유효 항목 5개 미만) | 버리고 규칙 결과 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |
| 근거가 답변에 없는 말 | 그 근거만 지움 | — |
| 정책 · 약속 · 쉬운 말 | Claude가 통과라고 해도 **규칙이 정함** | — |

Claude에게는 **판단만** 받고 모범 답안은 받지 않습니다. 예시는 언제나 실제 우수 응답에서 나옵니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버에 넣을 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 (작업 `cschecklist.review`) |
| 우수 응답 분석 | 팀장 평가 점수 + 항목별 표현 규칙 + 정책 대조 |
| 교육 자료 | 인쇄용 CSS(`@media print`) → PDF 저장, 텍스트 복사 |
| 테스트 | Node 내장 `node:test` |
