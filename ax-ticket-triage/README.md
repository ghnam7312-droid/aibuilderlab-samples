# 첫답

> 하루 150건의 고객 문의를 **분류해 담당자에게 나누고 답변 초안을 붙이는** 도구. 환불·보상과 안전·법률 문의는 **초안 없이 사람에게 바로** 넘깁니다.

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘문의정리반’)** 의 예시 프로젝트입니다. 가상의 쇼핑몰 ‘솔담리빙’의 문의 12건으로 시작하며, 고객·주문은 모두 지어낸 것입니다. 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 하루 150건 문의를 사람이 읽고 담당자에게 나누느라 첫 응답이 **4시간** | 들어오는 즉시 분류·배정·초안 → 첫 응답 목표 **40분** |
| 담당자를 잘못 배정해 다시 넘기는 일이 **12%** | 분류 근거 낱말과 신뢰도를 함께 보여 주고, 직접 바꾼 비율(배정 수정률)을 매일 확인 → 목표 **3%** |
| AI 초안이 환불·보상을 **약속**함 | 환불·보상 문의는 **초안을 만들지 않고** 팀장에게 바로. AI 초안에 약속 표현이 섞이면 버리고 사람에게 |
| 다친 일·신고 같은 문의도 같은 줄에서 기다림 | 안전·법률 낱말이 있으면 분류와 상관없이 매니저에게, ‘급함’ 표시 |

## 주요 기능

- **문의함** — 접수 시각·채널·대기 시간(목표 40분 기준 색), 분류·담당, ‘사람 확인’ 표시. 분류별·담당자별로 거르기.
- **분류 + 담당 배정** — 분류 낱말(제목은 두 번 셈)로 바로 나누고, 열어 본 문의는 Claude가 다시 분류합니다. 담당은 드롭다운으로 바꾸고 되돌릴 수 있습니다.
- **답변 초안** — 분류별 템플릿(주문번호 자동 삽입) 또는 Claude 초안. 고쳐 쓰는 동안 ‘환불해 드리겠습니다’, ‘무료로 교환’, ‘전액’ 같은 **약속 표현을 바로 경고**하고, 남아 있으면 보내지 못합니다.
- **사람에게 넘기기** — 환불·보상, 안전·법률 문의는 초안 칸 대신 넘긴 이유와 ‘담당자 전달 메모 복사’(개인정보 제외).
- **개인정보 가리기** — 이름·휴대폰·이메일·카드번호를 화면 목록, Claude에 보내는 글, CSV에서 가립니다.
- **배정표 CSV** — 번호·분류·담당·넘긴 이유만 내보냅니다(고객 이름·연락처·본문 없음).
- **새 문의 넣어 보기** — 직접 쓴 문의가 바로 분류·배정됩니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `triage.classify` → 형식 검사 → 약속 표현 검사 → 규칙 결과 덮어쓰기 | `Claude로 분류 · 1.8초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 | 분류 낱말 규칙 + 분류별 답변 템플릿 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 (목록에 없는 분류 등) | 버리고 규칙 결과 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |
| AI 초안에 약속 표현 | 초안을 버리고 담당자에게 넘김 | `AI 초안에 약속 표현(…)이 있어 버리고 담당자에게 넘김` |
| 규칙이 사람에게 넘긴 문의 | Claude가 다르게 분류해도 넘김을 풀지 않음 | 사람 확인 유지 |

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 (작업 `triage.classify`) |
| 문의함 | 실제 버전은 고객센터 문의함 내보내기, 데모는 샘플 12건 + 직접 넣기 |
| 답변 템플릿 | 분류별 6종, 주문번호(SD…) 자동 삽입 |
| 테스트 | Node 내장 `node:test` |
