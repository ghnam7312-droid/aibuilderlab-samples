# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 이 서비스가 서버에 등록해 쓰는 원문입니다([ai-task.json](ai-task.json)).

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 7주 | 붙여 넣기 | `[카톡] 이름 · 화면: 내용` 형식의 여러 줄을 읽어서 채널·이름·화면·내용으로 나눠 줘. 형식이 틀린 줄은 줄 번호로 알려 주고 나머지는 계속 읽게. |
| 7주 | 합치기 | 같은 화면의 코멘트끼리 비슷한 정도를 재서 한 항목으로 묶어 줘. 띄어쓰기·조사가 달라도 되게 두 글자씩 잘라 비교하고, 글씨·텍스트·글자처럼 같은 뜻 낱말은 하나로 맞춰. 코멘트 하나가 두 항목에 들어가면 안 돼. |
| 7주 | 응답 검사 | AI가 준 묶음에서 없는 id는 버리고, 두 번 나온 id는 앞에만 남기고, 화면이 섞이면 나누고, 빠진 코멘트는 혼자 한 항목으로 붙여. 쓸 게 없으면 null. |
| 8주 | 닫기 | 항목 상태를 반영함·보류·안 함으로 바꾸는 함수. 보류·안 함은 이유가 비면 실패. 다시 묶어도 닫은 상태는 지키되 새 코멘트가 들어오면 다시 열어 줘. |
| 8주 | 내보내기 | 수정 항목을 화면별 Notion 체크리스트 마크다운으로. 닫은 건 [x]와 상태·이유, 메일 주소와 전화번호는 지워. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

### designreview.group
```
디자인 시안에 달린 리뷰 코멘트를 수정 항목으로 묶는다. input.comments의 각 코멘트는 id, screen(화면 이름), text. 같은 screen 안에서 같은 수정을 요구하는 코멘트만 한 그룹으로 묶고, 다른 screen의 코멘트는 절대 섞지 않는다. 표현이 달라도 고칠 곳과 방향이 같으면 같은 의견이다(예: '배너 글씨가 작아요'와 '메인 배너 텍스트 크기 키우기'). 고칠 곳이 같아도 방향이 반대면 따로 둔다. 모든 id는 정확히 한 그룹에만 넣고, 혼자인 코멘트도 한 그룹으로 둔다. summary는 디자이너가 할 일로 다시 쓴 한 문장(30자 안팎, '~하기'로 끝남). 코멘트에 없는 요구나 화면을 지어내지 않고, 메일 주소·전화번호는 쓰지 않는다. 모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"groups":[{"ids":[""],"summary":""}]}
```
- 입력: `{ comments: [{ id, screen, text }] }` — 작성자 이름은 보내지 않고 연락처는 지운 뒤 보냄 · 최대 1200토큰
- 화면 검사: `normalizeGroups()` → `carryStatus()`로 닫은 결정을 옮겨 붙임

## 3. 왜 이렇게 썼나

- **id로만 답하게** — 요약 문장만 받으면 어떤 코멘트가 어느 항목에 들어갔는지 확인할 수 없습니다. id 목록을 받아 원래 코멘트와 다시 이어 붙입니다.
- **‘정확히 한 그룹’** — 한 코멘트가 두 항목에 들어가는 것이 이 서비스가 고친 문제였기에 지시문과 검사 양쪽에 적었습니다.
- **같은 화면만** — 디자이너는 화면 단위로 고칩니다. 화면이 섞이면 수정 범위가 흐려져서 막았습니다.
- **반대 방향은 따로** — “간격 넓혀 주세요”와 “간격 줄여 주세요”는 같은 곳이지만 다른 결정이 필요합니다.
- **닫기는 사람이** — AI는 묶기까지만 하고, 반영할지 말지는 정하지 않습니다.

## 4. 실패했던 이전 버전

| 버전 | 지시문 | 문제 |
|---|---|---|
| v1 | “피드백을 요약해서 수정 목록으로 만들어 줘” | 줄글 목록이 와서 원래 코멘트와 이을 수 없었고, 같은 의견이 다른 말로 두 번 들어가거나 코멘트에 없는 ‘전체 톤 정리’가 끼어듦 |
| v2 | 위 지시문 (id 묶음 + 같은 화면 + 정확히 한 그룹) + 화면 검사 | 항목마다 원래 코멘트가 붙고, 중복·누락은 화면 검사가 바로잡음 |
