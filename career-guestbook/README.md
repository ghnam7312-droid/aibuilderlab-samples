# 한마디함

> 행사가 끝나면 링크 하나로 익명 의견을 받고, 들어오는 즉시 칭찬·개선 요청·질문으로 나눠 보여 주는 피드백 보드

![한마디함 화면](./screenshot.png)

**데모** · https://aibuilderlab.kr/demo/career-guestbook/index.html

> **알림** 이 저장소의 서비스는 AI 빌더랩 커리어 트랙 **1기 목표 모델(가상의 수강생 ‘새벽기획자’)** 의 예시 프로젝트입니다. 샘플 데이터로 동작하며, 'AI 분류'는 브라우저 안의 규칙으로 흉내 냅니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 동아리 행사 후 익명 피드백을 모을 곳이 없어 매번 구글폼을 만들었다 | 행사마다 링크 하나, 이름 없이 바로 쓰는 쪽지 |
| 수백 건을 사람이 읽고 손으로 분류하느라 반나절이 걸렸다 | 들어오는 즉시 자동 분류 + 요약 → **반나절 → 5분** |
| 질문이 섞여 있어도 답하지 못하고 지나갔다 | 질문 쪽지에서 운영진이 바로 답변 |

## 주요 기능

- **쓰는 동안 분류 미리보기** — 글자를 칠 때마다 쪽지 색과 분류가 바뀌고, 어떤 단어 때문에 그렇게 나눴는지 근거를 보여 줍니다.
- **쪽지 벽** — 분류별 색 쪽지로 모아 보고, 분류 칩이나 요약 막대를 눌러 걸러 봅니다.
- **AI 요약** — 분류 비율, 긍정·부정 비율, 답이 필요한 질문 수를 세 줄로 정리합니다.
- **운영진이 손볼 것** — 개선 요청을 주제(시간 배분·장소·음향 등)로 묶어 많은 순으로 보여 줍니다.
- **사람이 바로잡기** — 자동 분류가 틀리면 쪽지에서 바로 고치고, ‘사람이 고침’ 표시가 남습니다.
- **답변 · 숨기기 · 되돌리기** — 질문에 답하고, 부적절한 쪽지는 숨기며, 실수는 알림의 ‘되돌리기’로 취소합니다.

## 화면 구성

```
┌ 머리글: 행사 이름 · 참가자 링크 복사 · 샘플로 되돌리기 ┐
│ 왼쪽                         │ 오른쪽                      │
│  의견 쓰기 (실시간 분류)     │  분류 칩                     │
│  AI 요약 · 운영진이 손볼 것  │  쪽지 벽 (최신순)            │
└──────────────────────────────┴──────────────────────────────┘
```

## 기술 스택

| 구분 | 이 데모 | 실제 버전 |
|---|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크 없음) | Next.js |
| 저장 | 브라우저 localStorage | Supabase (Postgres + 행 단위 권한) |
| 분류·요약 | 단어 사전 규칙 (`app.js`의 `RULES`, `TOPICS`) | Claude API |

```
career-guestbook/

├── app.js         분류 규칙 · 요약 · 쪽지 벽 · 저장

```

## 실행 방법

빌드가 필요 없습니다. 폴더에서 정적 서버를 띄우고 브라우저로 엽니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 을 엽니다
```

`index.html`을 바로 열어도 동작합니다. 상단의 ‘포트폴리오로’ 링크는 aibuilderlab.kr 안에서만 열립니다.

|---|---|---|
