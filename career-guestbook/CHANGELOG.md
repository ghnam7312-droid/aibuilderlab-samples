# 변경 기록

> 1기 목표 모델 예시의 버전 기록입니다.

## v1.0 — 8주차
- AI 요약 + ‘운영진이 할 일’ (`guestbook.summary`), 새 의견이 쌓이면 다시 요약 버튼
- 행사 진행 모드: 프로젝터용 큰 QR + 벽, 전체 화면, Esc로 끝내기
- 로직을 `logic.js`로 분리, 테스트 18개

## v0.7 — 7주차
- 실시간 방: QR → 참가자 화면 → 3초 안에 벽에 붙음
- 서버 API로 옮김(방 코드 검사, 도배 제한, 2일 뒤 정리)
- 숨긴 쪽지가 다시 나타나던 문제 수정 (cursor)

## v0.5 — 6주차
- 남길 때 Claude 분류(`guestbook.classify`) + 응답 검사, 실패 시 규칙
- ‘~었으면 좋겠어요’를 칭찬으로 잘못 나누던 규칙 수정
- 쪽지에서 분류 바로잡기, 질문에 답하기, 숨기기 + 되돌리기

## v0.1 — 5주차
- 쪽지 입력칸, 쓰는 동안 색이 바뀌는 분류 미리보기, 쪽지 벽
