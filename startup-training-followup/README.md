# 이어감

> 강의 한 번으로 끝나던 기업 교육을 **3개월 후속 관리 상품**으로 기획하는 도구. 담당자 인터뷰를 근거로 구성과 예시 가격을 짜고, ‘효과 보장’ 대신 **무엇을 어떻게 언제 재서 보고하는지**를 약속하는 제안 문구를 만듭니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 강의 한 번으로 끝나 매출이 행사처럼 들쭉날쭉했다 | 강의 뒤 3개월을 구성 요소(리마인드 퀴즈·현업 과제·팀장 점검·복습 세션·90일 리포트)로 나눠 고르는 **구독형 상품** |
| 무엇을 넣어야 담당자가 살지 몰랐다 | 담당자 8명 인터뷰의 요구를 세고, 고른 구성이 **몇 명의 요구를 모두 채우는지** 바로 보여 준다 |
| 제안서에 ‘효과 보장’이라고 썼다 | 문구 검사기가 보장·단정·확정 수치·재지 않는 성과 약속을 찾아 표시하고, **측정 지표 · 방법 · 시점** 문장으로 고친다 |
| 광고 문구가 괜찮은지 혼자 판단했다 | 검사기와 AI는 후보만 표시하고 판단하지 않는다. **사람이 최종 확인**을 체크해야 제안서를 복사할 수 있다 |

## 주요 기능

- **인터뷰 근거** — 요구 5가지를 담당자별 점으로 보여 주고, 1인 예산 중앙값을 계산. 지금 구성에 없는 요구는 빨간 태그.
- **구성 · 예시 가격** — 체크하면 3개월 합계·월·1인 금액이 바로 바뀐다(50명 이상 10%, 100명 이상 15% 할인, 천 원 단위).
- **문구 검사** — 초안을 고치는 동안 걸린 표현과 이유를 실시간 표시. ‘걸린 문장 측정 약속으로 고치기’(되돌리기 가능).
- **제안 문구** — 헤드라인, 소개, 측정 약속 표(지표·방법·시점). 배지로 ‘보장·단정 표현 0건’, ‘측정 약속 n/n’.
- **사람 확인 장치** — ‘사람이 최종 문구를 확인했어요’를 체크하고 걸린 표현이 0건일 때만 제안서 복사. 문구를 다시 만들면 체크가 풀린다.
- **제안서 복사 · 인쇄**, 샘플로 되돌리기.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `trainingfollowup.copy` → 형식 검사 → AI 문구에도 보장·단정 표현이 있으면 통째로 버림 | `Claude로 작성 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 고른 구성의 지표로 측정 약속 문구를 만들고, 초안의 걸린 문장을 측정 약속으로 바꿈 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 / 보장 표현이 있음 | 버리고 규칙 문구 유지 | `규칙 기반 · 응답 형식이 맞지 않거나 보장 표현이 있음` |
