# 이수함 — 사내 교육 신청 · 출결 자동 취합

> 신청 목록과 QR 출석 기록을 붙여 넣으면 **사번 기준으로** 합쳐 회차별 출결 · 이수 여부 · 결과 보고 문장까지 만드는 도구

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘출결은알아서’)** 의 예시 프로젝트입니다. 가상의 회사 ‘온결물산’의 교육 1과정(4회차, 17명) 샘플로 동작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 교육마다 신청 메일 · 출석부 · 이수 현황을 손으로 맞추느라 **회차당 3시간** | 두 표를 붙여 넣고 ‘취합’ → **회차당 30분** (목표치), 연 40회 교육에 적용 |
| 이름으로 맞추다 **동명이인이 한 사람으로 합쳐짐** | **사번 기준**으로 합친다. 이름이 같아도 사번이 다르면 다른 사람 (`동명` 표시) |
| 출석부에 사번이 빠진 줄을 어떻게 볼지 매번 고민 | 같은 이름이 한 명이면 연결하고 표시, **둘 이상이면 합치지 않고 ‘확인 필요’** — 사람이 고른다 |
| QR을 두 번 찍거나, 신청 없이 오거나, 이름을 잘못 쓴 기록 | 두 번 찍힘은 한 번으로, 나머지는 ‘확인 사항’ 칸에 표시 |
| 결과 보고 문장을 매번 새로 씀 | 집계 숫자로 3문장 + 후속 조치를 바로 만든다 |

> 리드 빌더 ‘엑셀탈출’ 코멘트 — “사번이라는 기준 하나로 데이터가 깔끔해졌죠. 기본을 지킨 자동화입니다.”

## 주요 기능

- **사번 기준 취합** — `m21-045`, `M21 045`도 같은 사번으로 읽는다. 같은 사번 중복 신청은 한 명으로.
- **동명이인 비교** — “이름으로 합쳤다면 신청자를 16명으로 셌을 것을 사번으로 17명으로 셌습니다.”
- **확인 필요 연결** — 사번 없는 출석을 후보 중에서 골라 연결(그 회차에 이미 출석한 후보는 뒤로, 표시). 되돌리기 가능.
- **이수 기준 · 지각** — 전 회차 / 75% / 50% 기준을 바꾸면 바로 다시 계산. 시작 10분 뒤 입실은 지각(△, 출석으로 셈).
- **거르기 · 내보내기** — 전체 / 미이수 / 확인 표시, CSV 내려받기(사번 가림, 엑셀용 BOM), 미이수자 안내 문구 복사.
- **샘플로 되돌리기** — 입력·설정·직접 연결을 처음 상태로 (되돌리기 가능). 작업 중인 내용은 브라우저에 저장.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | 집계 숫자(이름·사번 없음)를 `trainattend.report`로 보내 보고 문장을 받음 → 숫자 검산 통과 시 교체 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 아직 없는 작업 | 규칙 문장 틀로 3문장 + 후속 조치 | `규칙 기반 · (이유)` |
| 응답 형식이 틀리거나 집계에 없는 숫자가 들어 있음 | 버리고 규칙 문장 유지 | `규칙 기반 · 응답 숫자가 집계와 다름` |

출결 판단(누가 출석·이수했는지)은 AI가 하지 않습니다. 사번으로 맞추는 규칙만 씁니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 (작업 정의: [docs/ai-task.json](docs/ai-task.json)) |
