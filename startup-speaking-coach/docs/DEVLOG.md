# 말해봄 개발 일지 (창업 트랙 2~4주차)

> **1기 목표 모델**: 가상의 수강생 ‘스피킹메이트’(영어 회화 튜터 6년 차)가 이렇게 진행하는 것을 목표로 쓴 일지입니다. 실제 수강생의 기록이 아닙니다.
> 숫자는 COVI 학습 기록 기준이며, 포트폴리오에 적은 합계와 같습니다.

| 시기 | 만든 것 | 프롬프트 | 디버깅 | 시간 |
|---|---|---|---|---|
| 2주차 후반 | 숙제 화면, 녹음하며 받아쓰기, 직접 입력 | 12 | 3 | 2.5h |
| 3주차 전반 | 규칙 첨삭기 (실수 패턴 11개, 측정값) | 14 | 2 | 3.0h |
| 3주차 후반 | Claude 첨삭 + 형식 검사, **고칠 점 2개 제한** | 16 | 3 | 3.0h |
| 4주차 | 다시 말하기 확인, 튜터 화면, 테스트 | 13 | 2 | 2.5h |
| **합계** | | **55** | **10** | **11h** |

## 2주차 후반 — 숙제를 ‘내기 쉽게’

**한 일**
- 수업 사이 6일 동안 학생이 말하게 하는 게 목표. 녹음 파일을 받아 듣는 대신, 브라우저가 받아쓴 문장을 받기로 했다.
- Web Speech API로 영어 받아쓰기 + 말한 길이 재기.

**막힌 것 → 해결**
- 일부 브라우저에는 음성 인식이 없음 → 버튼을 끄고 이유를 보여 주고, 받아쓴 문장 직접 입력(휴대폰 키보드 받아쓰기도 가능)으로 같은 흐름.
- 마이크 권한을 거절하면 아무 반응이 없음 → `onerror`의 `not-allowed`를 잡아 안내 문구로.
- 말하는 중 화면에 글자가 두 번씩 쌓임 → 매번 결과 전체를 다시 이어 붙이도록 바꿈.

---

## 3주차 전반 — 규칙 첨삭기

**한 일**
- 지난 6년 수업 노트에서 자주 고쳐 준 실수 11개를 규칙으로: 과거 시제, bored/boring, I am agree, he don't, since 5 years, people is, enjoy to, more better, have went, discuss about, very like.
- 측정값: 단어 수, 분당 단어, um·uh, 목표 표현 사용 여부.

**막힌 것 → 해결**
- “I go to school every day.”까지 과거형으로 고치라고 함 → 지난 일 표현(yesterday, last …, ago)이 나온 뒤에만 과거 시제를 보게 하고, `I think`·`every`가 나오면 끔.
- um·uh를 단어 수에 세서 분당 단어가 부풀려짐 → 단어 수에서 뺌.

---

## 3주차 후반 — 첨삭이 너무 많았다

**한 일**
- `speakingcoach.feedback`으로 Claude가 문맥까지 보고 첨삭.
- 베타 학생 8명에게 2주 써 보게 했더니, 실수를 전부 보여 준 첨삭(평균 6~7개)을 받은 학생이 다음 숙제를 안 냈다. “빨간 줄이 너무 많아서 말하기가 무서워졌다”는 말을 들었다.
- **한 번에 고칠 점을 2개로 제한**했다. 찾은 실수를 뜻이 달라지는 것 → 반복된 것 → 먼저 나온 것 순으로 줄 세우고 위의 2개만 학생에게 보낸다. 나머지는 튜터만 보는 ‘다음 숙제에서 볼 것’으로 미룬다.

**막힌 것 → 해결**
- 지시문에 “2개만”이라고 써도 3~4개를 줄 때가 있음 → 화면 검사(`normalizeFeedback`)에서 한 번 더 2개로 자름. 테스트 추가.
- 학생이 말하지 않은 표현(“I goed”)을 지적함 → `wrong`이 받아쓴 문장에 없으면 버리고, 전부 그렇다면 응답을 버리고 규칙 결과를 씀.
- 같은 과거 시제 실수 3개가 고칠 점 3칸을 다 차지함 → 규칙별로 묶어 ‘같은 실수 2번’으로 한 칸에.

---

## 4주차 — 고쳤는지까지

**한 일**
- 고칠 점 2개만 바꾼 ‘다시 말하기 대본’ → 다시 말한 문장으로 ‘고침 / 아직’ 확인.
- 튜터 화면: 제출률, 미제출·다시 말하기 전 거르기, 미제출 알림 문구 복사.
- 로직을 `logic.js`로 분리하고 테스트 12개.

**막힌 것 → 해결**
- 카톡으로 첨삭을 복사할 때 학생이 말한 전화번호가 그대로 나감 → 복사 전에 전화번호·메일 가리기(`maskPii`).
- 대본에 고친 표현의 첫 글자가 소문자로 들어감 → 원문 대소문자를 따라가게(`keepCase`).

**결과 (1기 목표치)**
- 유료 수강생 41명(월 3만 원), 숙제 제출률 35% → 78%
