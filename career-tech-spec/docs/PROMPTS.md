# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버에 합칠 원문([ai-task.json](ai-task.json))입니다.

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 5주 | 테이블 제안 | 스터디 모임 출석·과제 앱이야. 화면은 로그인, 스터디 목록·만들기·상세, 출석 체크, 과제 제출, 피드백 7개. Postgres 테이블과 컬럼을 제안해 줘. |
| 5주 | 줄이기 | 화면마다 쓰는 테이블 목록이 있어. 아무 화면도 쓰지 않는 테이블은 빼고, 남은 테이블이 FK로 참조하는 테이블은 끝까지 따라가서 남기는 함수를 만들어 줘. 뺀 이유도 같이. |
| 6주 | API | API마다 쓰는 테이블을 적어 둘게. 남은 테이블만 쓰는 API만 걸러 주고, 화면마다 API가 하나도 없으면 체크리스트에서 잡아 줘. |
| 6주 | 체크리스트 | 설계 리뷰 체크리스트를 자동 항목(화면 사용, FK 대상, 화면별 API, snake_case 복수형)과 사람이 체크할 항목(개인정보 접근, 팀원 확인)으로 나눠 줘. |
| 6주 | 근거 검사 | Claude가 쓴 판단 근거에서 표에 없는 테이블이나 우리 결정과 반대인 문장(뺀 걸 남기자는 것)은 버리고, 남는 게 없으면 null을 돌려줘. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

공통 꼬리말: `모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.`

### techspec.reasons
```
캡스톤 프로젝트 기술 설계서의 '판단 기록'을 쓴다. input.decisions에는 테이블마다 이미 정해진 결정
(keep: 남김 true, 뺌 false)과 규칙 근거가 있다. 결정은 바꾸지 않는다. reasons에는 decisions의 테이블마다
table(이름 그대로), keep(input과 같은 값), why(그 결정의 근거 한 문장: 남긴 것은 어느 화면의 어떤 동작에
필요한지, 뺀 것은 왜 지금 화면에 필요 없는지와 나중에 필요해지는 조건)를 쓴다. summary는 전체 구조를 한
문장으로. risks는 남긴 테이블에서 팀이 미리 정해 둘 점(상태 값, 삭제 규칙, 개인정보 접근 등) 최대 3개.
input에 없는 화면·테이블·컬럼을 지어내지 않는다. 개인정보 처리의 적법성은 판단하지 않고 사람이 확인할
점으로만 적는다.
출력 형식: {"summary":"","reasons":[{"table":"","keep":true,"why":""}],"risks":[""]}
```
- 입력: `{ project, screens: [{ name, uses }], tables: [{ name, purpose, columns, refs }], decisions: [{ table, keep, rule }] }` · 최대 1,200토큰
- 화면 검사: `normalizeReview()` → 표에 없는 테이블, `keep`이 결정과 다른 문장은 버림. 기다리는 사이 표가 바뀌었으면 응답 전체를 버림

## 3. 왜 이렇게 썼나

- **결정은 이미 내려서 보낸다.** 처음엔 “이 테이블들 중 필요한 것만 골라 줘”라고 했더니 부를 때마다 결과가 달랐다. 남기고 빼는 것은 화면 기준 규칙으로 정하고, AI에게는 근거 문장만 맡겼다. 같은 표면 같은 결정이 나온다.
- **`keep`을 돌려받는다.** AI가 결정을 슬쩍 뒤집었는지 화면에서 확인할 수 있다.
- **개인정보는 사람에게.** 이메일·이름 컬럼의 접근 범위는 팀과 지도교수가 확인한다. AI는 “확인할 점”으로만 적는다.

## 4. 실패했던 이전 버전

| 버전 | 지시문 | 무엇이 틀렸나 |
|---|---|---|
| v1 | “화면 목록을 보고 필요한 테이블을 설계하고, 각 테이블이 왜 필요한지 설명해 줘.” | 13개 테이블에 전부 그럴듯한 이유가 붙어 왔다(“알림은 사용자 경험 향상에 필요”). 화면에 없는 기능을 이유로 들었고, 부를 때마다 개수가 11~15개로 달랐다. |
| v2 | 위 지시문 (결정은 규칙으로, AI는 근거만 · keep 돌려받기 · 지어내지 않기) | 근거가 화면 이름과 동작으로 쓰이고, 결정은 흔들리지 않는다. |
