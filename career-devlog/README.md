# 커밋일지

> 팀의 깃허브 커밋·PR·이슈를 모아 **주간 개발 일지**를 써 주는 도구. 공개할 저장소만 골라서, 비공개 저장소 내용은 일지에 섞이지 않습니다.

> **알림** AI 빌더랩 커리어 트랙 **1기 목표 모델(가상의 수강생 ‘커밋하는곰’)** 의 예시 프로젝트입니다. 팀원·저장소·커밋은 모두 가상이며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 팀 회고 때마다 누가 뭘 했는지 기억이 안 나 커밋을 다시 뒤졌다 | 한 주 활동을 사람별로 묶은 일지가 자동으로 써진다 → **회고 준비 1시간 → 10분 (목표)** |
| AI 요약에 인턴 회사·연구실 같은 **비공개 저장소 내용이 섞였다** | 저장소마다 `내용 포함 · 건수만 · 제외`를 고르는 설정. 비공개는 ‘내용 포함’을 고를 수 없고, 설정에 없는 저장소는 자동 제외 |
| 커밋 메시지에 메일 주소·토큰이 섞여 있었다 | 내보내기 전에 메일·토큰·내부 주소·IP·전화번호를 가린다 |
| 일지가 한 번 쓰고 끝났다 | 주마다 쌓여서 **8주 일지**를 거슬러 볼 수 있다 |

## 주요 기능

- **내보낼 저장소** — 공개 저장소는 내용 포함, 비공개는 건수만 또는 제외. 바꾸면 일지가 바로 다시 써지고 되돌리기가 됩니다.
- **내보내지 않은 것 안내** — 이번 주에 뺀 저장소·건수와 가린 곳을 일지 위에 보여 주고, 내보낼 마크다운에 비공개 저장소 이름이 0곳인지 확인 표시를 붙입니다.
- **쌓인 일지 8주** — 주를 고르면 그 주 일지로 바뀝니다. 막대는 주별 공개 활동 건수입니다.
- **사람별 보기 · 마크다운 보기** — 한 사람만 골라 볼 수 있고, 마크다운 그대로 확인할 수 있습니다.
- **복사 · .md 내려받기** — 노션이나 깃허브 위키에 붙여 넣는 형식입니다.
- **원본 활동 기록** — 샘플 활동(`날짜 저장소 @이름 내용`)을 고쳐 ‘다시 읽기’를 누르면 결과가 바뀝니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | ‘내용 포함’ 저장소의 **가린 뒤의 줄만** `devlog.summary`로 보냄 → 응답 검사 → 사람별 한 일 덮어쓰기 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 서버에 작업 없음 | 커밋 종류(feat·fix…)와 사람별로 묶는 규칙 일지 | `규칙 기반 · (이유)` |
| 응답에 비공개 저장소 이름, 입력에 없는 사람, 가렸던 메일·토큰이 있음 | 통째로 버리고 규칙 일지 유지 | `규칙 기반 · 응답 검사에서 걸러짐` |

비공개 저장소의 줄은 Claude에게도 보내지 않습니다. 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버에 합칠 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 실제 버전 | 이 데모 |
|---|---|---|
| 활동 수집 | GitHub API(커밋·PR·이슈), 주 1회 GitHub Actions로 실행 | 샘플 활동 기록(텍스트) |
| 요약 | Claude API — 서버 `aibuilderlab.kr/api/demo/ai` | 같음 |
| 결과 | Markdown 파일을 저장소 `devlog/`에 주마다 커밋 | 화면 · 복사 · .md 내려받기, 설정은 localStorage |
| 테스트 | Node 내장 `node:test` | 같음 |
