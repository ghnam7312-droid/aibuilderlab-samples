# 광고한장

> 광고 채널 4곳의 성과를 **‘전환’ 기준부터 맞춘 뒤** 합산해, 주간 리포트 한 장(핵심 숫자 · 채널별 표 · 요약 · 메일 본문)으로 만드는 도구

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘보고서는자동’ · 마케팅팀 주임)** 의 예시 프로젝트입니다. 가상의 생활용품 쇼핑몰 ‘하루살림’과 가상의 광고 채널 4곳의 2주치 숫자로 동작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 광고 채널 4곳의 성과를 매주 내려받아 붙여 넣느라 월요일 오전이 사라졌다 | 채널 원본만 넣으면 리포트 한 장 → **주간 리포트 3시간 → 20분 (목표치)** |
| 채널마다 ‘전환’ 기준이 달라 합계가 틀렸다 (장바구니 · 회원가입 · 본 뒤 구매까지 섞임) | **전환 기준표**로 채널 × 사건을 맞춘 뒤 합산. 채널 보고 합계 946건 → 기준 합계 364건을 나란히 보여 줌 |
| 기준을 바꾸면 어느 채널이 자료가 없는지 몰랐다 | 기준에 있는데 채널 파일에 없는 사건은 ‘자료 없음’ 경고 |
| 매주 요약 문장을 새로 썼다 | Claude가 3문장 + 다음 주 할 일을 쓰고, **문장 속 숫자를 리포트 숫자와 대조** |
| 바쁜 주에는 발행을 빠뜨렸다 | 발행 기록과 연속 주 수 → **8주 연속 자동 발행 (목표치)** |

## 주요 기능

- **전환 기준표** — 위의 체크박스로 리포트 기준(기본: 클릭 후 구매)을 고르면, 칸마다 ‘셈 · 뺌 · 없음’이 칠해지고 숫자가 바로 다시 계산됩니다. 바꾼 기준은 되돌리기 가능.
- **채널 원본 고치기** — 채널 탭에서 이번 주 숫자를 고치면 리포트가 즉시 바뀝니다. 빈 칸 · 음수 · 클릭>노출 · 구매>클릭은 빨간 칸으로 알리고 발행을 막습니다.
- **리포트 한 장** — 광고비 · 기준 전환 · CPA · ROAS와 지난주 대비, 채널별 표(채널 보고 전환은 지운 선으로), CPA 최저/최고 표시.
- **요약** — 규칙 요약이 즉시 나오고, Claude 요약이 오면 덮어씁니다. 숫자를 고치면 Claude 요약은 낡은 것이 되므로 규칙 요약으로 돌아갑니다.
- **내보내기** — 메일 본문 복사, 채널별 표 CSV(엑셀용 BOM 포함), 인쇄(리포트만).
- **발행 기록** — 최근 8주 발행 여부와 연속 주 수. 같은 주는 한 번만 발행됩니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `adweekly.summary` → 형식 검사 → 문장 속 숫자를 리포트 숫자와 대조 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 정해진 문장 틀에 숫자를 넣는 규칙 요약 | `규칙 기반 · (이유)` |
| 응답 형식이 틀리거나 데이터에 없는 숫자가 나옴 | 버리고 규칙 요약 유지 | `규칙 기반 · 응답에 데이터 밖 숫자 · 형식 오류` |
| 원본 숫자에 오류가 있음 | Claude에 보내지 않음 | `규칙 기반 · 원본 숫자 오류` |

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
