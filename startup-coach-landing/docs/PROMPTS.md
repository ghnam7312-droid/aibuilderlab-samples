# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 `docs/ai-task.json`의 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 4개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 6주 | 상품 구성 | 1회 상담 8만 원 옆에 4주 패키지를 만들고 싶어. 회차·가격·포함 항목을 바꾸면 회당 가격과 1회 상담 N번 금액을 비교해 주는 화면. |
| 6주 | 실험 판단 | A/B 방문 수와 신청 수로 전환율, 차이, p값을 계산하고, 안마다 300명이 안 되면 판단을 미루는 함수를 만들어 줘. |
| 7주 | 과장 검사 | 랜딩 문구에서 합격 보장, 100%, 누구나, 업계 최고, 연봉 N배, N주 만에 합격 같은 표현을 찾아서 칸별로 알려 줘. |
| 7주 | 후기 교체 | 과장으로 걸린 항목은 게시 동의한 실제 후기로 바꾸고, 제목·버튼은 회차·가격 같은 사실 문장으로. 후기가 모자라면 그 줄은 빼. |

## 2. 서비스가 쓰는 지시문 (`coachlanding.copy`)

```
커리어 코칭 '직무 전환 패키지' 랜딩 페이지 문구를 쓴다. input.product·sessions·price·perSession·single·
includes는 상품 정보, input.reviews는 게시 동의를 받은 실제 후기(who, text)다. headline은 25자 이내로
패키지가 무엇을 하는지(과정)를 말한다. sub는 회차·가격·회당 가격을 input 값 그대로 넣은 한 문장.
bullets는 3~4개: includes에서 2~3개, reviews가 있으면 그중 하나를 '“후기 원문” — who' 형식으로
글자 그대로 옮긴다. cta는 12자 이내 신청 버튼 문구. 합격·취업·이직·연봉 결과를 보장하거나 약속하지
않고, '100%', '누구나', '무조건', '최고', '1위' 같은 확인할 수 없는 표현과 'N주 만에 합격' 같은 기간
약속을 쓰지 않는다. input에 없는 후기·숫자·경력은 만들지 않는다. 모든 문장은 한국어로, 짧고 구체적으로
쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"headline":"","sub":"","bullets":[""],"cta":""}
```
- 입력: `{ product, sessions, price, perSession, single, includes, reviews }` — 후기는 동의한 것만, 이름은 성만 · 최대 600토큰
- 화면 검사: `normalizeCopy()` (형식) → `cleanCopy()` (과장 교체) → `publishCheck()` (게시 전 확인)

## 3. 왜 이렇게 썼나

- **결과 대신 과정** — 코치가 약속할 수 있는 것은 4주 동안 함께 하는 일이지 합격이 아니다.
- **금지 표현을 구체적으로** — “과장하지 마”만으로는 ‘누구나’, ‘업계 최고’가 남았다.
- **후기는 글자 그대로** — 고쳐 쓴 후기는 더 이상 실제 후기가 아니다. 동의한 후기만 input으로 보낸다.

## 4. 실패했던 이전 버전

```
직무 전환 코칭 4주 패키지 랜딩 문구를 전환율 높게, 임팩트 있게 써 줘. 과장하지 마.
```
- 결과: “4주 만에 합격 보장! 직무 전환 코칭”, “100% 맞춤 코칭으로 누구나”, “업계 최고의 HR 출신 코치”, “연봉 2배 상승 사례 다수”, 버튼 “지금 바로 합격하기”.
- 고친 것: 과정 중심 지시, 금지 표현 명시, 실제 후기 원문 사용 + 화면 과장 검사 · 교체.
