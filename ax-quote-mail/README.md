# 견적함 — 거래처 메일 자동 분류

> 아침마다 쌓이는 거래처 메일을 **분류함에 나눠 담고, 견적 요청만 골라 진행표로** 정리하고, **회신 초안까지** 써 주는 도구

![견적함 화면](screenshot.png)

**데모** https://aibuilderlab.kr/demo/ax-quote-mail/index.html

> AI 빌더랩 직장인 AX 트랙 **1기 목표 모델 예시**입니다. 가상의 거래처 메일 16통으로 동작하고, 등장하는 회사·사람·메일 주소는 모두 가상입니다.

## 문제 → 해결

| 전에는 | 이제는 |
|---|---|
| 매일 거래처 메일 30통을 다 읽고 견적 요청만 엑셀에 옮김 (**1시간**) | 버튼 한 번에 분류, 애매한 메일만 사람이 확인 (**20분**) |
| 품목·수량·납기를 손으로 옮겨 적음 | 본문에서 뽑아 **견적 진행표**에 올림 |
| 회신 메일을 매번 처음부터 씀 | 받은 품목·납기를 확인하는 **회신 초안**을 바로 만듦 (단가는 쓰지 않음) |
| 급한 견적을 놓침 | 납기가 7일 안이면 빨간색 **D-day** |

## AI는 어디에, 어떻게

| 단계 | Claude가 하는 일 | Claude가 안 될 때 |
|---|---|---|
| 분류 | `mail.classify` — 분류·확신(0~1)·근거·품목 | 단어 점수 규칙 (제목 2점, 본문 1점) |
| 사람에게 넘기기 | **확신 60% 미만이면 ‘확인 필요’** | 1·2등 점수 차이 1점 이하 |
| 회신 초안 | `mail.reply` — 품목·납기 확인, 회신 일정, 확인할 점 | 같은 내용을 채우는 규칙 템플릿 |

- 분류하면 **규칙으로 먼저 즉시 나누고**, Claude 답이 오는 대로 카드가 제자리로 옮겨 갑니다. AI를 기다리느라 화면이 멈추지 않아요.
- 카드마다 `AI 84%`처럼 확신이 붙고, 자세히 보기에서 **Claude의 판단 근거**와 **규칙 점수**를 나란히 볼 수 있어요.
- 화면 오른쪽 위 표시가 지금 상태를 알려 줍니다: `Claude 연결됨` / `규칙 모드`. 어느 쪽으로 판단했는지는 진행표 CSV에도 남아요.
- 키가 서버에만 있고 브라우저에는 없습니다. 지시문과 출력 형식도 서버가 가지고, 화면은 작업 이름과 메일만 보냅니다.

## 주요 기능

- **분류하기** — 받은 편지함의 메일이 5개 분류함(확인 필요 · 견적 요청 · 발주·주문 · 문의 · 기타)으로 날아가 들어감
- **확인 필요** — 추천 분류를 누르거나 `E`로 확정
- **키보드로 분류** — `J`/`K` 이동, `1`~`4` 분류, `E` 추천 확정, `R` 회신 초안, `?` 도움말
- **자세히 보기** — 근거 단어를 분류 색으로 칠한 본문, Claude 판단 카드(확신 막대·근거·뽑은 품목), 규칙 점수
- **회신 초안** — 편집 가능한 제목·본문, 복사, 메일 앱에서 열기(`mailto:`), 다시 쓰기. 쓰면 진행 상태가 ‘작성 중’으로 바뀜
- **견적 진행표** — 거래처·담당자·품목·수량·납기·진행 상태, 칸 수정, 판단 주체(사람/Claude/규칙)까지 CSV로
- **새 메일 넣어 보기** — 입력하는 동안 규칙 미리 보기, 넣으면 Claude가 다시 읽음
- **되돌리기** — 분류 확정·삭제·초기화를 알림에서 되돌림

## 화면 구성

```
┌ 받은 편지함 ┐┌ 확인 필요 ┬ 견적 요청 ┬ 발주·주문 ┬ 문의 ┬ 기타 ┐   ● Claude 연결됨
│ 메일 16통   ││ ▧ 애매함  │ ▮ AI 84% │ ▮ AI 93%  │      │      │
│ [분류하기]  ││ [견적 E]  │ ▮ AI 86% │           │      │      │
└────────────┘└──────────┴──────────┴───────────┴──────┴──────┘
┌──────── 견적 진행표 · 회신 초안 · CSV ────────┐   ┌ 자세히 보기 서랍 ┐
```

## 기술 스택

| 이 데모 | 실제 업무 버전 |
|---|---|
| HTML · CSS · JavaScript (빌드 없음) | 메일함 연동 (IMAP/Gmail API) |
| Claude API (`aibuilderlab.kr/api/demo/ai` 경유) + 규칙 대체 | 같은 분류·회신 로직 |
| Web Animations API(FLIP)로 카드 이동, localStorage 저장 | 팀 공용 진행표 (스프레드시트) |
| `node --test` 단위 테스트 14개 | |

## 폴더 구조

```
ax-quote-mail/
├── index.html          화면 뼈대
├── style.css           우편 분류함 스타일
├── logic.js            분류 규칙 · AI 응답 검증 · 품목/납기 추출 · 회신 템플릿 · CSV (순수 함수)
├── ai-client.js        Claude 호출 + 실패하면 null (화면이 규칙으로 처리)
├── app.js              화면: 카드 이동(FLIP), 키보드 분류, 서랍, 진행표
├── tests/logic.test.js 단위 테스트
├── docs/               개발 일지 · 프롬프트 기록 · 구조
├── CHANGELOG.md
└── package.json        npm test
```

## 실행 · 테스트

```bash
python3 -m http.server 8000   # → http://localhost:8000/
npm test                      # 또는 node --test (Node 18 이상, 설치할 것 없음)
```

로컬에서 열어도 AI 호출은 `aibuilderlab.kr` 서버로 갑니다. 서버에 키가 없거나 한도를 넘으면 규칙으로 동작해요.
