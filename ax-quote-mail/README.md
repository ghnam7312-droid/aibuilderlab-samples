# 견적함 — 거래처 메일 자동 분류

> 아침마다 쌓이는 거래처 메일을 **분류함에 나눠 담고, 견적 요청만 골라 진행표로** 정리하는 도구

![견적함 화면](screenshot.png)

**데모** https://aibuilderlab.kr/demo/ax-quote-mail/index.html

> AI 빌더랩 직장인 AX 트랙 **1기 목표 모델 예시**입니다. 가상의 거래처 메일 16통으로 동작합니다.

## 문제 → 해결

| 전에는 | 이제는 |
|---|---|
| 매일 거래처 메일 30통을 다 읽고 견적 요청만 엑셀에 옮김 (**1시간**) | 버튼 한 번에 분류, 애매한 메일만 사람이 확인 (**20분**) |
| 품목·수량·납기를 손으로 옮겨 적음 | 본문에서 자동으로 뽑아 **견적 진행표**에 올림 |
| 급한 견적을 놓침 | 납기가 7일 안이면 빨간색 **D-day** 표시 |

## 주요 기능

- **분류하기** — 받은 편지함의 메일이 5개 분류함(확인 필요 · 견적 요청 · 발주·주문 · 문의 · 기타)으로 날아가 들어감
- **분류 규칙 (데모: 브라우저 규칙 기반)**
  - 분류별 단어 점수: 제목에 있으면 2점, 본문에만 있으면 1점
  - 1등과 2등 점수 차이가 1점 이하 → **확인 필요** (사람이 정함)
  - 끝인사만 있는 줄(“감사합니다.”)은 점수에서 제외 — 거의 모든 메일이 ‘기타’로 끌려가던 문제를 고친 규칙
- **확인 필요 카드** — 추천 분류 두 개를 바로 눌러 확정, 카드가 해당 분류함으로 이동
- **자세히 보기** — 본문에서 근거 단어를 분류 색으로 칠하고, 분류별 점수 막대와 판단 이유를 보여 줌
- **견적 진행표** — 거래처·담당자·품목·수량·납기, 진행 상태(견적 작성 전 → 작성 중 → 발송 완료), 칸 수정, CSV 내려받기
- **새 메일 넣어 보기** — 입력하는 동안 분류 미리 보기, 빈 칸 검증, 넣으면 해당 분류함으로 이동
- **되돌리기** — 분류 확정·메일 삭제·초기화를 알림에서 되돌림

## 화면 구성

```
┌ 받은 편지함 ┐┌ 확인 필요 ┬ 견적 요청 ┬ 발주·주문 ┬ 문의 ┬ 기타 ┐
│ 메일 16통   ││ ▧▧▧      │ ▮ A4 용지 │ ▮ 발주서  │      │      │
│ [분류하기]  ││ [견적][문의]│ ▮ 의자    │           │      │      │
└────────────┘└──────────┴───────────┴──────────┴──────┴──────┘
┌──────────────── 견적 진행표 (CSV) ────────────────┐
```

## 기술 스택

| 이 데모 | 실제 업무 버전 |
|---|---|
| HTML · CSS · JavaScript (프레임워크 없음) | 메일 분류 · 사람 확인 · 자동 표 |
| 규칙 기반 분류 (외부 AI 호출 없음) | 메일함 연동 |
| Web Animations API로 카드 이동 효과, localStorage 저장 | |
