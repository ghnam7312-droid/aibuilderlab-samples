# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버에 합칠 원문([ai-task.json](ai-task.json))입니다.

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 1주 | 시간표 | 장비 6대를 행, 09~21시를 30분 칸으로 한 시간표를 만들어 줘. 빈 칸을 누르면 예약 폼이 그 장비·시간으로 채워지고, 예약은 막대로 보여 줘. |
| 1주 | 검사 | 예약 저장 전에 검사하는 함수를 만들어 줘. 지난 날짜·지난 시간, 09~21시 밖, 30분 단위 아님, 4시간 초과, 이름 없음. 오늘 날짜는 인자로 받아서 테스트할 수 있게. |
| 2주 | 버그 재현 | 두 사람이 같은 시간을 동시에 예약하면 둘 다 저장되는 버그가 있어. 고치기 전에, 둘이 같은 시점의 데이터로 ‘비어 있음’을 확인하고 둘 다 저장하는 상황을 재현하는 테스트부터 써 줘. |
| 2주 | DB 제약 | Supabase bookings 테이블에서 같은 장비의 시간 구간이 겹치면 저장이 거절되게 해 줘. 취소한 예약은 빼고. 거절되면 프론트에서 어떤 오류 코드로 알 수 있는지도. |
| 2주 | 응답 검사 | Claude가 돌려준 예약 칸에서 장비가 목록에 없거나 날짜가 YYYY-MM-DD가 아니면 그 칸만 비우고, 장비·날짜·시작이 다 비면 null을 돌려줘. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

공통 꼬리말: `모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.`

### labbooking.parse
```
실험실 장비 예약 요청 문장 하나를 예약 칸으로 바꾼다. equipment는 input.equipment 목록의 id 중 하나
(이름·별칭으로 찾는다, 없으면 빈 문자열). date는 YYYY-MM-DD로, input.today와 input.weekday를 기준으로
'내일', '금요일', '다음 주 화요일' 같은 표현을 날짜로 바꾼다. start·end는 24시간 HH:MM이고, 실험실은
09:00~21:00만 열므로 오전·오후가 없는 '2시'는 14:00으로 본다. '3시간'처럼 길이만 있으면 start에 더해
end를 만든다. purpose는 문장에 적힌 용도만 짧게. 문장에 없는 장비·날짜·시간은 지어내지 말고 빈 문자열로
두며, 애매한 점은 unclear에 한 문장으로 적는다. 안전교육 이수 여부나 사용 허가는 판단하지 않는다.
출력 형식: {"equipment":"","date":"YYYY-MM-DD","start":"HH:MM","end":"HH:MM","purpose":"","unclear":""}
```
- 입력: `{ text, today, weekday, equipment: [{ id, name, alias }] }` (문장 300자까지) · 최대 300토큰
- 화면 검사: `normalizeParse()` → 통과한 칸만 덮어쓰고, 빈 칸은 노란색으로 “직접 골라 주세요”

## 3. 왜 이렇게 썼나

- **id로 고르게 했다.** 장비 이름은 “SEM”, “전자현미경”, “주사전자현미경”처럼 여러 가지로 불린다. 이름을 그대로 돌려받으면 화면에서 다시 맞춰야 하므로, 목록의 id 중 하나를 고르게 하고 없으면 비운다.
- **오늘 날짜와 요일을 함께 보낸다.** ‘금요일’을 날짜로 바꾸려면 기준이 있어야 한다.
- **허가는 판단하지 않는다고 적었다.** 안전교육 이수 확인은 실험실 관리자의 일이다. AI가 “이수자로 보임” 같은 말을 붙이지 않게 했다.

## 4. 실패했던 이전 버전

| 버전 | 지시문 | 무엇이 틀렸나 |
|---|---|---|
| v1 | “예약 문장에서 장비, 날짜, 시간을 뽑아 줘.” | 장비가 “SEM 장비”, 날짜가 “내일”, 시간이 “오후 2시~3시간”처럼 글자로 와서 칸에 넣을 수 없었다. 문장에 없는 용도를 “시료 분석”으로 지어내기도 했다. |
| v2 | 위 지시문 (id 목록 · 날짜 형식 · 운영 시간 · 지어내지 않기) + 화면 검사 | 칸에 바로 들어가고, 모르는 칸은 비어서 사람이 고른다. |
