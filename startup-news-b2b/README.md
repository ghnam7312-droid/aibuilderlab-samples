# 팀한장

> 뉴스레터를 회사 단위로 팔 때 **인원 구간별 요금**을 설계하고, 인터뷰한 물류사마다 견적과 제안 메일을 만드는 도구

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘업계한장’)** 의 예시 프로젝트입니다. 회사·담당자·인터뷰 내용·금액은 모두 가상이며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 개인 구독만으로는 매출이 작았다 | 물류사 5곳을 인터뷰하고, 회사 단위 요금과 견적을 한 화면에서 |
| **‘팀 전체 무제한’으로 가격을 낮게 잡음** (85명 회사도 월 49,000원 = 인당 576원) | **인원 구간별 요금**으로 수정. 1~5명 기본료, 6명부터 구간마다 인당 요금을 더한다 |
| 구간 경계에서 한 명 늘었는데 더 싸지는 요금표 | 구간 점검이 ‘절벽’을 찾아 알림. 곡선에 빨간 원으로 표시 |
| 회사마다 제안 메일을 새로 썼다 | 인터뷰 메모와 계산된 견적으로 제안 메일 초안. 계약 조건은 사람이 따로 안내 |

결과 (1기 목표치): **물류사 5곳 인터뷰, 기업 구독 2곳 계약**

## 주요 기능

- **요금 구간 편집** — 기본료·구간 끝 인원·인당 요금을 고치면 곡선, 회사별 견적, 계약 매출이 함께 바뀝니다. 되돌리기 가능.
- **두 계산 방식 비교** — 누적(권장)과 전체 적용. 전체 적용은 21명·51명에서 요금이 내려가는 절벽이 생기는 것을 바로 보여 줍니다.
- **구간 점검** — 뒤 구간이 앞보다 비싼지, 개인 구독(월 5,900원)보다 싸지 않은지, 절벽이 있는지.
- **회사별 견적** — 인원·단계를 바꾸면 월 요금, 인당, 개인 구독 대비, ‘무제한이었다면’ 차이가 바로 바뀝니다. 연 결제(2개월분 할인) 전환.
- **제안 메일** — 규칙 초안이 즉시, Claude 초안은 금액 검사를 거쳐. 견적이 바뀌면 오래된 초안이라고 알려 줍니다.
- **견적 CSV · 메일 복사 · 견적서 인쇄**

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `newsb2b.proposal` (계산된 숫자 + 인터뷰 메모만 보냄) → 금액 검사 → 계약 조건 문장 빼기 | `Claude로 작성 · 2.4초` |
| 금액·인원이 계산값과 다름 | 통째로 버리고 규칙 초안 유지 | `규칙 기반 · 금액이 계산과 다르거나 형식이 맞지 않음` |
| 해지·환불·위약금·세금계산서·개인정보 문장 | 빼고 ‘사람 확인 필요’로 표시 — 담당자가 직접 안내 | 노란 안내 |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 계산된 숫자로 쓰는 규칙 초안 | `규칙 기반 · (이유)` |

자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음), 요금 곡선은 SVG 직접 그리기 |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 기획 | 고객 인터뷰 메모 · 가격 구성 (데모는 메일을 보내거나 결제하지 않음) |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
startup-news-b2b/
├── index.html
├── style.css
├── logic.js          요금 계산(누적·전체 적용) · 절벽 찾기 · 구간 점검 · 견적 · 제안 규칙 · 응답 검사 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            요금 구간 · 회사 · 제안 메일 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```
