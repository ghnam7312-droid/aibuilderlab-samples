# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 [ai-task.json](ai-task.json)에 있는 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 4개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 5주 | 인터뷰 정리 | 물류사 5곳 인터뷰 메모야. 회사마다 볼 사람 수, 지금 공유 방식, 돈을 낼 이유와 망설이는 이유를 표로 정리해 줘. |
| 5주 | 가격 구성 | ‘팀 무제한 49,000원’이면 85명 회사는 인당 얼마야? 개인 구독 5,900원보다 싸되 인원이 늘면 금액도 느는 구간별 요금을 3안 만들어 줘. |
| 5주 | 절벽 검사 | 요금표를 넣으면 1~100명 중 한 명 늘었는데 요금이 줄어드는 인원을 찾아 줘. 누적 방식과 전체 적용 방식 둘 다. |
| 5주 | 제안 메일 | 회사·인원·견적·인터뷰 메모로 제안 메일 초안을 써 줘. 금액은 내가 계산한 값만, 계약 조건은 쓰지 마. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

### `newsb2b.proposal`
```
물류 뉴스레터 '아침한장'의 기업 구독 제안 메일을 쓴다. 받는 곳은 input.company, 받는 사람은 직함 input.contactRole로만 부른다. 인터뷰에서 들은 필요(input.need)와 말(input.interviewQuote)에 맞춰, 인원(seats)·월 요금(monthly)·인당 요금(perSeat)·개인 구독 요금(personalPrice)을 담고, annual이 true면 연 요금(yearly)도 담는다. 금액과 인원은 input 값만 쓰고 새로 계산하거나 할인을 만들지 않는다. 계약 조건(해지, 환불, 위약금, 세금계산서, 개인정보 처리, 약관)은 쓰지 않는다. 담당자가 따로 안내한다. questions는 고객에게 확인할 실무 질문 1~2개. input에 없는 사실은 만들지 않는다. 모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"subject":"","body":"","questions":[""]}
```
- 입력: `{ company, kind, contactRole, need, interviewQuote, seats, monthly, perSeat, personalPrice, annual, yearly }` · 최대 900토큰
- 화면 검사: `normalizeProposal()` — 본문 속 금액·인원이 계산값과 다르면 버림, 계약 조건 문장·질문은 빼고 ‘사람 확인 필요’로 표시

## 3. 왜 이렇게 썼나

- **금액은 input 값만, 새로 계산하거나 할인을 만들지 않는다** — 견적 메일의 숫자는 약속이 된다. 계산은 화면(`logic.js`)이 하고 Claude는 문장만 쓴다.
- **계약 조건은 쓰지 않는다** — 해지·환불·세금계산서·개인정보 처리는 회사 정책과 법적 판단이 들어가는 부분이라 AI가 정하지 않는다. 담당자가 확인해 따로 안내한다.
- **받는 사람은 직함으로만** — 인터뷰 메모에 담당자 이름을 남기지 않아서, 메일도 직함으로 부른다.
- **인터뷰에서 들은 말에 맞춰** — 같은 견적이라도 “인원이 늘 때마다 다시 계약하기 번거롭다”는 회사에는 구간 자동 반영을 먼저 말하게 된다.

## 4. 실패했던 이전 버전

```
우리 뉴스레터 기업 구독 제안 메일을 써 줘. {company}, {seats}명. 매력적으로, 할인 혜택도 넣어서.
```
- “할인 혜택도 넣어서” 때문에 없는 ‘첫 3개월 30% 할인’을 만들어 넣었다.
- “언제든 위약금 없이 해지 가능”처럼 정하지 않은 계약 조건을 약속했다.
- → 금액은 계산값만, 계약 조건 금지, 화면에서 금액 검사·계약 문장 빼기를 붙인 지금 버전으로 바꿨다.
