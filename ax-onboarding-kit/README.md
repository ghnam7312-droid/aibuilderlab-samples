# 첫주노트 — 신입 온보딩 자료 정리 · 팀 확산 계획

> 부서마다 다른 온보딩 자료에서 **개정일 기준 최신본만** 남기고, 신입 질문을 **공통 질문**으로 묶어 최신본에 연결하고, 부서별 **확산 계획**까지 한 화면에서 관리하는 도구

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘출결은알아서’)** 의 예시 프로젝트입니다. 가상의 회사 ‘온결물산’ 4개 부서의 자료 목록 22건 · 신입 질문 34건 샘플로 동작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 부서마다 온보딩 자료가 달라 **신입이 같은 질문을 반복**했다 | 질문을 뜻이 같은 것끼리 묶고, 2개 부서 이상에서 나온 것을 공통 질문으로 → **공통 질문 30개 정리** (목표치) |
| 모아 보니 **오래된 규정 문서가 섞여** 있었다 | 같은 문서끼리 묶어 **개정일이 가장 늦은 최신본만** 남긴다. 구버전은 이유와 함께 따로 보관 |
| 개정일이 안 적힌 문서는 최신인지 알 수 없음 | 자동으로 남기지 않고 ‘확인 필요’ — 담당자가 ‘최신본으로 인정’해야 쓴다 |
| 급여·계약 질문에 자료 링크를 잘못 주면 문제가 됨 | 급여 · 근로계약 · 징계 등은 자료로 답하지 않고 **인사 담당자 답변**으로 넘긴다 |
| 한 부서에서 만들고 끝남 | 부서 × 4단계 확산 계획, 네 단계 완료 부서 = 적용 → **4개 부서 적용** (목표치) |

> 리드 빌더 ‘엑셀탈출’ 코멘트 — “최신본만 남기는 정리부터 한 것이 확산의 조건이었어요.”

## 주요 기능

- **최신본 정리** — `취업규칙(개정)`, `경비 처리 규정_최종`, `… v2`를 같은 문서로 본다. 같은 날짜 개정본이 여러 부서에 있으면 하나만 남기고 ‘사본’ 표시.
- **확인 필요 · 인정 · 되돌리기** — 개정일 없는 문서를 인정하면 그 문서가 관련 질문에 바로 연결된다.
- **공통 질문** — 기준(2개/3개 부서 이상) 변경, 한 부서 질문도 지우지 않고 ‘한 부서 질문도 보기’로 확인.
- **팀 확산 계획** — 칸을 눌러 예정 → 진행 → 완료. 적용 부서 수와 진행률이 위 숫자에 반영된다.
- **온보딩 키트 복사** — 최신본 목록 · 공통 질문 · 계획 표를 마크다운으로 복사(사내 위키용).
- **샘플로 되돌리기** — 입력 · 인정 · 계획을 처음으로(되돌리기 가능). 작업 내용은 브라우저에 저장.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | 질문 + 최신본 목록을 `onboarding.faq`로 보내 뜻으로 다시 묶음 → 검사(질문 번호 한 번씩, 최신본 id만) → 빠진 질문은 따로 붙임 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 아직 없는 작업 | 두 글자 조각 겹침으로 묶는 규칙 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 결과 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

어느 쪽이든 최신본 고르기와 ‘인사 담당자 답변’ 판정은 규칙이 합니다. AI는 문서 본문을 받지 않으므로 답을 쓰지 않고, 답이 있을 문서만 고릅니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 (작업 정의: [docs/ai-task.json](docs/ai-task.json)) |
| 자료 | 부서 공유 폴더 자료 목록 · 신입 질문 모음 붙여 넣기 |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
ax-onboarding-kit/
├── index.html
├── style.css
├── logic.js          개정일 · 같은 문서 판단 · 최신본 · 질문 묶기 · 자료 연결 · 응답 검사 · 계획 · 키트 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            최신본 자료 · 공통 질문 · 확산 계획 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```
