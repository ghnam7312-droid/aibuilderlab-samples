# 분기판

> 거래 목록을 점검해 **팀 누구나 같은 양식**의 분기 영업 리포트를 만들고, 요약 문장 속 숫자는 계산과 대조하는 도구. 처음 쓰는 팀원을 위한 1장 가이드 포함

**데모** · https://aibuilderlab.kr/demo/ax-sales-quarterly/index.html

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘미팅기록왕’)** 의 예시 프로젝트입니다. 등장하는 회사·사람·거래 숫자는 모두 가상이고, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 분기마다 리포트를 만드느라 이틀 | 거래 목록만 확인하면 숫자·요약·담당별 표가 바로 → **이틀 → 반나절** (목표치) |
| 팀원마다 양식이 다름 | 영업본부 공통 양식(숫자 6칸 · 요약 4문장 · 담당별 · 큰 수주 3건)으로 **3개 팀 확산** (목표치) |
| 빈칸·중복 행 때문에 숫자가 틀림 | 양식 점검: 걸린 줄은 빨갛게 표시하고 계산에서 뺌 |
| AI가 쓴 요약의 숫자를 믿기 어려움 | 문장 속 숫자를 계산과 대조, 하나라도 다르면 버림 |
| 팀원이 따라 하다 막힘 | **화면 캡처를 넣은 1장짜리 가이드**로 다시 씀 |

## 주요 기능

- **팀 · 분기 · 목표** — 세 팀을 버튼으로 오가며 같은 양식을 봅니다. 버튼에 팀별 달성률이 함께 보입니다.
- **양식 점검** — 담당·고객사·단계·금액·날짜 빈칸, 분기 밖 날짜, 같은 거래 두 번을 잡고 ‘고치기’로 그 칸에 바로 갑니다.
- **즉시 다시 계산** — 금액(3,200만 · 1.2억), 단계, 날짜, 목표를 고치면 리포트가 바로 바뀝니다. 지우기 + 되돌리기.
- **요약 + 숫자 검산** — 규칙 요약이 즉시 나오고, Claude 요약이 오면 숫자를 대조한 뒤 덮어씁니다. ‘숫자 검산 통과 · 12개’처럼 표시.
- **공유** — 마크다운 복사(메신저·위키), 리포트만 인쇄.
- **1장 가이드** — 4단계, 단계마다 화면 그림. 가이드만 인쇄.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `salesq.summary`(계산한 숫자만) → 형식 검사 → 숫자 검산 | `Claude로 작성 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 규칙 요약 4문장 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 요약 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |
| 문장 속 숫자가 계산과 다름 | 버리고 규칙 요약 유지 | `규칙 기반 · 계산과 다른 숫자(…)` |

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음), 가이드 그림은 인라인 SVG |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 저장 | 브라우저 localStorage (팀별 거래·목표) |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```

├── index.html
├── style.css         화면 + 인쇄(리포트만 / 가이드만)

├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            팀·분기 · 리포트 · 거래 목록 · 가이드
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```
