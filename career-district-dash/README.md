# 자리판

> 업종 하나와 구를 고르면 **행정동별 점포 수 · 경쟁 · 폐업률 · 매출**을 바로 비교하는 우리 동네 상권 분석 대시보드

**데모** · https://aibuilderlab.kr/demo/career-district-dash/index.html

> **알림** AI 빌더랩 커리어 트랙 **1기 목표 모델(가상의 수강생 ‘숫자읽는사람’)** 의 예시 프로젝트입니다. 구·행정동·업종 숫자는 모두 가상의 샘플이며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 창업 동아리 친구들이 가게 자리를 고를 때마다 공공데이터를 엑셀로 내려받아 하루씩 정리 | 업종·구만 고르면 18개 동 순위가 바로 → **분석 요청 1일 → 즉시** |
| 행정동 이름이 바뀌어 1분기 데이터가 빠졌다 (증감이 부풀려 보임) | **옛 이름 · 새 이름 대응표**로 맞추고, 대응표에 없는 이름은 경고 + 그 자리에서 이어 붙이기 |
| AI가 만든 집계 코드가 맞는지 확신이 없었다 | **표본 10건 검산** — 원본 행을 처음부터 다시 세어 집계와 대조 |
| 숫자만 있는 표는 친구들이 읽기 어려웠다 | 한눈 요약 3문장 + 동 3곳 나란히 비교 |

**목표치 (1기)** — 3개 구 · 업종 20개 비교, 조회 410회, 분석 요청 1일 → 즉시

## 주요 기능

- **행정동 순위** — 점포 수, 1분기 대비 증감, 유동인구 1만 명당 점포, 폐업률, 점포당 월매출, 참고 점수. 머리글로 정렬.
- **대응표** — `새솔2동 → 햇살동`, `솔밭1·2동 → 솔밭동`(통합) 등. 켜고 끄면 빠지는 행과 숫자 차이가 바로 보입니다. 대응표에 없는 `가람2동`은 경고에서 골라 이어 붙이고, 되돌릴 수 있습니다.
- **표본 검산** — 누를 때마다 다른 동 10곳을 골라 1·2분기 점포 수를 원본에서 다시 셉니다. 불일치한 동은 빨갛게.
- **동 비교** — 표에서 3곳까지 담아 다섯 지표를 막대로 비교. 더 나은 값은 굵게.
- **CSV 내보내기** — 엑셀에서 한글이 깨지지 않게 BOM을 붙입니다.
- **저장 · 되돌리기** — 조건은 이 브라우저에 저장되고, ‘샘플로 되돌리기’로 처음 상태로.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `district.brief` → 형식 검사 → **문장 속 숫자를 입력 숫자와 대조** | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 서버에 작업 없음 | 정해진 문장 틀로 쓴 규칙 요약 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 / 입력에 없는 숫자가 나옴 | 버리고 규칙 요약 유지 | `규칙 기반 · 숫자 검산 실패 (…)` |

규칙 요약이 먼저 즉시 나오고, Claude 요약이 오면 덮어씁니다. 참고 점수는 고른 동끼리의 상대 비교이며, 창업을 권하거나 말리는 판단은 하지 않습니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버에 합칠 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음). 실제 버전은 Next.js 차트 |
| 데이터 | 실제 버전은 Python으로 공공데이터를 정리해 Supabase에 적재. 데모는 같은 형식의 가상 샘플 740행 |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```

├── CHANGELOG.md

```
