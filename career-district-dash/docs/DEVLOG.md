## 4주차 — 하루짜리 엑셀 작업을 쪼개기

**한 일**
- 친구들이 자리 하나를 볼 때 하던 일을 적어 보니: 공공데이터 내려받기, 구·업종으로 거르기, 동별로 더하기, 지난 분기와 비교, 표 꾸미기. 하루가 걸렸다.
- 원본 파일을 Python으로 읽어 ‘분기 · 구 · 행정동 · 업종 · 점포 · 개업 · 폐업 · 매출’ 한 형식으로 맞추고 Supabase 테이블에 넣었다.

**막힌 것 → 해결**
- 분기마다 열 이름이 조금씩 달랐다(`점포수` / `점포 수`) → 열 이름을 공백 없이 비교하도록 맞춤.
- 매출을 그냥 평균 내니 점포가 1곳인 동이 튀었다 → 점포 수로 가중 평균.
- 숫자 열에 쉼표가 섞여 문자로 읽힘 → 읽을 때 쉼표를 떼고 숫자로 바꿈.

## 5주차 전반 — 순위 표

**한 일**
- 업종 하나 · 구 여러 개로 동별 집계. 점포 수, 증감, 폐업률, 유동인구 1만 명당 점포.
- 참고 점수: 경쟁 적음 40 · 폐업률 낮음 30 · 매출 30. 고른 동끼리 비교한 상대 점수라는 걸 화면에 같이 적었다.

**막힌 것 → 해결**
- 모든 동 값이 같으면 0으로 나누기 → 그때는 0.5로 둠(테스트 추가).
- 폐업률이 낮을수록 좋은데 정렬이 반대로 됨 → 지표마다 좋은 방향을 따로 둠.

## 5주차 후반 — 빠진 데이터 찾기

**한 일**
- 어느 동의 커피전문점이 한 분기 만에 21곳 늘었다고 나왔다. 이상해서 원본을 열어 보니 1분기에는 옛 동 이름으로 들어 있었다.
- **옛 이름 · 새 이름 대응표**를 만들어 이름을 맞췄다. 두 동이 하나로 합쳐진 경우(솔밭1·2동 → 솔밭동)도 대응표 두 줄로 처리.
- 대응표에 없는 이름은 버리지 않고 ‘몇 행이 빠졌는지’ 경고로 띄우고, 그 자리에서 지금 이름을 골라 이어 붙이게 했다.
- AI가 짜 준 집계 코드를 그대로 믿지 않기로 했다. **표본 10건을 원본에서 다시 세어** 집계와 대조하는 검산을 만들었다.

**막힌 것 → 해결**
- 행정동 이름이 바뀌어 데이터가 빠짐 → 옛 이름·새 이름 대응표를 만들어 해결.
- 대응표 이름에 띄어쓰기가 섞여(`새솔 2동`) 안 맞음 → 비교 전에 공백 제거.
- 대응표가 지금 목록에 없는 이름을 가리켜도 통과함 → 바꾼 이름이 지금 목록에 있을 때만 인정.
- 검산을 집계 함수로 다시 돌리면 같은 실수를 같이 함 → 검산은 원본을 한 행씩 비교하는 다른 방법으로 셈.

## 6주차 — 친구들이 읽게

**한 일**
- 동 3곳을 담아 다섯 지표를 나란히 비교.
- Claude(`district.brief`)가 3문장 요약을 쓰게 했다. 규칙 요약이 먼저 나오고 Claude 요약이 오면 덮어쓴다.
- CSV 내보내기, 조건 저장, 샘플로 되돌리기. 로직을 `logic.js`로 분리하고 테스트 13개.

**막힌 것 → 해결**
- Claude가 ‘평균 매출 약 1,500만 원’처럼 직접 계산한 숫자를 씀 → 문장 속 숫자를 모두 뽑아 입력 숫자와 대조, 없는 숫자가 하나라도 있으면 버리고 규칙 요약을 둠.
- 엑셀에서 CSV 한글이 깨짐 → 파일 앞에 BOM.

**결과 (1기 목표치)**
- 3개 구 · 업종 20개 비교, 조회 410회
- 분석 요청 1일 → 즉시
