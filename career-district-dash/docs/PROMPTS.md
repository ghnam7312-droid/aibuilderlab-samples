# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버 작업 정의([ai-task.json](ai-task.json))의 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 4주 | 정리 스크립트 | 분기별 상권 CSV 여러 개를 읽어서 분기·구·행정동·업종·점포·개업·폐업·매출 열로 맞춰 줘. 열 이름은 공백을 빼고 비교하고, 숫자 칸의 쉼표는 떼. |
| 5주 | 집계 | 업종 하나와 구 목록을 받아 동별로 1·2분기 점포를 더하고, 증감·폐업률·유동인구 1만 명당 점포를 계산해 줘. 매출은 점포 수 가중 평균. |
| 5주 | 대응표 | 옛 행정동 이름 → 지금 이름 대응표로 이름을 맞추는 함수를 만들어 줘. 못 찾은 이름은 버리지 말고 이름별 행 수를 모아서 돌려줘. |
| 5주 | 검산 | 집계 결과에서 동 10곳을 무작위로 골라, 집계 함수를 쓰지 말고 원본 행을 하나씩 비교해 다시 세서 맞는지 확인하는 함수를 만들어 줘. 씨앗을 받아 같은 표본이 나오게. |
| 6주 | 요약 검사 | Claude 요약 문장에서 숫자를 다 뽑아서 입력에 있는 숫자(반올림 포함)인지 확인하고, 아니면 버리는 함수를 만들어 줘. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

### district.brief
```
상권 집계 숫자로 예비 창업자용 한눈 요약을 쓴다. input.biz는 업종, input.dongs는 행정동별 2분기 점포 수(stores),
1분기 대비 증감(change), 폐업률(closeRatePct), 유동인구 1만 명당 점포(storesPer10k), 점포당 월매출(salesManwon, 만원),
참고 점수(score)다. headline은 가장 눈여겨볼 동 하나를 한 문장으로. lines는 3문장: 1) 고른 구 전체 점포 수와 증감,
2) 경쟁이 덜하고 폐업률이 낮은 동, 3) 가장 붐비거나 폐업률이 높은 동. caution은 이 데이터에 없어서 현장에서 확인해야 할 것
한 문장(임대료, 시간대별 유동인구 등). 숫자는 input에 있는 값만 그대로 쓰고, 새로 계산하거나 input에 없는 사실을 지어내지 않는다.
창업을 권하거나 말리는 단정은 하지 않는다. 모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"headline":"","lines":[""],"caution":""}
```
- 입력: `aiInput()` — `{ biz, gus, quarter, dongCount, totalStores, totalChange, dongs:[{dong, gu, stores, change, closeRatePct, storesPer10k, salesManwon, score}] }` · 최대 600토큰
- 화면 검사: `normalizeBrief()` — 형식 + 문장 속 숫자 대조. 실패하면 규칙 요약 유지

## 3. 왜 이렇게 썼나

- **열 이름의 뜻을 지시문에 적었다.** `closeRatePct`가 % 단위인지, 매출이 만원 단위인지 모르면 Claude가 단위를 바꿔 쓴다.
- **문장 세 개의 역할을 정했다.** 자유롭게 쓰게 하면 1등 동 칭찬만 세 줄이 나온다. 전체 → 좋은 동 → 조심할 동 순서로 고정.
- **‘새로 계산하지 않는다’.** 화면이 문장 속 숫자를 검산하므로, 평균·합계를 Claude가 직접 내면 검산에 걸린다. 필요한 합계는 입력에 미리 넣었다.
- **caution을 따로 뺐다.** 이 데이터로 모르는 것(임대료 등)을 늘 한 줄 남겨, 점수를 정답처럼 읽지 않게.

## 4. 실패했던 이전 버전

| 버전 | 지시문 | 무엇이 문제였나 |
|---|---|---|
| v1 | “이 상권 데이터를 분석해서 어느 동에 창업하면 좋을지 추천해 줘.” | ‘○○동에 여는 것을 추천합니다’처럼 단정. 데이터에 없는 임대료·상권 분위기를 지어냈고, 동 평균 매출을 직접 계산해 틀린 숫자가 나옴 |
| v2 | 3문장 JSON + 단정 금지 | 숫자 단위가 섞임(폐업률 0.056 / 5.6%), 합계를 직접 더해 1~2곳씩 틀림 |
| v3 (지금) | 열 이름의 뜻·단위 명시, 합계는 입력으로, “새로 계산하지 않는다” + 화면 숫자 검산 | 검산 통과 요약만 화면에 남음 |
