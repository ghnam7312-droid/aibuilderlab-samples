## 3주차 1일 — 50분이 어디서 새는지

**한 일**
- 하루 미팅 4~5건을 CRM에 옮기는 50분을 재 보니: 메모 다시 읽기 15분, 칸마다 옮겨 적기 25분, 금액·날짜 다시 확인 10분.
- 금액(`3,200만`, `1억 2천만`)과 날짜(`11/5`, `다음 주 화요일`)를 읽는 규칙부터 만들었다.

**막힌 것 → 해결**
- ‘다음 주 화요일’을 수요일에 쓰면 2주 뒤로 계산 → “다음 달력 주(월요일 시작)의 화요일”로 고치고 테스트 추가.

---

## 3주차 2일 — Claude로 칸 채우기

**한 일**
- `meetingcrm.extract`로 고객사·담당자·단계·금액·날짜·다음 할 일·요약을 한 번에 채우게 했다.
- 규칙 결과가 먼저 나오고 Claude 결과가 오면 덮어쓴다. 어느 쪽인지 화면에 항상 표시.

**막힌 것 → 해결**
- 응답이 가끔 `"amount":"3200만"`처럼 글자로 옴 → 숫자가 아니면 버리고 규칙 값을 남기는 `normalizeAi` + `mergeAi`.
- 메모의 고객 전화번호가 요약에 그대로 들어감 → 보내기 전에 `maskPII`로 가리고, 저장·CSV에서도 다시 가림.

---

## 3주차 3일 — AI가 숫자를 잘못 옮겼다

**한 일**
- 일주일 써 보니 금액·날짜를 AI가 잘못 옮긴 기록이 3건 나왔다. 처음 말한 예산(2,800만)을 최종 견적 자리에 넣거나, 날짜를 한 주 당겨 적었다.
- **숫자 항목은 사람이 확인해야 저장되게** 바꿨다: 금액·미팅일·다음 연락일 칸은 ‘확인 필요’로 시작하고, ‘원문과 맞음’을 누르거나 직접 고쳐야 저장 버튼이 열린다(`canSave`).
- 원문 버튼을 누르면 메모에서 그 글자가 선택된다. 금액이 여러 개면 ‘다른 후보’로 바로 바꾼다.

**막힌 것 → 해결**
- 확인 버튼만 누르고 넘어가는 경우 → Claude가 준 숫자가 메모에 아예 없으면(`inSource`) 칸을 빨갛게 하고 확인 버튼을 잠갔다. 고쳐야 풀린다.
- 같은 미팅을 두 번 저장해 중복 → 같은 고객사·같은 미팅일은 고쳐 쓰기(`upsert`).

---

## 3주차 4일 — 팀이 같이 쓰게

**한 일**
- 고객 목록: 단계·담당·검색 거르기, 지우기 + 되돌리기, ‘다음 연락’이 지난 건은 빨간 글씨.
- CSV 내보내기: 엑셀에서 한글이 깨지지 않게 BOM, `=`로 시작하는 글은 수식으로 읽히지 않게 처리, 연락처 제외.
- 팀원 5명이 영업 담당을 골라 같은 방식으로 저장. 로직을 `logic.js`로 분리하고 테스트 13개.

**결과 (1기 목표치)**
- CRM 입력 하루 50분 → 10분, 팀 5명 사용
