## 4주차 — 1시간이 어디로 가는지

**한 일**
- 강의 한 번 명단 정리에 1시간: 문자·통화 기록 다시 보기 20분, 엑셀에 옮기기 20분, 정원 세고 대기 연락 10분, 기관에 명단 보내기 10분.
- 신청 폼은 그대로 두고, 폼 밖으로 들어오는 전화·문자만 메모로 붙여 넣으면 정리되게 했다.
- 한 줄에서 번호·강의(기관 이름)·이름(호칭 앞)·아이 나이를 읽는 규칙 정리. 못 읽은 줄은 버리지 않고 ‘확인 필요’로.
- 강의별 정원: 먼저 신청한 순서대로 확정, 넘치면 대기 번호.

**막힌 것 → 해결**
- ‘신청’, ‘문자’를 이름으로 읽음 → 이름은 ‘어머님·님’ 같은 호칭 앞 낱말을 먼저 보고, 자주 나오는 낱말은 제외 목록으로.

## 5주차 전반 — 같은 사람이 두 번 (이 프로젝트의 막힌 문제)

**한 일**
- 첫 강의에서 명단 20명 중 2명이 같은 사람이었다. 폼으로 한 번, 며칠 뒤 “접수됐나요?” 하며 전화로 또 한 번. 자리 두 개가 잡혀 대기자가 못 들어왔다.
- **전화번호 기준 중복 확인** 추가: 번호를 숫자만 남겨 정규화하고, `번호 + 강의`가 같으면 한 명으로 합친다. 순서는 먼저 신청한 쪽.
- 미리 보기에서 ‘이미 명단에 있음 → 합침’, ‘메모 안에서 중복 → 합침’을 넣기 전에 보여 주고, 명단에는 ‘2회 신청 → 1명’ 표시.
- 받아 적은 메모가 들쭉날쭉해 `parentsignup.parse`로 Claude가 정리하게 했다. 번호는 `[전화1]`로 가려서 보낸다.

**막힌 것 → 해결**
- `010 3456 7788`과 `010-3456-7788`이 다른 사람으로 들어감 → 문자열 비교가 아니라 `normPhone()`으로 정규화한 뒤 비교. `+82 10-…`도 같은 번호로 테스트.

## 5주차 후반 — 정리한 뒤의 20분

**한 일**
- 확정·대기 안내 문자 문구 하나로 칸 채우기. 모르는 칸(`{이룸}`)이 있으면 복사 버튼을 막는다.
- 기관 제출용 명단 CSV: 엑셀에서 한글이 깨지지 않게 BOM, 전화번호는 가림.
- 로직을 `logic.js`로 분리하고 테스트 13개.

**막힌 것 → 해결**
- 명단에서 한 명을 빼도 대기 번호가 그대로 → 대기 번호를 저장하지 않고 화면을 그릴 때마다 순서로 다시 계산(`seats`).

**결과 (1기 목표치)**
- 명단 정리 회당 1시간 → 10분, 강의 월 6회 → 11회
