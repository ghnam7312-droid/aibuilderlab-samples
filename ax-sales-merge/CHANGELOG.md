# 변경 기록

> 1기 목표 모델 예시 · 주차는 직장인 AX 트랙 기준

## v1.0 — 8주차
- 검산 기록(시각·확인자·한 일·위치·전→후, 되돌리기 포함), CSV와 엑셀 시트
- 지난주 비교: 부서별 증감 막대, ±15% 넘는 부서 강조, 규칙 기반 이상치 설명(원인 품목·거래처)
- 형식 오류가 남아 있으면 비교 숫자에 경고
- `logic.js` 분리, 단위 테스트 15개

## v0.3 — 7주차
- 여러 파일 한꺼번에 끌어다 놓기(화면 어디든), 같은 부서는 수정본으로 교체
- 열 이름 맞추기(짐작 + 사람 확인 + 양식 기억), ‘다른 양식 파일로 시험해 보기’
- 오타 고칠 값 제안(O→0, l→1, 전각, 마침표 천 단위)
- 엑셀 4시트 내보내기, 다시 올리면 부서별로 나눠 읽기
- 고침: 따옴표 속 쉼표가 있는 CSV, 통합 엑셀이 한 부서로 들어가던 문제

## v0.2 — 6주차 후반
- 부서별 보고 합계 ↔ 행 합계 대조, 형식 오류 표시
- 고침: 날짜가 다른 같은 내용을 중복으로 잡던 문제

## v0.1 — 6주차
- 10개 부서 파일 취합, 검산 테이프, 검산 통과 도장
