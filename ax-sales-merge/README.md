# 한장 — 부서 실적 취합·검산

> 10개 부서가 보낸 실적 엑셀을 **한 장으로 합치고, 부서가 보고한 합계와 대조해 검산까지** 끝내는 도구

![한장 화면](screenshot.png)

**데모** https://aibuilderlab.kr/demo/ax-sales-merge/index.html

> AI 빌더랩 직장인 AX 트랙 **1기 목표 모델 예시**입니다. 가상의 회사(다온오피스) 샘플 데이터로 동작합니다.

## 문제 → 해결

| 전에는 | 이제는 |
|---|---|
| 매주 월요일 10개 부서 엑셀을 손으로 복사해 합치느라 **2시간** | 파일을 모아 두고 버튼 한 번, 확인까지 **15분** |
| 같은 행을 두 번 붙여 넣어 합계가 틀려도 몰랐음 | 부서 보고 합계와 행 합계를 대조해 **중복·형식 오류를 바로 표시** |
| 틀린 곳을 찾으려면 원본을 다시 열어야 했음 | 장부에서 그 칸을 눌러 **바로 고치고**, 검산 테이프가 다시 계산 |

## 주요 기능

- **받은 파일함** — 부서별 파일, 받은 시각(마감 09:00 이후는 ‘늦음’), 부서가 보고한 합계
- **원본 시트** — 엑셀처럼 열 글자·행 번호가 붙은 격자로 원본 확인
- **취합하고 검산하기** — 파일이 장부로 모이고, 계산기 영수증 같은 **검산 테이프**가 한 줄씩 찍힘
- **검산 규칙**
  1. 부서·담당·거래처·품목·수량·금액이 모두 같은 행 → 중복 의심
  2. 수량·금액에 숫자가 아닌 글자(예: `1,59O,000`) → 형식 오류
  3. 부서 보고 합계 = 행 합계 가 되어야 통과 (차이 0 → ‘검산 통과’ 도장)
- **통합 장부** — 부서별 소계와 보고 합계 비교, ‘확인할 행’만 모아 보기, 칸을 눌러 바로 수정(Enter 확정 · Esc 취소)
- **되돌리기** — 행 제외·파일 빼기·값 수정·초기화 모두 알림에서 되돌릴 수 있음
- **파일 추가** — CSV·엑셀(.xlsx) 끌어다 놓기. 첫 줄 열 이름(부서·담당·거래처·품목·수량·금액)으로 열을 맞추고, `합계` 행이 있으면 보고 합계로 사용
- **내려받기** — 결과 CSV, 엑셀(시트 2개: 통합 · 부서별 검산)

## 화면 구성

```
┌ 받은 파일 ┐┌──── 원본 시트 / 통합 장부 ────┐┌ 검산 테이프 ┐
│ 영업1팀 ✓ ││ #  일자  담당  거래처  품목  금액 ││ 보고 합계   │
│ 영업2팀 ! ││ ...                            ││ 중복 1행 [제외]│
│ ...       ││         [취합하고 검산하기]     ││ 차이 0  [통과]│
└───────────┘└───────────────────────────────┘└─────────────┘
```

## 기술 스택

| 이 데모 | 실제 업무 버전 |
|---|---|
| HTML · CSS · JavaScript (프레임워크 없음) | 엑셀 · 매크로 · 검산 체크 |
| 브라우저 localStorage에 저장 | 사내 공유 폴더의 부서 파일 |
| SheetJS(CDN)로 엑셀 읽기·쓰기, 못 불러오면 CSV로 안내 | |
