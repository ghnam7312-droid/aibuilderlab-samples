# 오늘공정

> 현장 사진을 **현장별 폴더**에 올리면 공정별로 묶어 그날의 공정 일지를 쓰고, 고객에게 보낼 공유 화면과 문구를 만드는 도구. 고객이 묻기 전에 먼저 보여 줍니다.

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘공간한컷’)** 의 예시 프로젝트입니다. 현장 3곳과 고객은 모두 가상이고, 사진은 실제 현장 사진이 아닌 샘플 그림입니다. 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 현장 사진을 찍어도 정리를 못 해, 고객에게 진행 상황을 설명하기 어려웠다 | 사진에 공정·한 줄 메모만 달면 공정별로 묶인 일지가 바로 나온다 → **하루 40분 → 8분** |
| 다른 현장 사진이 섞여 고객에게 공유됨 | 사진을 **현장별 폴더로 나눠 업로드**. 업로드는 지금 연 폴더로만 들어가고, 파일 이름에 다른 현장 코드가 보이면 보류해 공유에서 뺀 뒤 맞는 폴더로 옮기게 한다 |
| 진행 상황을 물어보는 고객 연락이 잦았다 | 공정 진행 막대 + 고객 화면 미리보기 + 공유 문구·링크 → **고객 문의 절반으로** |
| 누수·균열 같은 일을 문장으로 어떻게 전할지 애매했다 | AI가 판단하지 않는다. ‘담당자 확인’으로 표시하고 고객에게는 “담당자가 직접 확인 후 연락”만 나간다 |

## 주요 기능

- **현장 폴더** — A·B·C 현장마다 폴더가 따로 있고, 사진은 늘 폴더 하나에 속합니다. 다른 현장 의심 사진 수가 폴더에 ‘확인’ 배지로 보입니다.
- **사진 올리기** — 버튼이나 끌어 놓기로 지금 연 폴더에 올립니다. 파일 이름으로 공정을 짐작하고, `B현장_…`처럼 다른 현장 이름이면 보류합니다. 직접 올린 사진은 이 브라우저 안에서만 보입니다.
- **공정 일지** — 공정·메모·‘일지에 넣기’를 고치면 바로 다시 쓰입니다. 다음 작업은 현장의 공정 계획 순서로 정합니다.
- **고객 화면 · 공유** — 고객에게 보일 문구와 사진을 미리 보고, 문구 복사(이름은 `한*윤`)와 공유 링크(주소에 이름·위치 없음)를 만듭니다.
- **되돌리기** — 폴더 옮기기 · 업로드 · 샘플로 되돌리기는 토스트에서 되돌릴 수 있습니다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `sitelog.write` → 형식 검사(`normalizeLog`) → 안전 표시·다음 공정은 규칙 값으로 합침 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 공정별로 메모를 묶는 규칙 일지 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 · 그날 없는 공정을 지어냄 | 지어낸 항목은 빼고, 남는 게 없으면 버림 | `규칙 기반 · 응답 형식이 맞지 않음` |
| 안전 확인 건이 있는데 ‘문제없다·안전하다’고 씀 | 응답 전체를 버림 | `규칙 기반 · 응답 형식이 맞지 않음` |

AI에는 사진이 아니라 시간·공정·메모만 보내고, 안전 메모는 내용 대신 “안전 확인 필요”로 바꿔 보냅니다. 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| 사진 | 파일 선택·끌어 놓기 + 브라우저 안 미리보기, 샘플은 인라인 SVG 그림 |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
startup-site-log/
├── index.html
├── style.css
├── logic.js          공정 짐작 · 현장 코드 검사 · 안전 표시 · 규칙 일지 · 응답 검사 · 공유 문구 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            현장 폴더 · 사진 · 공정 일지 · 고객 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```
