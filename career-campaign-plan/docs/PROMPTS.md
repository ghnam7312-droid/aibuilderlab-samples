# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버에 합칠 원문([ai-task.json](ai-task.json))입니다.

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 7주 | 페르소나 설계 | 설문 응답을 ‘마시는 상황’으로 묶고, 묶음마다 많이 고른 기준 상위 3개, 살 만한 가격 중간값, 주로 사는 곳을 계산해 줘. 3건 미만인 묶음은 페르소나로 만들지 마. |
| 7주 | 평가표 | 메시지 문구를 근거(근거 응답 수) · 타깃(페르소나 장면이나 기준 표현이 들어갔는지) · 길이 · 과장 없음으로 각 1~5점 매기는 함수. |
| 7주 | 근거 검사 | 주장 문장과 응답 번호 목록을 받아서, 없는 번호, 근거 없음, 문장 속 %·명이 번호 개수와 맞지 않는 경우를 이유와 함께 돌려줘. |
| 7주 | 효능 표현 | 다이어트, 살 빠짐, 면역, 피로 회복 같은 효능·건강 표현을 찾아서 표시만 하고, 맞는지 판단은 하지 마. 사람이 확인 체크하기 전에는 채택 못 하게. |
| 7주 | 응답 검사 | AI 기획 초안 JSON에서 근거 검사를 통과한 페르소나·메시지만 남기고, 무엇을 왜 뺐는지 목록으로 돌려줘. |

## 2. 서비스가 쓰는 지시문

### campaign.plan
```
20대 대상 신규 음료 캠페인 기획서 초안을 쓴다. 근거는 input.responses(실제 설문 응답, id는 R01 형식)뿐이다.
personas는 2~3개: 마시는 상황과 고르는 기준이 비슷한 응답끼리 묶고, name은 2~10자 별칭,
summary는 한 문장, needs는 input.criteria 중 1~3개, refs는 그 페르소나에 속한 응답 id 전부(3개 이상).
messages는 4안: copy는 25자 이내 광고 문구, persona는 대상 페르소나 name 또는 '전체',
angle은 input.criteria 중 하나, refs는 그 문구의 근거 응답 id.
비율·인원 숫자를 쓰면 refs 개수와 input.total로 계산한 값과 같아야 한다.
input에 없는 설문 결과·통계·출처를 지어내지 않는다.
다이어트·면역·피로 회복 같은 효능·건강 표현과 '최고', '1위' 같은 과장 표현은 쓰지 않는다.
모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"personas":[{"name":"","when":"","summary":"","needs":[""],"refs":["R01"]}],"messages":[{"copy":"","persona":"","angle":"","refs":["R01"]}]}
```
- 입력: `{ product, total, criteria, responses:[{id, when, criteria, price, channel, quote}] }` (나이·신분은 보내지 않음) · 최대 1500토큰
- 화면 검사: `normalizePlan()` → `checkClaim()` 통과 + 근거 3건 이상인 페르소나, 근거 있고 과장 없는 메시지만. 통계는 `statsOf(refs)`로 다시 계산

### 왜 이렇게 썼나
- **근거는 input뿐** — 첫 초안의 문제는 AI가 그럴듯한 ‘설문 결과’를 만들어 낸 것이었다. 근거의 범위를 입력으로 못 박았다.
- **refs를 먼저, 숫자는 나중에** — 숫자를 쓰면 refs로 검산할 수 있어야 한다. 그래서 화면이 숫자를 다시 계산할 수 있다.
- **효능 표현 금지 + 화면 표시** — 지시문으로 막고, 그래도 들어오면 사람 확인으로 넘긴다. 이 판단은 AI의 몫이 아니다.

## 3. 실패했던 이전 버전

```
20대 대상 저당 스파클링 티 캠페인 기획서 써 줘. 타깃 조사 결과와 페르소나 3개, 메시지 4개 포함.
```
- 결과: “응답자의 78%가 제로 칼로리 음료를 매일 마신다”, “설문 300명 중 64%가 오후 3시에 카페인을 찾는다” 같은 ‘조사 결과’가 들어간 그럴듯한 기획서가 나왔다. 실제 설문은 52명이었고 이런 문항은 없었다. 메시지에는 “마시면 살 빠지는 탄산”, “20대 1위 음료” 같은 표현이 섞였다.
- 고친 점: 실제 응답을 입력으로 주고 그 밖의 근거 금지, 모든 항목에 응답 번호, 숫자는 번호로 검산, 효능·과장 표현 금지 + 화면 검사.
