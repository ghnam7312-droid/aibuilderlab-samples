# 응답대로

> 실제 설문 응답만 근거로 페르소나와 메시지를 만들고, **근거 없는 주장은 걸러 내는** 20대 신규 음료 캠페인 기획서 도구

> **알림** AI 빌더랩 커리어 트랙 **1기 목표 모델(가상의 수강생 ‘전환율장인’)** 의 예시 프로젝트입니다. 가상의 신제품 ‘톡차’와 가상의 설문 응답 52건으로 시작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 수업 과제로 캠페인을 기획할 때 타깃 조사와 메시지 정리가 뒤죽박죽이었다 | 응답 목록 → 페르소나 → 메시지 → 근거 검사, 한 화면 한 흐름 |
| AI가 만든 설문 결과(“응답자의 78%가…”)를 사실처럼 썼다 | **실제 응답 52건만 근거**로 다시 작성. 모든 주장에 응답 번호(R01…)를 달고, 근거 없거나 숫자가 근거와 다르면 걸러 낸다 |
| 메시지를 감으로 골랐다 | 프롬프트 평가표(근거 · 타깃 · 길이 · 과장 없음, 각 5점)로 4안을 비교 |
| 음료 효능 표현을 아무렇지 않게 썼다 | 효능·건강 표현은 도구가 판단하지 않고 ‘사람 확인 필요’로 넘기며, 확인 전에는 채택할 수 없다 |

**결과 (1기 목표치)** — 페르소나 3개, 메시지 4안, 실제 설문 52명 반영

## 주요 기능

- **설문 응답** — 상황별 거르기, 응답 추가(입력 검사)·지우기 + 되돌리기. 응답이 바뀌면 기획서 숫자가 다시 계산됩니다.
- **페르소나** — 인원·비율, 먼저 보는 기준 상위 3개, 살 만한 가격 중간값, 주로 사는 곳, 대표 한마디(응답 번호). ‘근거 응답 보기’를 누르면 왼쪽 목록이 그 응답만 남습니다.
- **메시지 4안 + 평가표** — 문구를 그 자리에서 고치면 점수가 다시 매겨집니다. 채택은 한 안만.
- **근거 검사** — 지금 기획서의 모든 주장 검사. ‘AI 첫 초안’ 탭에서는 지어낸 설문 결과가 어떻게 걸리는지 볼 수 있습니다.
- **보조** — 마크다운 복사, 인쇄(기획서만), 샘플로 되돌리기.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `campaign.plan` → `normalizePlan()`이 근거 3건 미만 · 없는 응답 번호 · 근거와 다른 %/명 · 과장 표현을 버림. 페르소나 통계는 남은 근거 응답으로 다시 계산 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 규칙 기획: 마시는 상황별로 묶고 가장 많이 고른 기준으로 문구 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 / 통과한 페르소나·메시지가 2개 미만 | 버리고 규칙 기획 유지 | `규칙 기반 · 근거 검사를 통과하지 못한 응답` |

효능·건강 표현(다이어트, 면역, 피로 회복 등)은 AI든 규칙이든 판단하지 않고 사람에게 넘깁니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버에 합칠 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |

```
├── CHANGELOG.md

```
