# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버 작업 정의([ai-task.json](ai-task.json))의 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 6주 | 정리 | 좌석 시스템 로그를 날짜·구역·시각별 앉은 좌석 수로 묶어 줘. 기록이 없는 시간은 0이 아니라 빈칸으로 남겨. |
| 6주 | 결측 | 평균을 낼 때 빈칸은 빼고 남은 날로 계산하고, 칸마다 빠진 날 수도 같이 돌려줘. 비교용으로 빈칸을 0으로 넣는 옵션도. |
| 7주 | 혼잡 찾기 | 구역마다 시각 순서로 보면서 90% 이상이 이어지는 구간을 묶어 줘. 빈칸은 구간을 끊고, 마지막 시각까지 이어지면 거기서 닫아. |
| 7주 | 보고서 | 보고서를 ‘이 데이터로는 모르는 것’, ‘결론’, ‘재배치 제안’ 순서로 쓰게 해 줘. 숫자는 내가 주는 값만. |
| 7주 | 검산 | 보고서 문장에서 숫자를 다 뽑아 입력에 있는 숫자인지 확인하고, 없는 숫자가 있으면 버리는 함수를 만들어 줘. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

### libseat.report
```
대학 도서관 좌석 기록을 집계한 숫자로 좌석 이용 분석 보고서 문장을 쓴다. input.zones는 구역별 좌석 수(seats), 하루 평균 이용률(avgPct),
최고 이용률(maxPct)이고, input.peaks는 이용률 input.threshold% 이상이 이어진 혼잡 시간대(구역, 시작 from, 끝 to, 평균 avgPct)다.
input.missingHours는 좌석 시스템이 멈춰 기록이 없는 시간 수, input.missingRule은 그 시간을 어떻게 계산했는지다.
headline은 보고서 제목 한 줄. unknowns는 결론보다 먼저 읽힐 '이 데이터로는 모르는 것' 2~3문장으로, 기록이 빠진 시간과 그 처리 방식,
가방만 두고 비운 자리, 자리가 없어 돌아간 학생처럼 기록에 없는 것을 적는다. findings는 혼잡 시간대마다 한 문장(없으면 혼잡 시간대가
없다는 한 문장). proposal은 붐비는 구역과 덜 쓰는 구역을 이은 좌석 재배치 제안 한두 문장으로, 결정은 도서관 담당자가 한다는 전제로 쓴다.
숫자는 input에 있는 값만 그대로 쓰고, 새로 계산하거나 input에 없는 사실을 지어내지 않는다. 모든 문장은 한국어로, 짧고 구체적으로 쓴다.
반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"headline":"","unknowns":[""],"findings":[""],"proposal":""}
```
- 입력: `aiInput()` — `{ period, range, threshold, missingHours, missingRule, overallPct, zones:[{zone, seats, avgPct, maxPct}], peaks:[{zone, from, to, avgPct}] }` · 최대 800토큰
- 화면 검사: `normalizeReport()` — 네 칸이 다 있어야 하고, 문장 속 숫자가 입력에 있어야 통과

## 3. 왜 이렇게 썼나

- **계산은 화면이, 문장은 Claude가.** 평균과 혼잡 시간대는 테스트가 있는 `logic.js`가 낸다. Claude에게는 결과 숫자만 준다.
- **‘모르는 것’을 맨 앞 칸으로.** 결론부터 쓰게 하면 한계를 맨 끝에 한 줄로 붙이거나 빼먹는다. 출력 형식에서 unknowns를 findings보다 앞에 두었다.
- **결측 처리 방식을 입력으로 준다.** 지금 평균이 결측을 뺀 것인지 0으로 넣은 것인지 알아야 그 한계를 정확히 쓴다.
- **결정은 사람이.** 제안은 ‘제안’까지만, 결정은 도서관 담당자가 현장 확인 뒤에 한다는 전제를 넣었다.

## 4. 실패했던 이전 버전

| 버전 | 지시문 | 무엇이 문제였나 |
|---|---|---|
| v1 | “좌석 데이터를 분석해서 혼잡 시간대와 개선안을 보고서로 써 줘.” (원본 기록을 통째로 보냄) | 평균을 직접 계산하다 틀림. 기록 빈칸을 0으로 읽은 결과를 그대로 믿고 ‘2층 열람실 B는 여유’라고 씀. ‘좌석 50석 증설’처럼 근거 없는 숫자 |
| v2 | 집계 숫자만 보내고 결론 · 제안 2칸 | 숫자는 맞았지만 한계를 쓰지 않아, 결측이 있는 시간대도 단정적으로 읽힘 |
| v3 (지금) | unknowns 칸을 맨 앞에, 결측 처리 방식 입력, “새로 계산하지 않는다” + 화면 숫자 검산 | 모르는 것이 먼저 읽히는 보고서 |
