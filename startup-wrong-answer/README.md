# 오답지도 — 내 반 오답 분석

> 학생이 고른 번호만 입력하면, 반 전체의 오답이 한 장의 **지도**로 칠해지고 오답 유형과 학부모 문구까지 나옵니다.

![오답지도 화면](./screenshot.png)

**데모:** https://aibuilderlab.kr/demo/startup-wrong-answer/index.html

> 이 저장소는 **AI 빌더랩 창업 트랙 1기 ‘목표 모델’ 예시**입니다. 수료생이 이 수준까지 만든다는 목표를 보여 주려고 만들었고, 학생 이름은 모두 가상입니다. 데모는 샘플 데이터(40명 · 12문항)로 동작합니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 학생 40명 시험지를 채점하고 학부모 카톡 리포트를 쓰는 데 주 6시간이 걸렸습니다. | 고른 번호만 넣으면 채점, 유형 분석, 학부모 문구가 한 번에 나옵니다. |
| 손글씨 풀이를 인식하면 오류가 많았습니다. | 풀이 대신 **학생이 고른 답**만 입력하고, 문항마다 단원·유형 태그와 ‘계산 실수 보기’를 붙여 유형을 판단합니다. |
| AI가 나눈 오답 유형을 믿어도 되는지 몰랐습니다. | 선생님이 한 건씩 맞음/틀림을 검수하고, **AI 분류 일치율**을 직접 잽니다. |

## 주요 기능

- **오답 지도:** ‘채점하기’를 누르면 문항 한 줄씩 색이 칠해지고 위쪽 정답률 막대가 올라옵니다. 정답률 60% 아래 문항에는 ‘다시’ 표시가 붙습니다.
  - 문항 번호를 누르면 학생들이 고른 보기 분포(정답·계산 실수 보기 표시)를 보여 줍니다.
  - 학생 이름을 누르면 그 학생의 틀린 문항과 유형을 보여 줍니다.
- **오답 유형 · AI 해설:** 개념 부족 / 계산 실수 / 문제 이해 비율, 가장 약한 단원, 다음 수업에서 다시 풀 문항
- **AI 분류 검수:** 한 번에 한 건씩 보여 주는 검수 카드. 키보드 `Y` 맞음 · `N` 틀림 · `S` 건너뛰기 · `Z` 취소. 반원 게이지로 일치율을 보여 줍니다(샘플 기준 약 94%).
- **학부모 문구:** 검수에서 ‘틀림’으로 표시한 분류는 빼고 문구를 만듭니다. 알림장 모양으로 미리 보고 복사합니다.
- **답 입력:** 엑셀처럼 화살표 키로 칸을 옮기고, 숫자를 넣으면 다음 칸으로 넘어갑니다. 1~5가 아니면 칸이 흔들리며 막습니다.
- **문항표:** 단원·유형 태그·정답·계산 실수 보기 수정. 정답과 계산 실수 보기가 같으면 저장하지 않습니다.

### 오답 유형 판단 규칙 (데모: 브라우저 규칙 기반)

1. 정답이면 통과
2. ‘계산 실수 보기’를 골랐으면 → 계산 실수
3. 아니면 문항 태그로 판단: 개념형 → 개념 부족, 계산형 → 계산 실수, 서술·활용형 → 문제 이해

## 실행 방법

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html`을 바로 열어도 동작합니다. 상단 ‘← 포트폴리오로’ 링크는 aibuilderlab.kr 사이트 기준 주소입니다. 입력한 내용은 이 브라우저에만 저장되고, 아래 ‘샘플 데이터로 되돌리기’로 처음 상태로 돌아갈 수 있어요.
