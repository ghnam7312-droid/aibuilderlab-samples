문항 번호를 누르면 그 문항에서 학생들이 고른 보기가, 학생 이름을 누르면 그 학생의 오답이 분석 칸에 나와요.

오답 유형

    3회 시험 추이

    1월 진단 평가 → 2월 단원 평가 → 이번 3월 단원 평가

    분류 검수

    규칙이 나눈 오답 유형이 맞는지 한 건씩 확인해요. 틀렸으면 진짜 유형을 골라 주세요. 확인한 건만 일치율에 들어갑니다.

    키보드 Y 맞음 · N 틀림(이어서 1 2로 진짜 유형) · S 건너뛰기 · Z 방금 것 취소

    분류 일치율

    Claude 학생 진단 일치율

    최근 검수

      학부모 문구

      검수에서 선생님이 고친 유형으로 쓰고, Claude 진단을 덧붙여요.

      오답 노트 인쇄

      틀린 문항, 진단, ‘다시 풀기’ 칸이 들어간 A4 한 장이에요.

      알림장
      
      
      
    
      
  
      

  
  
      
    
      
      
      
        
      학생 답 입력
      손글씨 풀이 대신 학생이 고른 번호(1~5)만 넣어요. 화살표 키로 칸을 옮기고, 고치면 바로 다시 채점합니다.
      
        
      
      
      
      
        엑셀·메모에서 한꺼번에 붙여 넣기
        
      한 줄에 한 명, 이름 3 5 2 … 또는 이름,3,5,2,… 또는 엑셀에서 복사한 칸 그대로. 명단에 있는 이름만 바뀌어요.
      
        
        
      
      
      
      
      
    
      
  
      

  
  
      
    
      
      
      문항표
      문항마다 단원, 유형 태그, 정답, ‘계산 실수 보기’를 적어 두면 학생이 고른 보기로 오답 유형을 판단해요.
      
      
      문항단원유형 태그정답계산 실수 보기
      
      
      
        문항 단위 판단 규칙 (logic.js · 테스트로 검사)
        
      1. 정답이면 통과
      2. ‘계산 실수 보기’를 골랐으면 계산 실수
      3. 아니면 문항 태그로 판단: 개념형 → 개념 부족, 계산형 → 계산 실수, 서술·활용형 → 문제 이해
      
        
      학생 단위 진단과 학부모 코멘트는 Claude가 오답 목록을 읽고 씁니다. 연결할 수 없을 때는 위 규칙의 결과로 정해진 문장을 씁니다.
