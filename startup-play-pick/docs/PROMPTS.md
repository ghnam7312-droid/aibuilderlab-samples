# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버에 넣을 원문([ai-task.json](ai-task.json))입니다.

## 1. 만들 때 쓴 프롬프트 (대표 4개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 7주 | 규칙 추천 | 놀이 목록에서 월령·시간·장소·재료가 맞는 것만 고르고, 영역이 겹치지 않게 3개. 이번 주에 많이 한 영역은 뒤로. 같은 조건이면 같은 결과가 나오게 seed를 받아. |
| 8주 | 응답 검사 | Claude 응답에서 plays가 배열이 아니거나 제목·순서가 없으면 null. 시간은 1~60이 아니면 15, 영역은 다섯 개 중 하나가 아니면 '감각'. |
| 8주 | 안전 기준 | 작은 부품·끈·풍선·비닐·날카로운 도구·불은 월령 미만이면 빼고, 물·높은 곳은 주의만. '콩콩'이나 '실내'는 걸리면 안 되니 낱말 + 조사로 찾아. 걸러낸 이유를 사람이 읽을 문장으로. |
| 9주 | 사람에게 넘기기 | 걱정 메모에 '삼켰', '경련'이 있으면 추천을 멈추고 119 안내, '말이 늦', '발달'이면 상담 안내만 하고 추천은 계속. 메모는 AI에 보내지 마. |

## 2. 서비스가 쓰는 지시문 (`playpick.recommend`)

```
부모가 오늘 집에서 아이와 할 놀이를 3개 추천한다. input.months(월령)에 맞는 놀이만, 한 놀이는
input.minutes분 안에 끝나게, input.place(실내·실외·상관없음)에 맞게 고른다. 준비물(materials)은
input.materials에 있는 것만 쓰고, 없으면 빈 배열로 둔다. input.avoid에 있는 기준(작은 부품, 끈·줄,
풍선, 비닐, 날카로운 도구, 불·열 등)에 해당하는 물건과 놀이는 절대 넣지 않는다. input.exclude에 있는
놀이 제목은 다시 추천하지 않는다. area는 대근육, 소근육, 언어, 감각, 정서·사회 중 하나이고,
input.weekAreas에서 횟수가 적은 영역을 먼저 고른다. steps는 부모가 그대로 따라 할 수 있는 순서 3개,
tip은 한 문장. 아이의 건강·발달 상태는 판단하지 않는다. input에 없는 사실(아이 이름, 성향, 진단)을
지어내지 않는다. 모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"plays":[{"title":"","minutes":10,"area":"","materials":[""],"steps":[""],"tip":""}]}
```
- 입력: `{ months, minutes, place, materials, weekAreas, avoid, exclude }` · 최대 900토큰
- 화면 검사: `normalizePlays()` → `screenAi()` (안전 기준) → 안전한 놀이가 없으면 규칙 결과 유지

### 왜 이렇게 썼나

- **`avoid`를 월령에 맞춰 화면이 계산해 보낸다.** “아이에게 위험한 것은 빼”라고만 하면 무엇이 위험한지 Claude가 정한다. 기준은 강사가 정하고, Claude에게는 결과만 알려 준다.
- **그래도 지시문을 믿지 않는다.** 지시문은 1차 방어이고, 최종 판단은 화면의 `screenAi()`가 한다. 안내 문장에 ‘절대’를 넣은 v3에서도 드물게 ‘쌀 촉감 놀이’가 섞여 왔다.
- **건강·발달 판단 금지 문장.** 입력에는 걱정 메모를 넣지 않지만, 혹시 조건만 보고 “이 월령이면 말이 트일 때” 같은 말을 쓰지 않게 막았다.

## 3. 실패했던 이전 버전

### v1 (버림)
```
{months}개월 아이와 집에서 할 수 있는 재미있는 놀이 3개를 추천해 줘.
```
- 18개월에 ‘숟가락으로 콩 옮기기’, ‘구슬 꿰기’가 나왔다. 발달 면에서는 그럴듯하지만 작은 부품이라 질식 위험.
- 준비물에 집에 없는 ‘폼폼이’, ‘클레이’.
- 줄글로 와서 카드로 나눌 수 없었다.

| 버전 | 바꾼 것 | 결과 |
|---|---|---|
| v1 | 자유 추천 | 위험한 놀이 · 없는 재료 · 줄글 |
| v2 | JSON 형식, 재료는 input.materials만 | 형식·재료는 해결, 작은 부품 놀이는 그대로 |
| v3 | `avoid` 기준 전달 + 화면에서 `screenAi()`로 최종 거름 | 위험한 놀이가 화면에 나오지 않음, 걸러낸 이유 표시 |
