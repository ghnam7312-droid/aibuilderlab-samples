# 안내한장

> 법령 개정 하나를 고객사마다 맞춘 안내문으로 바꾸고, 초안의 **시행일·금액을 공식 고시와 대조**한 뒤 **근거 링크를 붙여** 발송 대기에 넣는 도구

> **알림** AI 빌더랩 스타트업 트랙 **1기 목표 모델(가상의 수강생 ‘노무한눈’)** 의 예시 프로젝트입니다. 고객사는 모두 가상이고, **개정 내용·금액·시행일·고시 링크는 샘플 값**입니다(실제 법령 수치가 아님). 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 최저임금·근로시간 같은 개정 때마다 고객사별 안내문을 하나하나 썼다 | 개정 항목 × 고객사를 고르면 맞춤 초안이 바로 → **고객사당 30분 → 5분** |
| 어느 고객사에 보내야 하는지 매번 따졌다 | 시급제 직원·교대/연장 근무 여부로 **안내 대상**을 거른다 (사무소 기준, 법적 적용 판단 아님) |
| AI 초안의 **시행일이 틀렸다** | 초안의 모든 날짜·금액을 고시 정보와 대조해 다르면 **발송을 막고**, 공식 고시 링크를 함께 붙인다 |
| 대조를 했는지 남지 않았다 | ‘고시 원문과 대조했어요’를 눌러야 발송 대기에 들어가고, 대기 목록에 대조 기록이 남는다 |
| 고객사 22곳 관리 | 개정별 대상·검토 중·대기 수를 한눈에 (목표치 **22곳**) |

## 주요 기능

- **개정 항목** — 시행일까지 남은 날(D-n), 대상 고객사 수, 대기 수. 공식 고시 정보(시행일·금액·링크)는 대조 기준이며 고칠 수 있습니다.
- **고객사** — 대상만 보기, 상태(작성 전 · 검토 중 · 발송 대기).
- **안내문 초안** — 틀 초안 즉시 → Claude 초안이 오면 덮어씀. 제목·본문을 고치면 대조를 다시 합니다.
- **고시 대조** — `막음`(시행일 불일치·시행일 없음·고시에 없는 금액·링크 없음), `확인`(정부 도메인 아님·단정적 법적 표현), `참고`(샘플 링크), `통과`.
- **발송 대기** — 넣기·빼기 + 되돌리기, 대기 목록 `.txt` 내려받기(담당자 이름 가림).

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `labornotice.draft` → `normalizeDraft` → 링크가 빠졌으면 사람이 넣은 링크를 붙임 → `checkDraft` 대조 | `Claude로 작성 · 2.3초` + 대조 결과 |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 틀 초안 유지 | `틀 초안 (규칙 기반) · (이유)` |
| 응답 형식이 틀림 | 버리고 틀 초안 유지 | `… · 응답 형식이 맞지 않음` |
| Claude 초안의 시행일·금액이 고시와 다름 | 초안은 보여 주되 **발송 막음**, ‘틀 초안으로’ 또는 직접 고치기 | `막음 · 날짜 ‘…’가 고시 시행일과 달라요` |

샘플에는 예전에 문제가 됐던 ‘시행일이 틀린 AI 초안’(온새미 분식)이 들어 있어 처음 화면에서 대조가 막는 모습을 볼 수 있습니다. 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).
