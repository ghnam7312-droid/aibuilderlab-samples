# 구조

```mermaid
flowchart TB
  A[개정 항목<br/>시행일 · 금액 · 고시 링크] --> T{affected<br/>안내 대상?}
  C[고객사<br/>업종 · 인원 · 시급제 · 교대] --> T
  T -- 대상 --> R[ruleDraft<br/>틀 초안 · 즉시 표시]
  T -- 대상 --> AI["/api/demo/ai · labornotice.draft"]
  AI --> CL[Claude API]
  CL --> N{normalizeDraft}
  N -- 통과 --> L[ensureLink<br/>사람이 넣은 링크 붙이기]
  N -- 형식 오류 · 연결 안 됨 --> R
  L --> D[초안]
  R --> D
  D --> CHK{checkDraft<br/>고시 대조}
  A --> CHK
  CHK -- 막음 --> FIX[고치기 · 틀 초안으로]
  FIX --> CHK
  CHK -- 통과 + 사람 대조 확인 --> Q[발송 대기]
  Q --> TXT[.txt 내려받기<br/>담당자 이름 가림]
```

## 대조 규칙 (`checkDraft`)

| 단계 | 내용 | 결과 |
|---|---|---|
| 날짜 | 제목·본문의 모든 날짜(2027년 1월 1일 / 2027-01-01 / 2027. 1. 1.)가 고시 시행일과 같은가 | 다르면 `막음` |
| 시행일 | 시행일이 한 번이라도 적혀 있는가 | 없으면 `막음` |
| 금액 | 본문의 원 금액이 고시 정보(변경 전·후) 안에 있는가 | 아니면 `막음` |
| 링크 | https 주소이고 본문에 그대로 있는가 / .go.kr 인가 | 없으면 `막음`, 정부 도메인 아니면 `확인`, 샘플이면 `참고` |
| 표현 | “위반입니다·과태료가 부과됩니다” 같은 단정 표현 | `확인` (노무사가 직접 검토) |
| 사람 | ‘고시 원문과 대조했어요’ | 없으면 발송 대기 불가 |

AI가 링크를 빼먹으면 `ensureLink()`가 사람이 넣은 링크를 붙입니다. 링크는 AI가 만든 것을 쓰지 않습니다.
