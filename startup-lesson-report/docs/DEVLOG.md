# 오늘수업 개발 일지 (창업 트랙 5주차)

> **1기 목표 모델**: 가상의 수강생 ‘스피킹메이트’(영어 회화 튜터 6년 차)가 이렇게 진행하는 것을 목표로 쓴 일지입니다. 실제 수강생의 기록이 아닙니다.
> 숫자는 COVI 학습 기록 기준이며, 포트폴리오에 적은 합계와 같습니다.

| 시기 | 만든 것 | 프롬프트 | 디버깅 | 시간 |
|---|---|---|---|---|
| 5주차 1일 | 메모 나누기, 규칙 초안 (보호자 / 본인) | 9 | 1 | 1.5h |

| 5주차 4일 | 보내기 · 되돌리기, 발송 기록, 테스트 | 5 | 0 | 1.0h |
| **합계** | | **30** | **4** | **5h** |

## 1일 — 1시간이 어디서 새는지

**한 일**
- 수업 뒤 피드백 1시간을 재 보니: 수업 노트 다시 읽기 10분, 학생별로 카톡 쓰기 40분, 보호자·본인 말투 고치기 10분.
- 수업 중에 쓰던 메모 형식(`이름: 내용`)을 그대로 읽어 학생별로 나누고, 틀에 넣어 초안을 만들었다.

**막힌 것 → 해결**
- 한 학생 메모가 두 줄로 넘어가면 둘째 줄을 놓침 → 이름 없는 줄은 바로 위 학생에게 이어 붙임.

---

## 2일 — 초안을 사람처럼

**한 일**
- `lessonreport.draft`로 Claude가 보호자용 / 본인용 문장을 씀. 학생마다 따로 부르고, **그 학생 메모만** 보낸다.

**막힌 것 → 해결**
- 메모에 없는 칭찬(“발음이 많이 좋아졌어요”)을 지어냄 → 지시문에 “메모에 있는 내용만, 지어내지 않는다”, 학생 이름이 없거나 너무 짧으면 버림.

---

## 3일 — 발송 직전에 멈춘 메시지

**한 일**
- 처음엔 ‘모두 보내기’ 버튼 하나였다. 시험 삼아 내 번호로 보내 보려던 직전, 도현 님 메시지에 **하윤 학생 이름**이 들어 있는 걸 발견했다. 메모에 ‘하윤이랑 짝 활동 때…’라고 적은 게 그대로 들어간 것.
- 다른 학생 보호자가 받았다면 신뢰를 잃는 일이라, **보내기 전 미리보기 확인 단계**를 넣었다.
  - 메시지마다 명단의 다른 학생 이름을 찾아 빨갛게 표시하고 보내기를 막는다.
  - ‘그 문장 지우기’ 또는 ‘의도한 언급이에요’를 골라야 풀린다.
  - 튜터가 한 건씩 ‘미리보기 확인’을 눌러야 보낼 수 있고, 확인 뒤 고치면 확인이 풀린다.

**막힌 것 → 해결**
- ‘서아’를 찾다가 ‘서아영’ 같은 다른 이름 안의 글자에도 걸림 → 받는 학생 본인 이름 안에 든 경우는 빼고, 명단 이름만 비교.
- AI가 메모에 없던 다른 학생과 비교하는 문장을 씀(“서아보다 잘했어요”) → 메모에 없던 다른 학생 이름이 나오면 응답을 버림.

## 4일 — 보낸 뒤

**한 일**
- 확인한 건만 보내기, 5초 안 되돌리기. 발송 기록에는 가린 번호와 글자 수만 남기고 본문은 남기지 않는다.
- 로직을 `logic.js`로 분리하고 테스트 12개.

**결과 (1기 목표치)**
- 피드백 작성 1시간 → 15분, 재등록률 72% → 85%
