> **1기 목표 모델**: 가상의 수강생 ‘숫자읽는사람’이 이렇게 진행하는 것을 목표로 쓴 일지입니다. 실제 수강생의 기록이 아닙니다.
> 숫자는 COVI 학습 기록 기준이며, 포트폴리오에 적은 합계와 같습니다.

## 4주차 전반 — 이틀이 어디서 드는지

**한 일**
- 300건 분류를 재 보니: 읽기 · 분류 정하기가 대부분이고, 애매한 응답을 두고 조교들끼리 다시 맞추는 데도 시간이 들었다.
- 구글 시트를 ‘원문 / 자동 분류 / 근거 / 사람 검수 / 일치’ 열로 설계.
- 응답에 학번 · 전화번호가 섞여 있어서, 받는 즉시 가리고 가린 글만 쓰기로 했다.

**막힌 것 → 해결**
- `2026년` 같은 연도까지 학번으로 가려짐 → 학번은 앞뒤에 숫자가 없는 8자리(20으로 시작)만.

---

## 4주차 후반 — 돌릴 때마다 다른 답

**한 일**
- “이 응답을 주제별로 분류해 줘”로 AI 분류를 붙였다.

**막힌 것 → 해결**
- 같은 300건을 두 번 돌렸더니 분류 이름부터 달랐다(‘수업’ / ‘강의 방식’ / ‘교육 방법’). 같은 응답이 실행마다 다른 갈래로 가기도 했다.
- 분류가 매번 달라짐 → **분류 기준 5개와 예시를 고정**해서 지시문에 넣고, 응답은 그 이름 중 하나만 고르게 했다.
- 기준 밖 이름(‘기타’)이 계속 섞여 옴 → 기준 이름이 아니면 그 항목만 버리고 규칙 결과를 쓰는 검사 추가.

---

## 5주차 전반 — 규칙도 같은 기준으로

**한 일**
- 같은 기준 표(`CRITERIA` v3)에 핵심어를 붙여 규칙 분류를 만들었다. AI가 안 될 때도, 될 때도 같은 기준.
- 동점이면 기준 순서가 앞선 쪽으로. 무작위로 갈리는 곳을 없앴다.
- 기준 예시 문장이 자기 갈래로 가는지 테스트로 묶음 — 첫 예시가 ‘안내’ 때문에 학과 운영으로 가서 예시 문장을 고침.

**막힌 것 → 해결**
- 띄어쓰기가 달라 ‘전공 선택’ / ‘전공선택’이 다르게 잡힘 → 비교 전 공백 제거.

---

## 5주차 후반 — 믿을 수 있는 숫자로

**한 일**
- 사람 검수 칸과 **일치율**(검수한 것 중 자동 분류와 같은 비율). 샘플 22건 검수 → 20건 일치, 91%.
- ‘같은 결과인지 확인’: 순서를 섞어 3번 돌려 결과 비교.
- 폭언 · 괴롭힘 같은 응답은 자동 분류하지 않고 AI에도 보내지 않게 — 담당 교수가 직접 읽는다.
- 로직을 `logic.js`로 분리하고 테스트 12개.

**결과 (1기 목표치)**
- 분류 이틀 → 40분
- 사람 검수 일치율 91%
