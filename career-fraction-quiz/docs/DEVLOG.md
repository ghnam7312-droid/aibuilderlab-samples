## 3주차 전반 — 점수 뒤에 숨은 이유

**한 일**
- 교육 봉사에서 모은 분수 오답지를 다시 보니, 같은 50점이라도 틀린 이유가 제각각이었다.
- 자주 보이는 오답을 다섯 가지로 묶었다: 분자·분모 따로 더하기, 분모가 크면 큰 분수, 똑같이 나누지 않아도 분수, 크기가 같은 분수를 다르게 봄, 대분수·가분수 바꾸기 오류.
- 오답 선지 하나하나가 어떤 오개념에서 나오는지 정해 문항 10개를 만들었다.

**막힌 것 → 해결**
- 한 유형이 문항 하나에만 나와서, 한 번 실수한 아이도 그 유형으로 찍힘 → 유형마다 문항 2개 이상, ‘확실(2번 이상)’과 ‘의심(1번)’을 나눔.

## 3주차 후반 — 고른 번호만으로 채점과 분류

**한 일**
- 학생 풀이 화면. 그림 선지(색칠한 1/4)는 SVG로 그렸다.
- 고른 번호를 받으면 점수와 유형별 오답 수가 바로 나오는 `grade()`. 손 채점 1시간이 제출 즉시로.

**막힌 것 → 해결**
- 안 푼 문항이 `undefined`라 오개념 개수가 NaN → 안 푼 문항은 ‘blank’로 따로 세고 오개념에서 뺌.
- 단순 계산 실수까지 오개념으로 셈 → 선지 판정에 `etc`(단순 실수)를 두고 세지 않음.
- 제출 버튼을 두 번 누르면 같은 학생이 두 번 들어감 → 번호로 덮어쓰도록 저장 구조를 바꿈.

## 4주차 전반 — 아이 이름이 주소에 보였다

**한 일**
- 교사 화면: 반 전체 학생 × 다섯 유형 표. 유형 칸을 누르면 그 오개념이 있는 학생만.

**막힌 것 → 해결**
- **아이 이름이 화면 주소에 노출됨** → 처음엔 `?name=김○○`로 학생을 구분했는데, 주소창·방문 기록·공유 링크에 이름이 그대로 남았다. 학생 화면 주소를 `#/solve/07`처럼 **번호로 바꾸고, 이름은 교사 화면 명단에서만 번호 옆에 붙이도록** 고쳤다. 주소나 내보낼 글에 명단의 이름이 들어 있으면(인코딩된 형태 포함) 막는 `addressSafe()`와 테스트를 추가했다.
- 수업 중 화면을 TV로 띄우면 이름이 다 보임 → ‘이름 가리기(화면 공유용)’ 토글.

## 4주차 후반 — 교사에게 건넬 한 문단

**한 일**
- 학생을 고르면 유형마다 “아이가 어떻게 생각했는지 + 교실에서 할 활동”을 보여 준다. 규칙 설명이 먼저, Claude 설명(`fractionquiz.explain`)이 오면 덮어쓴다.
- Claude에는 번호와 틀린 문항, 유형 수만 보낸다. 이름은 보내지 않는다.
- CSV 내보내기(번호·점수·문항별 답·유형).
- 로직을 `logic.js`로 분리하고 테스트 12개.

**막힌 것 → 해결**
- Claude가 오답이 없는 유형까지 설명에 넣음 → 규칙이 센 오답 수가 0인 유형은 버리는 `normalizeExplain()`.
- 엑셀에서 CSV 한글이 깨짐 → 파일 앞에 BOM을 붙임.

**결과 (1기 목표치)**
- 학생 63명 사용, 오개념 유형 5개 자동 분류 · 채점 1시간 → 즉시
