# 금요보고 — 주간 성과 보고서 자동 생성

> 일별 숫자만 넣으면 **핵심 숫자 · 일별 차트 · 요약 문장 · 메일 본문**까지 A4 한 장으로 만들어 주는 도구

![금요보고 화면](screenshot.png)

**데모** https://aibuilderlab.kr/demo/ax-weekly-report/

> AI 빌더랩 직장인 AX 트랙 **1기 목표 모델 예시**입니다. 가상의 온라인몰 2주치 샘플 데이터로 동작합니다.

## 문제 → 해결

| 전에는 | 이제는 |
|---|---|
| 금요일마다 숫자를 여기저기서 복사해 보고서 작성 (**1시간**) | 숫자만 옮겨 적으면 보고서 완성 (**10분**) |
| 차트 날짜가 하루씩 밀려 보임 | 모든 날짜를 **한국 시간(KST)** 기준으로 계산 |
| 동료에게 넘기기 어려움 | 안내서와 자동 발송 설정까지 포함 |

## 주요 기능

- **숫자 입력** — 이번 주/지난주 7일(금~목) 매출·주문·방문. 고치는 즉시 보고서에 반영, Enter로 아래 칸 이동
- **입력 검증** — 숫자가 아닌 글자, 빈 칸, 방문보다 많은 주문을 바로 알려 주고 고칠 때까지 보고서는 이전 숫자 유지
- **보고서 만들기** — A4 종이 위에 제목 → 핵심 숫자(올라가는 숫자) → 막대가 자라는 차트 → 전환율 선 → 요약 순서로 채워짐
- **핵심 숫자 5개** — 매출 · 주문 · 방문 · 전환율 · 객단가와 지난주 대비 증감
- **일별 흐름 차트** — SVG로 직접 그린 막대(지난주·이번 주) + 전환율 선, 매출/주문/방문 전환, 휴일(한글날) 표시, 마우스를 올리면 같은 요일 비교
- **이번 주 요약 (데모: 브라우저 규칙 기반)** — 증감률, 최고·최저 요일, 휴일 효과, 전환율·객단가, 상품 1위 변화로 문장 작성
- **많이 팔린 상품** — 순위와 지난주 대비 순위 변화
- **메일 본문 복사 · PDF로 저장(인쇄)**
- **발송 설정** — 매주 금 17:00 자동 발송(시뮬레이션), 받는 사람 이메일 검증, 발송 기록
- **사용 안내서** — 처음 쓰는 동료용 5단계

## 화면 구성

```
┌ 숫자 입력 | 발송 설정 | 안내서 ┐ ┌──────── A4 보고서 ────────┐
│ 이번 주 / 지난주                 │ │ 10월 9일–15일 주간 성과 보고 │
│ 10/9(금) 한글날  6,120,000  92 │ │ 매출 · 주문 · 방문 · 전환율 · 객단가 │
│ ...                            │ │ ▮▮ ▮▮ ▮▮  일별 흐름 + 전환율 선 │
│ 합계                            │ │ 요약 1·2·3 · 상품 순위 · 메일 본문 │
└───────────────────────────────┘ └──────────────────────────┘
```

## 기술 스택

| 이 데모 | 실제 업무 버전 |
|---|---|
| HTML · CSS · JavaScript (프레임워크 없음) | 데이터 정리 · 차트 · 자동 발송 |
| SVG 차트 직접 구현, `Intl.DateTimeFormat`(Asia/Seoul) | 판매 시스템 집계 |
| localStorage 저장, `@media print`로 A4 인쇄 | 메일 자동 발송 |
