# 끝까지

> 뉴스레터 글마다 클릭과 **끝까지 읽은 비율**을 함께 보고, 낚시성 제목을 걸러 낸 뒤 다음 호 주제를 추천하는 도구

**데모** · https://aibuilderlab.kr/demo/startup-news-insight/index.html

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘업계한장’)** 의 예시 프로젝트입니다. 뉴스레터 41~48호의 글·숫자는 모두 가상이며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 어떤 글이 반응이 좋은지 감으로만 판단했다 | 호별 열람률·유료 전환율 추이와 글별 순위를 한 화면에 |
| **클릭 수만 보다 낚시성 제목이 1등** | 끝까지 읽은 비율(완독률)을 함께 보는 ‘완독 점수’로 순위. 클릭률은 높은데 완독률이 낮은 글은 **낚시 의심** 표시 |
| 다음 호 주제를 그때그때 정했다 | 주제별 평균 완독 점수로 다음 호 주제 3개 추천 + 낚시 글이 많은 주제 주의 |
| 제목을 정할 때 기준이 없었다 | 제목을 넣으면 지난 호에서 완독률이 낮았던 표현을 찾아 숫자로 알려 줌 |

결과 (1기 목표치): **열람률 38% → 51%, 유료 전환 1.2% → 3.4%**

## 주요 기능

- **두 기준 순위** — ‘클릭 수’와 ‘완독 반영’을 오가면 자리가 몇 칸 움직였는지(▲▼) 보여 줍니다. 샘플에서는 클릭 1~3위가 모두 낚시 의심 글이고, 완독을 반영하면 20~22위로 내려갑니다.
- **지표 정의를 화면에** — 클릭률 = 클릭 ÷ 그 호 열람자 · 완독률 = 끝까지 읽음 ÷ 클릭 · 완독 점수 = 열람자 100명당 끝까지 읽은 사람.
- **기다리지 않는 추천** — 규칙 추천이 즉시 나오고, Claude 추천이 오면 검사를 거쳐 덮어씁니다.
- **제목 점검** — 지난 호 데이터로 ‘이 표현이 든 글은 완독률이 몇 %였는지’ 알려 줍니다.
- **기간 거르기(최근 4호 / 8호) · 데이터 바꾸기(CSV 붙여 넣기, 틀린 줄은 이유와 함께 건너뜀) · CSV 내려받기**

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `newsinsight.recommend` (계산이 끝난 주제별 합계만 보냄) → 검사 | `Claude로 추천 · 1.8초` |
| 없는 주제 · input에 없는 숫자 · 낚시성 제목 아이디어 | 없는 주제는 빼고, 숫자를 지어낸 이유는 규칙 문장으로, 낚시성 제목은 비움 | — |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 주제별 평균 완독 점수로 3개 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 추천 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).
