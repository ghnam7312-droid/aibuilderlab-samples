# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 서버 작업 정의(`docs/ai-task.json`) 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 4개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 1일 | 약속 찾기 | 미팅 메모에서 우리가 ‘보내드리기로·전달하기로’ 한 줄을 찾아 자료 이름과 기한을 뽑아 줘. 고객이 회신하기로 한 건 빼고, 기한이 없으면 영업일 2일 뒤로. |
| 3일 | 내부 분리 | 메모를 줄마다 고객 공유 / 내부 전용으로 나눠 줘. (내부) 표시나 마지노선·원가·할인 한도·경쟁사 단가 같은 말이 있으면 내부. 메일 초안과 AI에는 고객 공유 줄만 넣어. |
| 3일 | 섞임 검사 | 메일 초안에 내부 줄의 금액·%나 민감한 낱말, 비슷한 문장이 있으면 찾아서 복사 버튼을 막아 줘. 어느 줄 때문인지도 보여 줘. |
| 4일 | 캘린더 | 안 보낸 약속만 .ics로 내보내 줘. 기한일 종일 일정, 전날 오전 9시 알림, 한글 제목 안 깨지게 75바이트 접기. |

## 2. 서비스가 쓰는 지시문 (`followup.draft`)

```
영업 미팅 뒤 고객에게 보낼 후속 메일 초안을 쓴다. 보내는 사람은 input.sender(회사·이름), 받는 사람은
input.contact(input.customer 소속). 본문은 1) 미팅 감사 인사 한 문장, 2) input.points에서 고객과 나눈 내용
2~3개를 고객이 읽기 좋은 존댓말로 정리, 3) input.promises의 자료마다 '자료명: M/D(요일)까지' 한 줄,
4) 짧은 마무리와 보내는 사람 이름 순서로 쓴다. input에 있는 내용만 쓰고, 없는 자료·날짜·금액·할인 조건은
지어내지 않는다. 가격 협상 여지, 할인 한도, 원가, 경쟁사, 사내 보고 같은 내부 사정은 쓰지 않는다.
subject는 40자 이내. 모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"subject":"","body":""}
```
- 입력: `{ customer, contact, sender, meetingDate, today, points(고객 공유 줄만), promises[{item,due}] }` · 최대 900토큰
- 화면 검사: `normalizeDraft()` → `leakCheck()` (걸리면 버리고 규칙 초안)

## 3. 왜 이렇게 썼나

- **지시문보다 입력이 먼저** — “내부 사정은 쓰지 말라”고 해도, 입력에 있으면 섞일 수 있습니다. 그래서 내부 줄은 아예 보내지 않고, 지시문의 금지 문장은 두 번째 안전장치로 둡니다.
- **약속 날짜는 우리가 계산해서 넘긴다** — 기한(`due`)은 화면이 YYYY-MM-DD로 계산해 보내므로, Claude가 날짜를 새로 셈하지 않습니다.
- **순서를 정했다** — 감사 → 나눈 내용 → 약속 자료 → 마무리. 고객이 ‘언제 무엇이 오는지’를 바로 찾을 수 있게.

## 4. 실패했던 이전 버전

| 버전 | 지시문 · 입력 | 결과 |
|---|---|---|
| v1 | “이 미팅 메모로 고객에게 보낼 후속 메일을 써 줘.” + 메모 전체 | 내부 줄의 “할인은 최대 8%”가 “할인은 최대 8%까지 가능합니다”로 초안에 들어감. 경쟁사 얘기도 한 번 섞임 |
| v2 (지금) | 고객 공유 줄만 입력 · 내부 사정 금지 문장 · 화면 섞임 검사 | 내부 숫자·낱말이 초안에 나오지 않음. 혹시 나오면 화면이 버림 |
