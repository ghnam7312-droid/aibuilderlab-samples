# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 [ai-task.json](ai-task.json)에 있는 서버용 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 4개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 4주 | 분류 | 문의 문장을 재료, 환불, 수강 기간, 영상·접속, 기타로 나눠 줘. 환불 관련 말이 하나라도 있으면 다른 것보다 먼저 환불로. |
| 4주 | 환불 계산 | 이 환불 규정 5개 조항을 함수로 만들어 줘. 결제일, 시청 강의 수, 전체 강의 수, 키트 발송·반송을 받아서 금액과 적용한 조항 번호를 돌려줘. |
| 4주 | 응답 검사 | AI 답변 초안에 환불, 환급, 보상 같은 말이 있거나 없는 FAQ 번호를 대면 null을 돌려주는 함수와 테스트를 써 줘. |
| 4주 | 가리기 | 이름은 성만 남기고 ○로, 문장 속 휴대폰 번호와 이메일은 가리는 함수를 만들어 줘. |

## 2. 서비스가 쓰는 지시문 (`classfaq.reply`)

공통 꼬리말: `모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.`

```
온라인 그림 클래스에 들어온 수강 문의 한 건에 답변 초안을 쓴다. input.faq(운영자가 쓴 질문과 답)
안의 내용으로만 답하고, faqId에는 근거로 쓴 FAQ id를 넣는다(맞는 FAQ가 없으면 빈 문자열).
category는 재료, 수강 기간, 영상·접속, 기타 중 하나. 환불·취소·금액·보상에 대해서는 어떤 내용도
쓰지 않는다(환불은 규정 문서로 따로 답한다). FAQ와 input에 없는 사실(날짜, 금액, 약속)을 지어내지
않는다. 인사 한 줄로 시작하고, 수강생 이름은 쓰지 않는다.
출력 형식: {"category":"","reply":"","faqId":"F01"}
```
- 입력: `{ question, category, faq:[{id, q, a}] }` — question은 전화번호·이메일을 가린 문장, 이름은 보내지 않음 · 최대 500토큰
- 이 작업은 FAQ 갈래에만 쓴다. 환불·분쟁·규정 밖 사정 문의는 화면이 아예 호출하지 않는다(`aiAllowed`).
- 화면 검사: `normalizeReply()` — 돈 얘기, 범주 ‘환불’, 없는 FAQ 번호, 길이

## 3. 왜 이렇게 썼나

- **지시문만으로 막지 않는다.** “환불은 쓰지 마”라고 써도 문의에 환불 얘기가 섞이면 AI가 답하고 싶어 한다. 그래서 환불 문의는 보내지 않고(화면), 돌아온 답에 돈 얘기가 있으면 버린다(검사). 지시문은 세 겹 중 하나다.
- **FAQ 번호를 받는다.** 어느 답을 근거로 했는지 알아야 FAQ 정리 숫자를 셀 수 있다.

## 4. 실패했던 이전 버전

```
우리 클래스 FAQ와 환불 규정을 줄게. 수강생 문의에 친절하게 답해 줘.
```
- 결과: “10강까지 들었는데 환불되나요?” → “수강 기간 내라면 전액 환불 가능합니다. 언제든 말씀해 주세요.”
- 문제: 규정(남은 강의 비율 · 재료비 차감)과 다른 금액을 약속. 돈이 걸린 답이라 한 번이라도 틀리면 안 된다.
- 고친 점: 환불을 AI에서 빼고 규정 문서 계산으로, AI는 FAQ 갈래만.
