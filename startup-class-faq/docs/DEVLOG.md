# 답해둠 개발 일지 (스타트업 트랙 4주차)

> **1기 목표 모델**: 가상의 수강생 ‘그림한스푼’이 이렇게 진행하는 것을 목표로 쓴 일지입니다. 실제 수강생의 기록이 아닙니다.
> 숫자는 COVI 학습 기록 기준이며, 포트폴리오에 적은 합계와 같습니다.

| 시기 | 만든 것 | 프롬프트 | 디버깅 | 시간 |
|---|---|---|---|---|
| 4주차 1일 | 문의 모으기 · 분류 · FAQ 8개 | 8 | 1 | 1.5h |
| 4주차 2일 | Claude 답변 초안 → 환불 오답 → 규정 문서로 분리 | 10 | 1 | 1.5h |
| 4주차 3일 | 사람에게 넘기기 · 가리기 · FAQ 정리 · 테스트 | 7 | 1 | 1h |
| **합계** | | **25** | **3** | **4h** |

## 4주차 1일 — 하루 20번 같은 답

**한 일**
- 일주일 문의를 모아 보니 재료(키트 배송 포함), 환불, 수강 기간, 영상 재생이 대부분이었다. 하루 20건쯤, 한 건 답하는 데 3분.
- 낱말 규칙으로 분류하고, 내가 쓰던 답을 FAQ 8개로 정리했다.
- 질문 말투가 제각각이라 같은 낱말이 없어도 찾도록 두 글자 조각 겹침으로 가장 가까운 FAQ를 고른다.

**막힌 것 → 해결**
- “작품 전시도 하나요?” 같은 새 질문이 아무 FAQ에나 붙음 → 겹침 30% 미만이면 ‘맞는 FAQ 없음 · 직접 답변’으로.

---

## 4주차 2일 — AI가 환불 규정과 다르게 답했다

**한 일**
- Claude에게 FAQ를 주고 답변 초안을 쓰게 했다. 재료·기간 질문은 잘 썼다.
- 그런데 “10강 들었는데 환불되나요?”에 “수강 기간 내라면 전액 환불 가능합니다”라고 썼다. 우리 규정은 남은 강의 비율만큼이고, 키트를 받았으면 재료비를 뺀다.
- **해결: 환불은 AI에 보내지 않는다.** 환불 규정 문서를 조항으로 나누고, 주문 정보(결제일·시청 강의·키트 발송)로 `refundCalc()`가 금액과 조항을 정한다. 답변에는 조항 원문을 그대로 붙인다.
- 분류에서 ‘환불·취소·돌려받’ 같은 말이 하나라도 있으면 다른 범주보다 먼저 환불로 보낸다.

**막힌 것 → 해결**
- FAQ 질문인데 AI 초안에 “어려우면 일부 환불해 드릴게요”가 끼어듦 → 응답에 환불·환급·보상 같은 말이 있으면 버리는 검사(`normalizeReply`) 추가.

---

## 4주차 3일 — 사람이 봐야 하는 문의

**한 일**
- “소비자원에 신고할게요”, “입원해서…” 같은 문의는 규칙도 AI도 답하지 않고 ‘운영자가 직접 답변’으로 넘긴다. 규정 5항(규정에 없는 사정은 운영자가 확인)과 맞췄다.
- 이름은 화면에서 `윤○○`으로, 문의 속 전화번호·이메일은 가리고, AI에는 이름을 보내지 않는다.
- 오늘 문의가 어느 FAQ로 답해졌는지 세어서 많이 걸린 순서로 FAQ 마크다운을 만든다. 수업 안내 페이지 위쪽에 붙였다.
- 로직을 `logic.js`로 분리하고 테스트 14개.

**막힌 것 → 해결**
- 1,000원 단위 버림을 키트 재료비를 뺀 뒤에 해서 금액이 달라짐 → 규정 순서대로 ‘비율 계산 → 버림 → 재료비 빼기’로 고정하고 테스트.

**결과 (1기 목표치)**
- 반복 문의 응대 하루 1시간 → 15분
