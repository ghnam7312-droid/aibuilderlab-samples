# 들어보니 — 고객 인터뷰 보드

> 만들기 전에 먼저 들어 봅니다. 인터뷰를 카드로 붙이고 근거를 태그하면, 가설 도장이 **검증 중 → 검증됨 / 반증됨**으로 바뀌는 보드예요.

![들어보니 보드 화면](./screenshot.png)

**데모:** https://aibuilderlab.kr/demo/startup-interview-board/

> 이 저장소는 **AI 빌더랩 창업 트랙 1기 ‘목표 모델’ 예시**입니다. 수료생이 이 수준까지 만든다는 목표를 보여 주려고 만들었고, 인터뷰 대상 15명은 모두 가상 인물입니다. 데모는 샘플 데이터로 동작합니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 다른 학원도 같은 문제를 겪는지, 원장님이 돈을 낼 만큼 불편한지 몰랐습니다. | 원장 6명 · 강사 5명 · 학부모 4명을 만나 카드로 모으고, 가설 2개에 대한 근거를 셉니다. |
| 처음 질문이 ‘쓰시겠어요?’처럼 답을 유도해서 다들 ‘좋다’고만 했습니다. | 지난달 실제로 한 일을 묻는 질문으로 바꾸고, 새 질문을 넣으면 유도 질문인지 바로 점검합니다. |
| 가격을 얼마로 잡아야 할지 근거가 없었습니다. | 원장 응답을 모아 분포를 보고 ‘월 10만 원 이하’라는 기준을 정했습니다. |

## 주요 기능

- **가설 도장:** H1 “원장·강사는 학부모 리포트에 한 달 4시간 넘게 쓴다”, H2 “원장은 월 10만 원 이하라면 리포트 도구에 돈을 낸다”
  - 확정한 근거가 지지 3건 이상이고 반증의 2배 이상이면 ‘검증됨’, 반증이 더 많으면 ‘반증됨’ 도장이 찍힙니다.
- **근거 태그 (제안 → 확정):** 카드마다 기록된 숫자(리포트에 쓴 시간, 낼 수 있는 금액)로 ‘H1 지지?’ 같은 **제안**이 점선으로 붙습니다. 눌러서 확정해야 근거로 셉니다. 확정한 표시를 다시 누르면 지지 → 반증 → 상관없음으로 바뀝니다.
  - 샘플은 H2가 ‘검증 중’에서 시작합니다. 원장 카드의 제안 하나를 확정하면 도장이 ‘검증됨’으로 바뀌는 것을 볼 수 있어요.
- **인터뷰 기록하기:** 역할·이름·시간·금액·메모를 적는 창. 빈 칸은 바로 알려 주고, 저장하면 보드 맨 앞에 붙습니다. 카드를 지우면 알림에서 되돌릴 수 있어요.
- **인사이트:** 많이 나온 이야기(역할별 색으로 나눈 막대), 역할별로 그대로 옮긴 말
- **질문 설계:** 바꾸기 전 / 후 질문 비교, 질문 점검기, 인터뷰 질문 목록
- **가격 응답:** 원장 응답 분포, 중간값, 가격 기준을 정한 이유

### AI 요약은 어떻게 동작하나요

데모에서는 **브라우저 규칙 기반**입니다. 정해 둔 말 사전(‘엑셀’, ‘캡처’, ‘카톡’, ‘다음 주’ 등)으로 인터뷰마다 주제를 세고, 메모 속 큰따옴표 안의 말을 인용으로 뽑습니다. 유도 질문 점검도 정해 둔 표현(‘~하시겠어요?’, ‘좋을까요’ 등)과 좋은 표현(‘지난달’, ‘몇 시간’, ‘마지막으로’ 등)으로 판단합니다.

## 기술 스택

| | 이 데모 | 실제 작업 (포트폴리오 기준) |
|---|---|---|
| 화면 | HTML · CSS · JavaScript (빌드 도구 없음) | 인터뷰 설계 · AI 요약 · 가설 표 |
| 데이터 | 브라우저 localStorage | 인터뷰 메모 |
| 요약 | 브라우저 규칙 기반 | AI 요약 후 사람이 확인 |

글꼴은 Wanted Sans(화면)와 나눔명조(고객의 말)를 씁니다.

## 폴더 구조

```
startup-interview-board/
├── index.html      화면 뼈대 (탭 4개, 인터뷰 기록 창)

```

## 실행 방법

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html`을 바로 열어도 동작합니다. 상단 ‘← 포트폴리오로’ 링크는 aibuilderlab.kr 사이트 기준 주소입니다. 입력한 내용은 이 브라우저에만 저장되고, 아래 ‘샘플 데이터로 되돌리기’로 처음 상태로 돌아갈 수 있어요.
