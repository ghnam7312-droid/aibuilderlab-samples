> **알림** AI 빌더랩 커리어 트랙 **1기 목표 모델(가상의 수강생 ‘전환율장인’)** 의 예시 프로젝트입니다. 가상의 음료 브랜드 5곳 게시물 18행으로 시작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 경쟁 브랜드 5곳 게시물을 매주 손으로 캡처·정리하느라 3시간 | 시트 범위를 붙여 넣으면 주 거르기 · 브랜드별 집계 · 요약까지 → **3시간 → 25분** |
| 게시물 날짜 형식이 섞여 정렬이 틀렸다 (`2026. 10. 20.`, `10/21`, `24 Oct 2026`, 시트 숫자 `46318` …) | **날짜를 `YYYY-MM-DD` 하나로 바꾸는 단계**를 따로 두고, 읽지 못한 칸은 버리지 않고 ‘확인 필요’로 남겨 직접 넣게 했다 |
| AI 요약이 맞는지 확인할 길이 없었다 | 요약 문장마다 근거 게시물의 **원문 링크**를 붙이고, 링크 없는 문장은 리포트에 넣지 않는다 |
| 바쁜 주에는 리포트를 건너뛰었다 | 발행 기록과 연속 발행 주 수 표시 → **8주 연속 발행** |

## 주요 기능

- **처리 단계 표시** — 붙여넣기 → 날짜 맞추기 → 주 거르기 → 요약 + 원문 링크, 단계마다 몇 건인지.
- **날짜 맞추기** — ISO · 점 구분 · 빗금 · 한글(`2026년 10월 21일 오후 3:12`) · 월/일 · 영문 · 상대 표현(`어제`, `3일 전`) · 시트 숫자. 원문과 맞춘 날짜를 나란히 보여 주고, 못 읽은 행은 그 자리에서 입력.
- **정렬 비교** — ‘날짜 맞추기 전 정렬로 보기’를 켜면 원문 글자 순서로 정렬했을 때 얼마나 틀리는지 보입니다.
- **주간 리포트** — 요약(원문 링크), 브랜드별 게시물 수·반응 합계·대표 게시물, 게시물 목록(브랜드 거르기), 앞·다음 주 이동.
- **보조** — 마크다운 복사(링크 포함), 인쇄(리포트만), 발행 + 되돌리기, 샘플로 되돌리기.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `snsreport.summary` → `normalizeSummary()`가 그 주 게시물 id가 없는 문장을 버림 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 규칙 요약(가장 활발한 브랜드 · 반응 1위 · 많이 쓴 채널 · 공통 낱말), 문장마다 근거 id | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 / 근거 있는 문장이 2개 미만 | 버리고 규칙 요약 유지 | `규칙 기반 · 원문 링크 없는 응답` |

날짜 맞추기와 집계는 AI를 쓰지 않습니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버에 합칠 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 데이터 | 구글 시트에서 복사한 탭 구분 표 (실제 버전은 구글 시트 + Apps Script가 매주 월요일에 실행) |
| 테스트 | Node 내장 `node:test` |
