# 작은집

> 원룸·투룸 리모델링을 맞춤 견적 대신 **패키지**로 팔 때, 최신 단가로 원가·이익·마진을 계산하고 목표 마진에 맞는 판매가와 소개 문구를 만드는 도구

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘공간한컷’)** 의 예시 프로젝트입니다. 단가·인건비는 모두 **가상의 샘플 단가**이고(실제 시세 아님), 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 맞춤 견적만 하다 보니 작은 공사는 남는 게 없었다 | 구성·면적·인건비 일수를 고정한 패키지 3종으로 원가를 미리 계산하고, 목표 마진에 못 미치면 **최소 판매가**를 바로 제안 |
| 자재 단가를 작년 기준으로 계산해 마진이 실제보다 높게 보였다 | 단가마다 **기준일**을 두고 늘 가장 최신 단가로 계산. 작년 단가로 계산했을 때와 나란히 보여 주고, 오래된 단가는 경고 |
| 패키지를 어떻게 소개할지 매번 새로 썼다 | 패키지 구성으로 소개 문구(포함·제외·자주 묻는 질문)를 만들고, 가격은 계산값만 넣는다 |
| 결과(목표치) | 원룸·투룸 패키지 3종, 첫 달 문의 26건 |

## 주요 기능

- **단가 기준 비교** — ‘작년 단가 / 최신 단가’를 바꿔 보면 같은 패키지의 마진이 얼마나 달라 보였는지 바로 보입니다(샘플: 원룸 기본 30.1% → 20.9%).
- **패키지 카드** — 판매가(만 원)를 고치면 원가·이익·마진 막대와 목표선이 바로 바뀌고, 목표 미달·손해면 ‘최소 ○○만 원 적용’ 버튼이 나옵니다.
- **목표 마진 · 관리비** — 슬라이더로 바꾸면 세 패키지가 함께 다시 판정됩니다.
- **패키지 구성** — 항목별 수량(㎡·개·식), 샘플 단가, 단가 기준월, 금액. 인건비 일수를 고칠 수 있습니다.
- **단가표** — 최신 단가를 고치면 기준일이 오늘로 바뀌고 세 패키지가 다시 계산됩니다. 작년 단가와 상승률을 함께 보여 줍니다.
- **내보내기 · 되돌리기** — 패키지 비교 CSV, 소개 문구 복사, 판매가 적용·단가 수정·샘플로 되돌리기의 되돌리기.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `smallpkg.pitch` → 검사(`normalizePitch`) → 소개 문구 교체 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 패키지 구성으로 만든 규칙 문구 | `규칙 기반 · (이유)` |
| 구성에 없는 항목을 넣음 | 그 항목만 빼고, 남는 게 없으면 버림 | `규칙 기반 · 응답 형식이 맞지 않음` |
| 금액·과장 표현(‘최저가’, ‘100%’)이 있음 | 응답 전체를 버림 | `규칙 기반 · 응답 형식이 맞지 않음` |

**금액은 AI가 만들지 않습니다.** 원가·마진·판매가는 늘 `logic.calcPackage()`가 계산하고, 소개 문구의 가격도 그 값을 넣습니다. 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| 계산 | 기준일이 있는 단가 기록 → 패키지별 원가·마진 (`logic.js`) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 내보내기 | CSV (UTF-8 BOM, 엑셀에서 한글 깨짐 없음) |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
startup-small-package/
├── index.html
├── style.css
├── logic.js          단가 고르기 · 오래된 단가 찾기 · 패키지 원가·마진 · 최소 판매가 · CSV · 문구 검사 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            단가 기준 · 패키지 카드 · 구성 · 소개 문구 · 단가표 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```

## 실행 · 테스트

```bash
python3 -m http.server 8000   # http://localhost:8000
npm test                      # = node --test, 12개
```
