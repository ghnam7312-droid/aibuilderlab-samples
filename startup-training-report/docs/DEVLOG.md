## 4주차 — 1주 걸리던 정리를 쪼개 보기

**한 일**
- 지난 3개 고객사 결과 보고에 걸린 시간을 적어 보니: 설문 내려받기·정리 2일, 의견 읽고 요약 2일, 보고서 꾸미기 1일. 교육 담당자는 그동안 윗선 보고를 미루고 있었다.
- 설문 도구에서 내려받는 CSV를 그대로 붙여 넣으면 문항 평균, 역량 자가진단 사전→사후, 추천 지수가 나오는 화면을 만들었다.

**막힌 것 → 해결**
- 의견 안에 쉼표가 있으면 칸이 밀림 → 따옴표 안 쉼표·줄바꿈을 지키는 CSV 파서로 교체.
- 6점, 빈칸 같은 잘못된 점수가 평균을 망침 → 범위를 벗어난 줄은 빼고 ‘n번째 응답’으로 알림.

## 5주차 — 응답자 이름이 리포트에 그대로 나갔다

**한 일**
- 첫 고객사 시험 전달에서 담당자가 “의견에 팀장님 이름이 그대로 있어서 위로 못 올리겠다”고 돌려보냈다. 의견 원문에 응답자와 동료 이름이 섞여 있었고, 3명뿐인 부서는 평균만 봐도 누군지 보였다.
- 익명 처리를 세 겹으로 넣었다: 응답 표는 응답 번호로, 의견 속 이름·연락처는 가리고 순서를 섞기, 5명 미만 부서는 합치거나 숨기기.
- 리포트를 다 그린 뒤 화면 글자 전체에서 응답자 이름을 다시 찾는 마지막 검사를 붙였다. 남아 있으면 복사·인쇄를 막는다.

**막힌 것 → 해결**
- 성+이름만 가렸더니 “도현 팀장님”, “김 팀장”이 남음 → 이름+호칭, 성+직함 패턴을 추가하고 각각 테스트로 고정.
- 오류 메시지에 “김도현 응답의 점수가…”처럼 이름이 찍힘 → 오류 문구도 ‘n번째 응답’으로만.

## 6주차 — 의견 요약을 Claude에게

**한 일**
- `trainingreport.summary`로 Claude가 잘된 점·보완할 점·다음 단계를 쓰게 했다. 입력은 집계 숫자와 가린 의견만.
- 규칙 요약이 먼저 나오고 Claude 결과가 오면 덮어쓴다. 어느 쪽인지 배지로 늘 보인다.
- 메일에 붙일 보고 문구 복사, 리포트 한 장만 나오는 인쇄 화면. 로직을 `logic.js`로 분리하고 테스트 12개.

**막힌 것 → 해결**
- Claude가 의견을 인용하다 가린 이름 대신 다른 이름을 붙여 옴 → 지시문에 “사람 이름·부서·연락처를 쓰지 않는다”, 화면에서는 `normalizeSummary`가 명단으로 한 번 더 가린다.
- 요약이 줄글 한 덩어리로 옴 → 항목별 배열 형식을 고정하고 형식이 틀리면 버림.

**결과 (1기 목표치)**
- 고객사 12곳, 리포트 전달 1주 → 당일, 재계약률 40% → 70%
