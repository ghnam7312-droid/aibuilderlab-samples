# 당일결과

> **알림** AI 빌더랩 창업 트랙 **1기 목표 모델(가상의 수강생 ‘교육효과측정소’)** 의 예시 프로젝트입니다. 고객사·응답자·점수는 모두 가상이고, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 교육이 끝나고 설문을 받아도 정리할 시간이 없어 결과를 1주 뒤에 줬다 | CSV를 붙여 넣고 ‘리포트 만들기’ → 문항 평균·역량 변화·추천 지수·의견 주제가 바로 나온다 (**1주 → 당일**) |
| 응답자 이름이 리포트에 그대로 노출됐다 | 이름은 중복 확인에만 쓰고, 의견 속 이름(성+이름, 이름+호칭, 성+직함)·연락처를 가린 뒤 **집계만** 표시. 마지막에 화면 전체에서 이름을 다시 찾아 `이름 노출 0건`을 확인 |
| 부서가 작으면 평균만으로도 누가 썼는지 보였다 | 응답 5명 미만 부서는 ‘기타’로 합치고, 합쳐도 5명이 안 되면 부서 표에서 뺀다. 부서 필터도 5명 이상 부서만 |
| 의견을 하나씩 읽고 요약했다 | Claude가 집계와 가린 의견만 받아 잘된 점·보완할 점·다음 단계를 쓴다. AI가 꺼져 있으면 숫자·낱말 규칙으로 요약 |

## 주요 기능

- **익명 집계 리포트** — 전체 만족도, 역량 자가진단 사전→사후, 추천 지수(NPS), 문항별 막대(4.0 미만은 주황), 부서별 표.
- **이름 가리기 + 마지막 검사** — 가린 자리는 노란 표시로 보이고, 리포트 위 배지에 ‘의견 속 이름·연락처 n곳 가림’, ‘이름 노출 0건’이 늘 붙는다. 이름이 남으면 복사·인쇄를 막는다.
- **두 가지 예시 과정** — 신임 팀장 리더십(32명, 5명 미만 부서 3곳 합산) · 고객 응대 실무(21명, 3명 부서 숨김).
- **CSV 고치기** — 붙여 넣은 CSV를 바로 고쳐 다시 만들기. 범위를 벗어난 점수·칸이 모자란 줄은 ‘n번째 응답’으로만 알린다(오류 문구에도 이름을 쓰지 않음).
- **보고 문구 복사 · 인쇄/PDF** — 메일·메신저에 붙일 텍스트 보고, 인쇄용 화면은 리포트 한 장만.
- **샘플로 되돌리기**(되돌리기 가능), 응답률 계산을 위한 참석 인원 입력.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `trainingreport.summary` → 형식 검사 → 이름이 섞여 오면 다시 가림 | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 숫자에서 바로 나오는 규칙 요약(4.0 미만 문항, 반복된 아쉬움, 낱말 주제) | `규칙 기반 · (이유)` |
| 응답 형식이 틀림 | 버리고 규칙 요약 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

Claude에는 **집계 숫자와 가린 의견만** 보냅니다. 이름·부서별 원자료는 보내지 않습니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 익명 처리·집계 | 브라우저 안에서 `logic.js` (서버에 설문 원문을 보내지 않음) |
| 테스트 | Node 내장 `node:test` |

실제 버전(포트폴리오 기준)은 Next.js + 설문 폼 + Claude API입니다. 이 데모는 그 핵심 흐름을 정적 파일로 옮겼습니다.

## 폴더 구조

```

```
