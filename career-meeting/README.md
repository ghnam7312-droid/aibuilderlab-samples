# 회의끝

> 회의록을 붙여 넣으면 결정사항과 할 일(담당자·마감)을 찾아 업무판에 올려 주는 도구

![회의끝 화면](./screenshot.png)

**데모** · https://aibuilderlab.kr/demo/career-meeting/

> **알림** 이 저장소의 서비스는 AI 빌더랩 커리어 트랙 **1기 목표 모델(가상의 수강생 ‘새벽기획자’)** 의 예시 프로젝트입니다. 샘플 데이터로 동작하며, 'AI 정리'는 브라우저 안의 규칙으로 흉내 냅니다. Notion에는 직접 연결하지 않습니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 주 3회 회의마다 회의록 정리와 업무 배정에 40분씩 걸렸다 | 회의록을 붙여 넣고 ‘정리하기’ 한 번 → **40분 → 6분** |
| 누가 무엇을 언제까지 하기로 했는지 회의 다음 날이면 흐려졌다 | 할 일마다 담당자·마감을 뽑아 업무판에 올림 |
| 정리한 내용을 Notion에 다시 옮겨 적었다 | Notion에 붙이면 체크리스트가 되는 형식으로 복사 |

## 주요 기능

- **줄마다 무엇인지 표시** — 정리하면 회의록의 줄이 제목·참석·결정·할 일·논의로 칠해지고, 담당자(`@이름`)와 마감(`10/24`, `금요일까지`, `내일`)이 강조됩니다.
- **결과 바로 고치기** — 할 일 표에서 담당·내용·마감을 그 자리에서 고칩니다. 마감 형식이 틀리면 바로 알려 줍니다.
- **업무판** — 할 일 · 진행 중 · 완료. 카드를 끌어 옮기거나(마우스) 화살표 버튼(키보드)으로 옮깁니다.
- **출처 줄 찾기** — 업무판 카드에 마우스를 올리면 그 할 일이 나온 회의록 줄이 표시됩니다.
- **마감 알림 표시** — 지난 마감은 빨강, 이틀 안은 주황(D-1, D-2)으로 보입니다.
- **담당자별 보기 · 삭제 되돌리기 · Notion용 복사**

## 화면 구성

```
┌ 회의록 (고치기 ↔ 표시 보기) ┬ 정리 결과                      ┐
│ 줄마다 결정/할 일/논의 표시 │ 결정사항 · 할 일 표 · 논의      │
│                  [정리하기] │        [할 일 N건 업무판에 올리기] │
└─────────────────────────────┴─────────────────────────────────┘
┌ 업무판: 할 일 │ 진행 중 │ 완료        담당자 필터 · Notion용 복사 ┐
```

## 기술 스택

| 구분 | 이 데모 | 실제 버전 |
|---|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크 없음) | 같은 구성 |
| 회의록 정리 | 줄 단위 규칙 (`app.js`의 `parse`) | AI 요약 |
| 업무 등록 | Notion용 마크다운 복사 | Notion API로 바로 등록 |
| 저장 | 브라우저 localStorage | Notion 데이터베이스 |

## 폴더 구조

## 실행 방법

```bash
python3 -m http.server 8000
# http://localhost:8000 을 엽니다
```

샘플 회의록의 날짜는 여는 날을 기준으로 만들어져, 언제 열어도 마감 표시(D-1, 지남 등)가 살아 있습니다.
