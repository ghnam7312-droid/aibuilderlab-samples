# 프롬프트 기록

> 1기 목표 모델 예시입니다. ‘만들 때 쓴 프롬프트’는 가상의 수강생이 COVI에서 썼다고 가정한 대표 예시이고, ‘서비스가 쓰는 지시문’은 지금 실제로 서버에서 돌아가는 원문입니다.

## 1. 만들 때 쓴 프롬프트 (대표 5개)

| 시기 | 목적 | 프롬프트 |
|---|---|---|
| 3주 | 규칙 정리기 | 회의록을 줄 단위로 읽어서 `@이름`이 있으면 할 일, `결정:`이면 결정, 나머지는 논의로 나눠 줘. 마감은 10/24, 금요일까지, 내일을 읽어. 오늘 날짜는 인자로 받아서 테스트할 수 있게. |
| 3주 | 업무판 | 할 일·진행 중·완료 3단계 칸반을 만들어 줘. 마우스는 드래그, 키보드는 화살표 버튼으로 옮기고, 옮긴 뒤 포커스가 같은 카드에 남게. |
| 4주 | 출처 줄 | AI가 뽑은 할 일 문장이 회의록 어느 줄에서 나왔는지 찾는 함수를 만들어 줘. 띄어쓰기·조사가 달라도 되게 두 글자씩 잘라 겹침으로 비교하고, 담당자 이름이 있는 줄에 가점. |
| 4주 | 응답 검사 | Claude 응답에서 마감이 YYYY-MM-DD가 아니면 비우고, 담당이 비면 '미정', 결정도 할 일도 없으면 null을 돌려줘. |
| 4주 | 캘린더 | 할 일 목록을 .ics로 만들어 줘. 마감일 종일 일정, 하루 전 알림, 쉼표·세미콜론 이스케이프, 한 줄 75바이트 넘으면 UTF-8 기준으로 접기. |

## 2. 서비스가 쓰는 지시문 (서버 `/api/demo/ai`)

공통 꼬리말: `모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.`

### meeting.extract
```
회의록에서 결정사항, 할 일, 논의를 뽑는다. tasks의 owner는 회의록에 나온 이름 그대로,
due는 YYYY-MM-DD (오늘 날짜 input.today 기준으로 '금요일까지', '내일' 같은 표현을 날짜로 바꾼다;
없으면 빈 문자열). 회의록에 없는 내용은 만들지 않는다.
출력 형식: {"title":"","attendees":[""],"decisions":[""],"tasks":[{"owner":"","task":"","due":""}],"discussion":[""]}
```
- 입력: `{ notes, today, weekday }` (회의록 8,000자까지) · 최대 900토큰
- 화면 검사: `normalizeExtract()` → `mergeAi()`로 줄 색을 다시 칠하고 출처 줄을 붙임

## 3. 지시문을 고친 이유

| 버전 | 바꾼 것 | 이유 |
|---|---|---|
| v1 | “회의록 요약해 줘” | 줄글 요약이 와서 업무판에 올릴 수 없음 |
| v2 | 결정·할 일·논의 JSON | 담당이 없는 일에 이름을 지어냄, 마감이 “금요일”로 옴 |
| v3 | 오늘 날짜를 함께 보내고 YYYY-MM-DD 지정, “없는 내용은 만들지 않는다” + 화면 검사 | 마감이 날짜로 오고, 지어낸 담당이 사라짐 |
