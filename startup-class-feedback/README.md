# 한줄더

> 수강생 과제 그림을 분석해 먼저 볼 항목을 고르고, **작가가 직접 쓴 피드백 예시 30개만 보고** 초안을 만든 뒤, 마지막 한 줄은 작가가 쓰는 피드백 보조 도구

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 과제가 몰리면 피드백이 5일씩 밀려 수강생이 중간에 그만뒀다 | 오래 기다린 과제부터 줄 세우고, 초안이 바로 나와 **대기 5일 → 1일** |
| 그림마다 명암·구도를 처음부터 다시 봤다 | 캔버스로 밝기를 읽어 명암 대비·중심 벗어남·화면 채움을 재고, 먼저 볼 항목을 골라 둔다 |
| AI가 작가 스타일과 다른 조언을 했다 (도구 추천, 단정하는 말투) | **내 피드백 예시 30개**만 근거로 쓰게 하고, 근거 예시 번호가 예시 밖이거나 평소 쓰지 않는 표현이 있으면 버린다 |
| AI가 다 써 버리면 클래스의 가치가 사라진다 | 마지막 한 줄은 작가가 직접 써야 ‘보내기’가 열린다 |

결과 (1기 목표치) · 수강생 212명 · 피드백 대기 5일 → 1일 · 완강률 41% → 63%

## 주요 기능

- **대기열** — 오래 기다린 과제부터. 3일 넘은 과제만 보기, 평균·최장 대기일.
- **그림 분석** — 바탕색을 귀퉁이에서 읽고, 그 밖의 밝기로 명암 대비·그림 중심·차지한 넓이를 잰다. 기준을 넘으면 ‘명암’·‘구도·여백’ 항목에 표시.
- **예시 기반 초안** — 고른 항목에 맞는 예시 문장으로 ‘좋은 점 / 다음에 해 볼 것’을 쓰고 근거 예시 번호(`E07`)를 붙인다. 번호를 누르면 예시 목록에서 그 문장을 보여 준다.
- **말투 검사** — 초안을 고치다 평소 쓰지 않는 표현(예: “하십시오”, “포토샵”)이 들어가면 바로 알려 주고 보내기를 막는다.
- **마지막 한 줄** — 작가가 8자 이상 직접 써야 보낼 수 있다. 보낸 뒤 되돌리기.
- **기록 내보내기 (.csv)** — 과제 번호·항목·대기일만. 닉네임과 본문은 빼고 내보낸다.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | `classfeedback.draft` → 근거 예시·말투 검사 → 초안 덮어쓰기 | `Claude로 초안 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 알 수 없는 작업 | 예시 문장을 그대로 가져온 규칙 초안 | `규칙 기반 · (이유)` |
| 예시 밖 번호 · 평소 쓰지 않는 표현 · 형식 오류 | 버리고 규칙 초안 유지 | `규칙 기반 · 예시 밖 내용이라 버림` |
| 기다리는 사이 작가가 초안을 고침 | 고친 초안 유지 | `규칙 기반 · 직접 고친 초안 유지` |

자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버용 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| 그림 분석 | Canvas `getImageData` → 밝기 배열 → `logic.analyze()` |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 테스트 | Node 내장 `node:test` |

실제 버전은 Next.js로 만들고 수강생이 올린 이미지를 분석합니다. 공개 데모는 같은 로직을 정적 파일로 옮겼습니다.
