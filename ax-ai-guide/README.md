# 프롬서랍

> **AI에 넣으면 안 되는 정보 목록을 맨 앞에 둔** 팀 AI 사용 가이드. 공용 프롬프트 12개를 꺼내 채우고, 복사하기 전에 검사하고, 결과물은 검수표 한 장으로 확인합니다.

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘보고서는자동’ · 마케팅팀 주임)** 의 예시 프로젝트입니다. 가상의 쇼핑몰 ‘하루살림’ 마케팅팀(6명)의 가이드로 동작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 팀원마다 AI를 다르게 써서 결과물 품질이 들쭉날쭉했다 | 역할 · 목적 · 대상 · 형식 · 분량 · 조건을 갖춘 **공용 프롬프트 12개 (목표치)** |
| 고객 개인정보를 AI에 넣는 사례가 있었다 | **넣으면 안 되는 정보 목록을 가이드 맨 앞에.** 복사할 때 자동 검사, 있으면 복사를 막고 ‘가리고 복사’만 허용 |
| 표시광고 위반 여부 같은 판단을 AI 답으로 정했다 | 법률 · 의료 · 안전 판단 요청은 ‘사람 확인’ 표시, 담당자가 결론 |
| 결과물을 누가 어떻게 확인하는지 정해져 있지 않았다 | **검수 체크리스트 1장 (목표치)** — 자동으로 볼 수 있는 항목은 먼저 확인 |

## 주요 기능

- **금지 목록** — 막을 것(고객 이름 · 전화번호 · 이메일 · 집 주소 · 주문/회원번호 · 주민등록번호 · 카드번호)과 조심할 것(미공개 매출·원가 · 계약 단가). 지금 프롬프트에 들어 있는 항목이 빨갛게 켜집니다.
- **공용 프롬프트** — 찾기 · 분류, 빈칸 입력, 자료 붙이기. 미리 보기에서 금지 정보는 빨강, 조심할 정보는 노랑, 빈칸은 주황.
- **복사 / 가리고 복사** — 금지 정보가 있으면 복사 버튼이 잠기고, ‘가리고 복사’는 `[고객]`, `[전화번호]`로 바꿔 복사합니다(되돌리기 가능). 복사하면 팀 사용 횟수가 올라갑니다.
- **프롬프트 점검** — 규칙 점수가 바로 나오고, ‘Claude로 점검’은 가린 프롬프트만 보내 고친 프롬프트를 받습니다.
- **결과물 검수표** — 결과물을 붙이면 개인정보 · 과장 표현 · 법률 문장을 자동으로 보고, 숫자 대조 · 출처 · 승인은 사람이 체크합니다. 인쇄하면 금지 목록 + 검수표 한 장.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | 가린 프롬프트로 `aiguide.review` → 형식 · 점수 범위 · 금지 정보 재검사 | `Claude로 점검 · 2.1초` |
| AI 키 없음 · 한도 초과 · 알 수 없는 작업 · 네트워크 오류 | 6가지 요소가 있는지 보는 규칙 점검 | `규칙 기반 · (이유)` |
| 응답 형식이 틀리거나 고친 프롬프트에 금지 정보가 들어 있음 | 버리고 규칙 점검 유지 | `규칙 기반 · 응답 형식 오류 · 금지 정보` |

검사 · 가리기 · 검수표는 AI 없이 브라우저에서만 동작합니다. 자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md), 서버 작업 정의는 [docs/ai-task.json](docs/ai-task.json).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 화면 | HTML · CSS · JavaScript (프레임워크·빌드 없음) |
| AI | Claude API — 서버 `aibuilderlab.kr/api/demo/ai`가 호출 |
| 실제 버전 | 팀 공유 가이드 문서 + 검수 체크리스트 |
| 테스트 | Node 내장 `node:test` |

## 폴더 구조

```
ax-ai-guide/
├── index.html
├── style.css
├── logic.js          금지 목록 · 검사 · 가리기 · 빈칸 채우기 · 점검 · 응답 검사 · 검수표 · 공용 프롬프트 12개 (DOM 없음)
├── ai-client.js      /api/demo/ai 호출, 실패하면 null
├── app.js            금지 목록 · 프롬프트 목록 · 작업대 · 검수표 화면
├── tests/logic.test.js
├── docs/ (ARCHITECTURE · DEVLOG · PROMPTS · ai-task.json)
├── CHANGELOG.md
└── package.json
```

## 실행 · 테스트

```bash
python3 -m http.server 8000   # http://localhost:8000
npm test                      # = node --test, 12개
```
