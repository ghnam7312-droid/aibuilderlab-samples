# 빠짐없이 — 교육 만족도 서술형 응답 요약

> 서술형 의견을 붙여 넣으면 **좋았던 점 · 아쉬운 점 묶음**으로 요약하되, **3명 이상 나온 의견은 하나도 빠뜨리지 않고** 검수표로 확인하는 도구

> **알림** AI 빌더랩 직장인 AX 트랙 **1기 목표 모델(가상의 수강생 ‘출결은알아서’)** 의 예시 프로젝트입니다. 가상의 회사 ‘온결물산’ 교육 1과정의 만족도 응답 36건 샘플로 동작하며, 결과 숫자는 1기 목표치입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 서술형 의견을 읽을 시간이 없어 **점수만 보고**했다 | 붙여 넣고 ‘요약하기’ → 의견 묶음 · 3문장 요약 · 개선 항목. **요약 1일 → 30분** (목표치) |
| AI 요약에서 **소수 의견이 사라졌다** | **3명 이상 나온 의견은 모두 남긴다.** Claude가 빠뜨리면 규칙 묶음을 되살리고 노란색 ‘되살림’ 표시 |
| 요약이 맞는지 원문과 대조하기 어려웠다 | 검수표: 묶음마다 ‘원문 n건 보기’ → 왼쪽에 그 응답만, 확인하면 체크(검수 n/m) |
| 1~2명 의견은 어디 갔는지 모름 | 지우지 않고 ‘기타 의견’ · ‘분류 안 됨’으로 따로 모아 둔다 |
| 개선 회의 때 뭘 바꿀지 다시 정리 | 아쉬움 묶음에서 개선 항목을 뽑고 ‘다음 교육 반영’ 체크 → **개선 3건 반영** (목표치) |

> 리드 빌더 ‘엑셀탈출’ 코멘트 — “소수 의견을 지키는 기준을 넣은 점이 교육 담당자답습니다.”

## 주요 기능

- **의견 묶음** — 주제(실습 시간, 진행 속도, 교육장 환경 …) × 결(좋음/아쉬움). “좋았지만 실습이 짧았다”는 두 묶음에 모두 들어간다.
- **반드시 남길 기준** — 2명 / 3명 / 4명 이상을 고르면 바로 다시 나눈다. 규칙 모드에서는 “많은 순 5개만 남겼다면 빠졌을 의견”을 함께 보여 준다.
- **검수표** — 원문 보기 · 검수 체크 · 검수 표시 지우기(되돌리기 가능). 보고서에는 검수하지 않은 묶음이 ‘미검수’로 남는다.
- **개인정보 가리기** — 응답 속 전화번호 · 메일 · 사번은 화면과 AI 입력 전에 `[전화번호]`처럼 가린다.
- **보고서 복사 · 샘플로 되돌리기** — 요약 · 주요/기타 의견 · 반영 항목을 텍스트로 복사. 작업 내용은 브라우저에 저장.

## AI는 이렇게 동작합니다

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| Claude 연결됨 | 가린 응답을 `survey.summary`로 보냄 → 형식 검사 → **기준 이상 의견이 빠졌는지 대조, 빠졌으면 되살림** | `Claude로 정리 · 2.1초` |
| AI 키 없음 · 한도 초과 · 네트워크 오류 · 아직 없는 작업 | 주제 사전으로 묶는 규칙 요약 | `규칙 기반 · (이유)` |
| 응답 형식이 틀림(결이 다름, 없는 응답 번호 등) | 버리고 규칙 요약 유지 | `규칙 기반 · 응답 형식이 맞지 않음` |

자세한 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 지시문 원문은 [docs/PROMPTS.md](docs/PROMPTS.md).
