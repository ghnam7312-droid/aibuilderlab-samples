# 다음주 — 학원 학부모 리포트

> 학부모가 궁금한 건 점수가 아니라 **다음 주 계획**입니다. 단원 평가 결과를 학부모가 카카오톡으로 바로 읽는 리포트로 바꿔 주는 학원용 서비스예요.

![다음주 리포트 작업대 화면](./screenshot.png)

**데모:** https://aibuilderlab.kr/demo/startup-academy-report/index.html

> 이 저장소는 **AI 빌더랩 창업 트랙 1기 ‘목표 모델’ 예시**입니다. 수료생이 이 수준까지 만든다는 목표를 보여 주려고 만들었고, 학원·학생·가격은 모두 가상입니다. 데모는 샘플 데이터로 동작합니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 학원마다 학부모 리포트를 만드는 데 강사 시간이 많이 듭니다. 한 달에 몇 시간씩 엑셀 성적표를 캡처해 카톡으로 보냅니다. | 학생을 고르고 ‘리포트 만들기’를 누르면 단원별 정답률, 보완할 단원, 다음 주 계획이 담긴 리포트가 만들어집니다. |
| 기존 학원 프로그램은 비싸고 기능이 많아 잘 쓰지 않습니다. | 리포트 한 가지에 집중했고, 요금은 학생 수 기준으로 단순하게 잡았습니다(예시 가격). |
| 학원마다 교재와 단원 순서가 다릅니다. | 교재 단원표를 직접 고치거나 CSV로 한 번에 올리면, 리포트가 그 순서대로 만들어집니다. |

## 주요 기능

- **리포트 작업대:** 학생 목록(반·이름으로 찾기) → 단원별 정답률 → 보완할 단원 3개를 형광펜으로 표시 → 다음 주 계획 3줄 → 선생님 한마디
- **학부모 화면 미리보기:** 카카오톡 채팅방에서 학부모가 받을 리포트 카드를 옆에서 바로 확인합니다. ‘리포트 만들기’를 누르면 카드가 차례로 채워집니다.
- **카톡 문구 복사:** 누르면 학부모에게 보낼 문구가 복사되고, 그 학생은 ‘보냄’으로 바뀝니다. 실수로 눌렀으면 알림에서 되돌릴 수 있어요.
- **원장 대시보드:** 반별 평균 정답률, 반마다 가장 약한 단원, 단원 × 반 정답률 표, 아직 보내지 않은 학부모 목록
- **교재 단원표:** 단원 추가·수정·삭제(되돌리기 지원), CSV 올리기, CSV 예시 받기
- **요금제:** 학생 수에 맞는 요금제를 추천합니다. 가격은 예시입니다.

### AI 분석은 어떻게 동작하나요

데모에서는 **브라우저 규칙 기반**으로 동작합니다. 정답률이 가장 낮은 단원 3개를 고르고, 정해 둔 틀(월·수 개념 복습 / 목 틀린 유형 / 토 누적 테스트)에 넣어 계획을 만듭니다. 만든 문장은 선생님이 고쳐 쓸 수 있습니다. 실제 버전은 Claude API로 학생별 오답 패턴을 읽어 계획 문장을 씁니다.

## 화면 구성

```
┌──────────┬───────────────────────────────────────────────┐
│ 다음주     │  10월 학부모 리포트                 보냄 3/15 ▬▬ │
│          ├──────────┬────────────────────┬───────────────┤
│ 리포트 작업대 │ 학생 목록  │ 리포트 재료            │ 학부모가 받는 화면 │
│ 원장 대시보드 │ (반·검색)  │ 단원별 정답률 · 형광펜    │ ┌───────────┐ │
│ 교재 단원표  │          │ 다음 주 계획 3줄        │ │ 카톡 리포트 카드 │ │

```

모바일(375px)에서는 메뉴가 위로 올라가고, 학생 목록 → 재료 → 미리보기 순서로 세로로 쌓입니다.

## 기술 스택

| | 이 데모 | 실제 버전 (포트폴리오 기준) |
|---|---|---|
| 화면 | HTML · CSS · JavaScript (빌드 도구 없음) | Next.js |
| 데이터 | 브라우저 localStorage | Supabase |
| AI | 브라우저 규칙 기반 | Claude API |
| 공유 | 문구 복사 | 카카오톡 공유 |

글꼴은 SUIT(화면)와 고운바탕(선생님 한마디)을 씁니다.

## 실행 방법

```bash
# 폴더에서 간단한 서버를 띄운 뒤 브라우저로 엽니다
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html`을 바로 열어도 동작합니다. 상단 ‘← 포트폴리오로’ 링크는 aibuilderlab.kr 사이트 기준 주소라서 내 컴퓨터에서는 열리지 않습니다.

입력한 내용은 이 브라우저에만 저장됩니다. 왼쪽 아래 ‘샘플 데이터로 되돌리기’로 처음 상태로 돌아갈 수 있어요.
