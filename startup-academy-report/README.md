# 다음주 — 학원 학부모 리포트

> 학부모가 궁금한 건 점수가 아니라 **다음 주 계획**입니다. 단원 평가 결과를 Claude가 읽고, 학부모가 카카오톡 링크 하나로 여는 리포트로 바꿔 주는 학원용 서비스예요.

**학부모 화면 예시:** 데모에서 ‘리포트 만들기’ → ‘학부모 링크 · QR’ → 휴대폰으로 QR을 비춰 보세요.

> 이 저장소는 **AI 빌더랩 창업 트랙 1기 ‘목표 모델’ 예시**입니다. 수료생이 이 수준까지 만든다는 목표를 보여 주려고 만들었고, 학원·학생·가격은 모두 가상입니다. 데모는 샘플 데이터로 동작합니다.

## 문제 → 해결

| 문제 (인터뷰에서 들은 말) | 해결 |
|---|---|
| 강사 3명이 한 명당 4시간씩, 엑셀 성적표를 캡처해 카톡으로 보냅니다. | 학생을 고르고 ‘리포트 만들기’ → Claude가 다음 주 계획 초안까지 써 줍니다. 선생님은 고쳐서 보내기만 합니다. |
| “점수보다 다음에 뭘 할지 물어보는 학부모가 많아요.” | 리포트 맨 위에 보완 단원과 **요일이 들어간 계획 3줄**. 학부모는 휴대폰에서 아이와 함께 체크합니다. |
| “우리 교재 단원 순서대로 나와야 해요.” | 교재 단원표를 학원마다 두고, CSV로 한 번에 올립니다. 리포트가 그 순서대로 만들어집니다. |
| “기존 학원 프로그램은 월 20만 원인데 기능이 너무 많아서 안 써요.” | 리포트 하나에 집중, 학생 수 기준의 단순한 요금제(예시 가격). |

## 주요 기능

- **리포트 작업대** — 학생 목록(반·이름 검색) → 단원별 정답률과 3개월 추이 → 형광펜으로 표시한 보완 단원 → 다음 주 계획 3줄 → 학부모 첫 인사 → 선생님 한마디. 옆에서 카카오톡 미리보기가 차례로 채워집니다.
- **Claude 다음 주 계획** — 정답률을 읽고 요일·문항 수가 들어간 계획을 씁니다. 결과 옆에 `Claude로 분석 · 1.4초` 또는 `규칙 기반 · 이유`가 늘 붙습니다. 선생님이 고치면 `선생님이 고침`.
- **학부모 링크 · QR** — 리포트를 압축해 주소 안에 담습니다. 서버에 학생 정보를 저장하지 않고, 휴대폰으로 QR을 비추면 바로 열립니다. 카톡 문구에도 링크가 들어갑니다.
- **학부모 화면** (`report.html`) — 큰 평균 점수, 지난달 대비, 3개월 막대, 단원 막대, 아이와 함께 체크하는 계획(그 휴대폰에만 저장), 선생님 손편지.
- **원장 대시보드** — 6개월 반별 추이(반을 눌러 강조), 발송률, 가장 약한 단원, 단원 × 반 히트맵, 미발송 학부모.
- **시작하기** — 새 학원이 첫 리포트를 보내기까지 4단계 체크리스트. ‘새 학원으로 처음부터 해 보기’로 빈 학원에서 직접 해 볼 수 있습니다.
- **교재 단원표** — 고치기 · 추가 · 삭제(되돌리기) · CSV 올리기 · 끌어다 놓기 · 예시 받기. 못 읽은 줄 번호를 알려 줍니다.
- **요금제** — 학생 수에 맞는 추천, 월/연 결제, 학생 1명당 가격, 기능 비교, 자주 묻는 질문. **가격은 예시입니다.**

### AI가 연결되지 않으면?

`ai-client.js`가 실패를 감지해 `null`을 돌려주고, 화면은 `logic.js`의 **규칙 계획**(정답률이 낮은 단원 3개 → 월·수 / 목 / 토 틀)으로 바꿉니다. 사이드바의 `Claude 연결됨 / 규칙 모드` 표시와 계획 옆 칩으로 어느 쪽인지 알 수 있어요. 서비스는 어느 경우에도 멈추지 않습니다.

## 기술 스택

| | 이 데모 | 실제 버전 (포트폴리오 기준) |
|---|---|---|
| 화면 | HTML · CSS · JavaScript (빌드 도구 없음) | Next.js |
| 데이터 | 브라우저 localStorage | Supabase |
| AI | Claude API (서버 경유) + 규칙 대체 | Claude API |
| 공유 | 링크·QR (주소 안에 압축) · 문구 복사 | 카카오톡 공유 |

글꼴은 SUIT(화면)와 고운바탕(선생님 한마디). 그래프는 라이브러리 없이 SVG로 직접 그립니다. QR만 `qrcode-generator@1.4.4`(CDN)를 씁니다.

자세한 구조: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## 실행 · 테스트

```bash
# 화면: 폴더에서 서버를 띄우고 브라우저로
python3 -m http.server 8000      # → http://localhost:8000

# 테스트: Node 18 이상, 설치할 패키지 없음
npm test
```

`index.html`을 바로 열어도 동작합니다. 내 컴퓨터에서 열어도 같은 Claude 서버를 부르고, 연결이 안 되면 규칙 모드로 동작합니다. 상단 ‘← 포트폴리오로’ 링크는 aibuilderlab.kr 기준 주소입니다.
