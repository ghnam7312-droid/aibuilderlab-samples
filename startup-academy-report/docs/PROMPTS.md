# 다음주 · AI 활용 기록

> 1기 목표 모델 예시입니다. 개발하며 쓴 프롬프트(가상의 창업자 기준)와, 서비스가 실행 중에 Claude에게 보내는 실제 지시문을 함께 적었습니다.

## 1. 서비스 안에서 Claude가 하는 일

| 작업 | 언제 | 보내는 것 | 받는 것 |
|---|---|---|---|
| `academy.plan` | ‘리포트 만들기’를 처음 누를 때, ‘Claude로 다시 쓰기’ | 학생 이름·반·단원별 정답률·선생님 한마디 | 보완 단원, 계획 3줄, 학부모 첫 인사 |

호출 경로: 브라우저 `ai-client.js` → `https://aibuilderlab.kr/api/demo/ai` (서버가 키를 가짐) → Claude.
키가 없거나, 사용량 한도를 넘거나, 응답 모양이 틀리면 **규칙 계획**(`logic.js`의 `rulePlan`)으로 바꾸고 화면에 이유를 표시합니다.

### 실제 지시문 (서버)

```text
학원 단원 평가 결과로 학부모에게 보낼 '다음 주 계획'을 쓴다.
weak는 정답률 낮은 단원 최대 3개.
plan은 요일이 들어간 구체적 학습 3줄(문항 수·시간 포함).
message는 학부모 카카오톡 첫 문장(학생 이름 포함, 2문장 이내, 과장 없이).
모든 문장은 한국어로, 짧고 구체적으로 쓴다. 반드시 JSON 하나만 출력하고 다른 말은 쓰지 않는다.
출력 형식: {"weak":[""],"plan":["","",""],"message":""}
```

### 보내는 입력 예

```json
{
  "student": "김서윤", "className": "중2 A반", "month": "10월", "academy": "하늘수학학원",
  "units": [{ "name": "유리수와 순환소수", "rate": 65 }, { "name": "일차부등식", "rate": 60 }],
  "teacherNote": "질문이 많아져서 반가워요."
}
```

### 응답을 그대로 믿지 않는 이유

`normalizeAiPlan`이 다음을 검사합니다 (`tests/logic.test.js`).
- 계획이 3줄이 안 되면 버림 → 규칙 계획
- 단원표에 없는 단원 이름은 보완 단원에서 지움
- 한 줄 70자, 첫 인사 140자에서 자름

## 2. 만들면서 쓴 프롬프트 (주차별 대표)

| 주차 | 프롬프트 | 바뀐 것 |
|---|---|---|
| 7 | "학부모가 카톡 첫 화면에서 3초 안에 '다음 주에 뭘 하는지' 알 수 있게 카드 구조를 제안해 줘. 점수는 작게." | 카드 맨 위를 평균 점수에서 '보완 단원 + 계획'으로 |

| 8 | "엑셀에서 저장한 CSV를 읽는 함수 … 못 읽은 줄 번호를 돌려줘. 테스트도." | `parseUnitCsv` + 테스트 2개 |
| 8 | "단원 × 반 정답률을 색으로 보여 주는 표. 낮을수록 진하게, 글자 대비 유지." | 원장 대시보드 히트맵 |
| 9 | "Claude 응답이 형식에 안 맞을 때를 다 막는 검사 함수를 짜 줘. 지어낸 단원 이름도." | `normalizeAiPlan` |
| 9 | "AI 결과인지 규칙 결과인지 사용자가 늘 알 수 있게 표시하는 방법" | 칩: `Claude로 분석 · 1.4초` / `규칙 기반 · 이유` |
| 10 | "서버 없이 리포트를 링크로 보내고 싶어. 개인정보가 서버에 안 남게." | 주소 `#` 안에 압축해 담기 |
| 10 | "한글 JSON을 base64url로 바꿀 때 깨지는 이유와 고치는 법" | `TextEncoder` → base64url |

## 3. 디버깅 기록 (12건 중 대표)

| 증상 | 원인 | 고친 방법 |
|---|---|---|
| CSV 둘째 칸이 `"단항식의` 로 잘림 | 따옴표 안 쉼표를 칸 구분으로 읽음 | 따옴표 상태를 기억하는 파서 |
| 보완 단원에 없는 단원이 나옴 | Claude가 단원 이름을 지어냄 | 단원표와 대조해 걸러 냄 |
| QR을 휴대폰이 못 읽음 | 링크 1,200자 → QR이 너무 촘촘 | deflate 압축 + 오류 정정 L |
| 학부모 화면에서 한글 깨짐 | `btoa`는 라틴 문자만 받음 | UTF-8 바이트로 바꾼 뒤 인코딩 |
